1 Algorithm Description

Real-life analogy: Imagine you're organising a huge party for 300 guests. You have 5 tables. You want each guest to sit with people most similar to them (by age, interests, industry). At first, you randomly assign guests to tables. Then, for each table, you compute the "average guest" profile. Next, you reassign each guest to whichever table's average profile is closest to them. Repeat. Eventually, guests stop switching tables — that's your final seating arrangement. This iterative "assign → update → repeat" loop is exactly K-Means.

What is K-Means?

K-Means is an unsupervised clustering algorithm that partitions N data points into K non-overlapping groups (clusters), where each point belongs to the cluster with the nearest centroid (the mean of the points in that cluster). It is one of the simplest, fastest, and most widely used clustering algorithms in the world.

Key properties:

  • Unsupervised — no labels. The algorithm discovers structure on its own.
  • Partition-based — every point belongs to exactly one cluster (hard assignment).
  • Centroid-based — each cluster is represented by its mean.
  • Iterative — refines centroids and assignments until convergence.
  • Guaranteed to converge — but only to a local optimum, not necessarily the global one.

How the Algorithm Works (Step by Step)

Step 1
Choose K
Decide how many clusters you want. This is a hyperparameter you choose.
Step 2
Initialise centroids
Pick K initial centroid positions — often randomly from the data (or use K-Means++).
Step 3
Assign points
Assign each data point to the nearest centroid (usually by Euclidean distance).
Step 4
Update centroids
Recompute each centroid as the mean of all points currently assigned to it.
Step 5
Repeat or stop
Repeat Steps 3–4 until centroids stop moving (convergence) or max iterations reached.
Step 6
Return clusters
Final centroids and cluster assignments are your output. Optionally run multiple restarts and pick the best.

2 Applications

K-Means is used everywhere data needs to be grouped into natural buckets. It is often the first clustering algorithm people try — and often the one that works well enough to keep.

🛒 Customer Segmentation

  • Marketing segments — group customers by purchase behaviour for targeted campaigns.
  • RFM analysis — Recency, Frequency, Monetary value clustering.
  • Churn cohorts — identify similar groups of at-risk customers.
  • Persona building — cluster users for product design.

🖼️ Image Processing

  • Colour quantisation — reduce an image to K dominant colours.
  • Image compression — represent pixels by their cluster centroids.
  • Segmentation — group pixels with similar colours/textures.
  • Background subtraction — cluster foreground vs. background.

📝 Document & Text

  • Topic discovery — cluster documents by topic.
  • News grouping — group similar articles.
  • Search deduplication — collapse near-duplicate results.
  • Word embeddings — cluster word vectors into semantic groups.

🏥 Healthcare

  • Patient stratification — cluster patients by symptoms and outcomes.
  • Gene expression — group genes by expression patterns.
  • Medical imaging — segment tissue types.
  • Epidemiology — cluster regions by disease rates.

🌐 Technology & Networks

  • Anomaly detection — points far from any centroid are anomalies.
  • Network clustering — group users by behaviour.
  • Data compression — codebook learning (vector quantisation).
  • Recommendation systems — cluster users/items for candidate generation.

🏭 Operations & Science

  • Warehouse location — cluster delivery points to find optimal hubs.
  • Inventory grouping — cluster SKUs by demand patterns.
  • Sensor networks — group sensors by behaviour.
  • Astronomy — classify stars and galaxies.
  • Seismology — cluster earthquake epicentres.
Why so popular? Because it scales to millions of points, produces compact understandable clusters, and its results are easy to interpret. Whenever you need to "bucket" data without labels, K-Means is the natural first choice.

3 Advantages

  • Extremely simple to understand and implement — the algorithm fits in a few lines of code, and its intuition is easy to explain to non-technical stakeholders.
  • Fast and scalable — O(N·K·d·i) per iteration (N points, K clusters, d dimensions, i iterations). Lloyd's algorithm is essentially linear in N. Can cluster millions of points in minutes.
  • Guaranteed convergence — inertia decreases monotonically at every step. The algorithm always terminates.
  • Easy to interpret results — each cluster has a clear centroid that can be described in terms of feature means.
  • Works well with spherical, well-separated clusters — if the data actually has K globular groups, K-Means is optimal.
  • Requires only one hyperparameter K — unlike DBSCAN (which needs ε and minPts) or Gaussian Mixture (which needs covariance structure).
  • Produces hard partitions — every point belongs to exactly one cluster. Useful when you need definitive assignment.
  • Works with any distance metric — Euclidean is standard, but cosine, Manhattan, etc. can be used.
  • Foundation for more advanced algorithms — Mini-Batch K-Means, K-Medoids, Fuzzy C-Means, Spectral Clustering, and vector quantisation all build on it.
  • Memory efficient — only K centroids need to be stored, plus one label per point.
  • Parallelisable — the assignment step can be distributed across many machines (used in Spark MLlib, Dask, etc.).
  • Well-studied theoretically — convergence, complexity, and quality bounds are well understood.
  • Multiple restarts improve reliability — running K-Means 10 times with different inits and picking the best is standard practice.
  • Feature of many pipelines — vector quantisation for deep learning, bag-of-words, image compression, and more.

4 Disadvantages

  • You must specify K in advance — the number of clusters is a hyperparameter. There's no way to know it from the algorithm itself. You must use elbow, silhouette, gap statistic, or domain knowledge.
  • Sensitive to initialisation — different random seeds can produce very different clusters. A bad init leads to a bad local optimum. Always use K-Means++ or multiple restarts.
  • Assumes spherical, equal-variance clusters — K-Means implicitly assumes clusters are round, similarly sized, and driven by Euclidean distance. Elongated or uneven clusters are handled poorly.
  • Sensitive to outliers — because centroids are means, a single far-away point drags the centroid significantly. Use K-Medoids or trim outliers first.
  • Only finds convex clusters — cannot separate concentric rings, moons, or other non-convex shapes. Use DBSCAN or Spectral Clustering instead.
  • Hard assignment only — every point belongs to exactly one cluster, even if it's on a boundary. Fuzzy C-Means provides soft memberships.
  • Requires feature scaling — Euclidean distance is scale-sensitive, so features must be standardised or normalised first.
  • Fails with different cluster densities — if one cluster is dense and another is sparse, K-Means struggles to separate them.
  • Fails with categorical data — Euclidean distance is meaningless for categorical features. Use K-Modes or K-Prototypes.
  • Suffers from the "curse of dimensionality" — in high dimensions, distances become less discriminative. Reduce dimensions first (PCA, UMAP).
  • Inconsistent results across runs — unless you set a random seed and use K-Means++, results may not be reproducible.
  • No p-values or statistical guarantees — clustering is exploratory. Unlike regression, you cannot say "this cluster is statistically significant."
  • Convergence to local optimum only — the algorithm finds the best solution near its starting point, not the globally optimal one. Multiple restarts help but don't guarantee the global optimum.
  • Empty cluster problem — sometimes a centroid ends up with no points assigned. Common workarounds: reassign the farthest point, or drop the cluster and reduce K.
The spherical assumption trap: Imagine you have two concentric rings of points (inner circle and outer ring). No matter what K you choose, K-Means cannot separate them — it only draws straight-line boundaries between centroids. For non-convex clusters, use DBSCAN or Spectral Clustering.

5 Pre-Deployment KPIs — Detailed with Formulas

Unlike supervised learning, clustering has no ground-truth labels, so we cannot compute accuracy. Instead, we use internal metrics (measuring cluster quality from the data alone) and external metrics (when we do have labels for validation).

5.1 Internal Metrics — Quality of the Clustering

Inertia / WCSS (Within-Cluster Sum of Squares) Internal

What it measures: The total squared distance from each point to its assigned centroid. This is the objective K-Means minimises. Lower is better, but it always decreases as K grows.

Formula Inertia = Σk=1K Σxi ∈ Ck || xi − μk ||²

K = number of clusters
Ck = set of points in cluster k
μk = centroid of cluster k
||·||² = squared Euclidean distance
Worked example: Cluster has 3 points: (0,0), (2,0), (1,2). Centroid = (1, 0.67).
Distances²: (0−1)²+(0−0.67)² = 1.45; (2−1)²+(0−0.67)² = 1.45; (1−1)²+(2−0.67)² = 1.78
Cluster inertia = 1.45 + 1.45 + 1.78 = 4.68
Interpretation: Lower = tighter clusters. Compare across K values to find the elbow. Absolute value is dataset-specific and not directly interpretable.
✔ Use when Comparing multiple K values (elbow method) or comparing different initialisations with the same K.
✘ Avoid when Comparing across datasets or different feature scales — inertia is scale-dependent.

Silhouette Score Internal

What it measures: For each point, how similar it is to its own cluster compared to the next-closest cluster. Combines cohesion (intra-cluster tightness) and separation (inter-cluster distance).

Per-point silhouette s(i) = ( b(i) − a(i) ) / max( a(i), b(i) )

a(i) = mean distance from point i to all other points in its own cluster (cohesion)
b(i) = minimum mean distance from point i to all points in any other cluster (separation)

Overall silhouette Silhouette = (1/N) · Σi=1N s(i)

Range −1 ≤ s(i) ≤ +1
Worked example: Point i is 2.0 units from its own cluster on average (a = 2.0) and 5.0 units from the nearest other cluster (b = 5.0).
s(i) = (5.0 − 2.0) / max(5.0, 2.0) = 3.0 / 5.0 = 0.60 (good!)
Interpretation scale:
• s ≈ +1 → point is far from neighbours, in the "right" cluster ✅
• s ≈ 0 → point is on the boundary between clusters ⚠️
• s < 0 → point might be in the wrong cluster ❌
• Average > 0.5 → strong structure
• Average 0.25–0.5 → weak but usable
• Average < 0.25 → no real structure
✔ Use when Choosing K, comparing clusterings, or identifying misclassified points.
✘ Avoid when Data has non-convex clusters — silhouette favours convex clusters.

Davies-Bouldin Index (DBI) Internal

What it measures: The average ratio of within-cluster scatter to between-cluster separation. Lower = better.

Cluster scatter Sk = (1/|Ck|) · Σxi ∈ Ck || xi − μk ||

Distance between clusters Mjk = || μj − μk ||

Similarity between clusters j and k Rjk = ( Sj + Sk ) / Mjk

Davies-Bouldin Index DBI = (1/K) · Σk=1K maxj ≠ k Rjk
Interpretation: Lower is better.
• DBI < 1 → excellent separation
• DBI ≈ 1 → reasonable
• DBI > 2 → poor separation
DBI has no upper bound. Always compare against other K values.
✔ Use when You want a compact score to compare multiple K values (lower DBI = better K).
✘ Avoid when Clusters have very different densities — DBI is biased toward spherical, equal-size clusters.

Calinski-Harabasz Index (CH) Internal

What it measures: The ratio of between-cluster dispersion to within-cluster dispersion. Higher = better.

Between-cluster dispersion SSB = Σk=1K |Ck| · || μk − μ ||²

Within-cluster dispersion SSW = Σk=1K Σxi ∈ Ck || xi − μk ||²

CH Index CH = ( SSB / (K − 1) ) / ( SSW / (N − K) )

μ = global mean of all points
N = total number of points
Interpretation: Higher is better.
• CH has no upper bound
• Higher CH = clusters are dense and well-separated
• Typically peaks at the "correct" K
✔ Use when Comparing K values and looking for a peak.
✘ Avoid when Clusters are non-convex — CH favours globular clusters.

Dunn Index Internal

What it measures: The ratio of the smallest inter-cluster distance to the largest intra-cluster diameter. Higher = better.

Formula Dunn = minj ≠ k d( Cj, Ck ) / maxk diam( Ck )

d( Cj, Ck ) = minimum distance between any two points in clusters j and k
diam( Ck ) = maximum distance between any two points in cluster k
Interpretation: Higher is better. Dunn > 1 means clusters are well-separated. Very sensitive to outliers (one extreme point can destroy the metric).

Gap Statistic Internal

What it measures: Compares the observed within-cluster dispersion to that expected under a null reference (uniform random data). Helps identify the true K.

Formula Gap(K) = (1/B) · Σb=1B log( WK(b) ) − log( WK )

WK = within-cluster dispersion for K clusters on real data
WK(b) = same on the b-th reference dataset
B = number of Monte Carlo reference datasets

Choose K as the smallest K such that Gap(K) ≥ Gap(K+1) − sK+1
where sK+1 is the standard error of Gap(K+1)
Interpretation: Larger gap = stronger evidence for that K. The Gap Statistic is more rigorous than the elbow method but also more expensive (requires Monte Carlo simulation).

Elbow Method (Visual Heuristic) Internal

What it measures: Plot inertia vs K and look for the "elbow" where the curve flattens.

Heuristic 1. Run K-Means for K = 1, 2, 3, …, Kmax
2. Plot inertia(K) vs K
3. Look for the "elbow" where the slope changes abruptly
4. Choose that K
Interpretation: The elbow is a visual heuristic — not a formal metric. It works well when clusters are well-separated. Combine with silhouette score for confidence.

5.2 External Metrics — When You Have Ground-Truth Labels

Adjusted Rand Index (ARI) External

What it measures: Similarity between the predicted clustering and the true labels, corrected for chance. Range −1 to +1.

Rand Index RI = ( a + b ) / C(N, 2)

a = pairs of points that are together in both clusterings
b = pairs of points that are apart in both clusterings
C(N, 2) = total number of pairs

Adjusted Rand Index ARI = ( RI − E[RI] ) / ( max(RI) − E[RI] )
Interpretation scale:
• ARI = 1 → perfect match
• ARI = 0 → random labelling
• ARI < 0 → worse than random

Normalised Mutual Information (NMI) External

What it measures: How much information the predicted clusters share with the true labels.

Mutual Information MI( U, V ) = Σi Σj P( i, j ) · log( P( i, j ) / ( P(i) · P(j) ) )

U = predicted clusters  |  V = true labels

NMI NMI = MI( U, V ) / √( H(U) · H(V) )

H(U), H(V) = entropies of U and V
Interpretation: Range 0 to 1 (higher is better). NMI = 1 means perfect correspondence; NMI = 0 means no shared information.

Fowlkes-Mallows Index (FMI) External

What it measures: Geometric mean of precision and recall for pairwise cluster membership.

Formula FMI = √( ( TP / (TP + FP) ) · ( TP / (TP + FN) ) )

TP = pairs together in both clusterings
FP = pairs together in predicted but not true
FN = pairs together in true but not predicted
Interpretation: Range 0 to 1 (higher is better). FMI = 1 means identical clusterings.

Purity & Homogeneity / Completeness External

Purity Purity = (1/N) · Σk maxj | Ck ∩ Lj |

Ck = predicted cluster, Lj = true label

Homogeneity Each cluster contains only members of a single class.

Completeness All members of a given class are in the same cluster.

V-measure V = 2 · (homogeneity · completeness) / (homogeneity + completeness)
Interpretation: All range 0 to 1 (higher is better). Purity is easy but biased toward many clusters; V-measure balances both directions.

5.3 Model Quality & Robustness KPIs

Cluster Stability Across Restarts Robustness

What it measures: How consistent the clusters are across multiple random initialisations. High stability = reliable clustering.

Pairwise stability Stability = (1 / C(R, 2)) · Σa < b ARI( labelsa, labelsb )

R = number of K-Means runs with different seeds
ARI = Adjusted Rand Index between two runs
Interpretation: Range 0 to 1 (higher is better). Stability > 0.8 = very consistent. Stability < 0.5 = the choice of K or the data is unstable.

Bootstrap Stability Robustness

What it measures: Refit K-Means on bootstrap samples and check if the same clusters reappear.

Procedure 1. Draw B bootstrap samples from the data
2. Run K-Means on each
3. For each cluster in the original, find its "best match" in the bootstrap runs
4. Compute the Jaccard similarity of memberships

Jaccard similarity J( Ck, C'k ) = | Ck ∩ C'k | / | Ck ∪ C'k |
Interpretation: Mean Jaccard > 0.75 = stable clusters. < 0.5 = clusters are not reliable.

Number of Empty Clusters Robustness

What it measures: How many clusters ended up with zero points.

Formula Empty = | { k : |Ck| = 0 } |
Interpretation: Ideal = 0. Any empty cluster means K is too large, initialisation was bad, or the algorithm hit a degenerate solution. Common fixes: reduce K, use K-Means++, or reassign the farthest point.

Smallest Cluster Size Ratio Robustness

What it measures: The ratio of the smallest cluster to the expected cluster size.

Formula Size Ratio = mink |Ck| / (N/K)
Interpretation: Ratio close to 1 = balanced clusters. Very small ratio suggests a tiny "junk" cluster — often an outlier being isolated. Consider whether that's meaningful or a problem.

6 Post-Deployment KPIs — Detailed with Formulas

Once clusters are deployed (e.g., customers are assigned to segments), you must monitor whether the clusters still mean something. If customers shift, clusters become stale.

6.1 Cluster Stability & Drift

Centroid Drift Cluster Health

What it measures: How much each centroid has moved between the training run and the production refit.

Formula Driftk = || μktrain − μkprod ||

Normalised drift Drift%k = Driftk / || μktrain ||
Interpretation: Small drift = clusters are stable. Large drift (> 20%) means the cluster definitions have changed significantly — investigate or retrain.

Cluster Population Shift Cluster Health

What it measures: How the relative sizes of clusters change over time.

Population shift for cluster k Shiftk = | pkprod − pktrain |

pk = |Ck| / N (fraction of points in cluster k)

Total variation distance TVD = ½ · Σk | pkprod − pktrain |
Interpretation: TVD < 0.05 = stable. TVD > 0.15 = significant shift. A cluster that shrinks to near-zero is a warning sign.

Cluster Assignment Entropy Cluster Health

What it measures: How uniformly points are distributed across clusters.

Formula H = − Σk=1K pk · log( pk )

pk = |Ck| / N

Normalised entropy Hnorm = H / log(K)
Interpretation: Hnorm close to 1 = balanced clusters. Hnorm close to 0 = all points collapse into one cluster.

Average Silhouette Over Time Cluster Health

What it measures: Whether the cluster separation is degrading over time.

Formula Silhouettet = mean silhouette at time t

Decay Decay % = ( Silhouettetrain − Silhouettet ) / Silhouettetrain × 100
Interpretation: Decay > 15% suggests the clusters no longer reflect the current data — retrain.

Feature Distribution Shift per Cluster Cluster Health

What it measures: For each cluster, whether the distribution of input features has changed.

PSI per cluster and feature PSIk,f = Σi ( A%i − E%i ) · ln( A%i / E%i )

A% = production distribution of feature f within cluster k
E% = training distribution of feature f within cluster k
Interpretation:
• PSI < 0.10 → stable ✅
• 0.10 ≤ PSI < 0.25 → monitor ⚠️
• PSI ≥ 0.25 → cluster meaning has shifted 🚨

6.2 Assignment Quality KPIs

Distance to Assigned Centroid Assignment

What it measures: Average distance from each point to its assigned centroid — a per-point version of inertia.

Formula AvgDist = (1/N) · Σi=1N || xi − μassign(i) ||
Interpretation: Watch for a rising average distance — it means new points are landing far from existing centroids, suggesting the clusters no longer cover the data.

Outlier Rate (Far from Any Centroid) Assignment

What it measures: Fraction of production points whose distance to the nearest centroid exceeds a threshold (e.g., 99th percentile of training distances).

Formula OutlierRate = ( # { i : d( xi, μassign(i) ) > τ } ) / N

τ = threshold (e.g., the 99th percentile of training distances)
Interpretation: A sudden spike in outlier rate means new data is unlike the training data — a signal of concept drift or a broken upstream pipeline.

Cluster Assignment Confidence Assignment

What it measures: How much closer a point is to its assigned centroid than to the second-closest one.

Confidence Conf(i) = ( d2(i) − d1(i) ) / d2(i)

d1(i) = distance to nearest centroid
d2(i) = distance to second-nearest centroid
Interpretation: Confidence near 1 = clear winner. Confidence near 0 = the point is on a boundary — treat the assignment with caution.

6.3 Business & Operational KPIs

Segment Actionability Business

What it measures: Whether business metrics differ significantly across clusters — proving the segmentation is useful.

Between-cluster variance of business KPI Varbetween = Σk pk · ( KPIk − KPIoverall )²

F-ratio F = Varbetween / Varwithin
Interpretation: Higher F = segments differ meaningfully on business metrics — the segmentation is useful for targeting.

Cluster-Level Conversion / Revenue Business

What it measures: Business outcomes per cluster — the ultimate test of whether clustering adds value.

Formula Revenuek = Σi ∈ Ck revenuei
Conversionk = conversionsk / |Ck|
Interpretation: If all clusters have similar revenue, the segmentation isn't useful for targeting. Retrain or reconsider K.

Assignment Latency Operational

What it measures: Time to assign a new point to a cluster in production.

Formula AssignTime = O(K · d)

One distance computation per centroid per dimension. Extremely fast even for K = 1000.
Target example: K-Means is one of the fastest assignment algorithms. p50 < 0.1 ms, p95 < 1 ms for K = 100 and d = 50.

Retrain Frequency Governance

What it measures: How often clusters are refit as data drifts.

Formula Retrains/month = # of refits in last 30 days

Typical cadence Monthly to quarterly, depending on data velocity.
Trigger-based: when centroid drift > 20% or population shift > 15%.

Business Impact (ROI) Business

Formula ROI % = ( Net Gain / Total Cost ) × 100%

Net Gain = Uplift from segmentation − Cost of building/running
Worked example: Uplift from targeted campaigns = ₹8,00,000. Cost = ₹2,00,000.
Net Gain = ₹6,00,000. ROI = (6,00,000 / 2,00,000) × 100 = 300%
Golden rule: Clusters drift just like supervised models. Monitor centroid positions, cluster populations, and business outcomes per cluster. If cluster 3 used to be "high-value loyal customers" but now looks like "one-off buyers," the segmentation has lost its meaning — retrain.

7 Mathematical Formulas — How K-Means Actually Works

The core idea: minimise the total squared distance between points and their assigned centroids.

7.1 The Objective Function (Inertia / WCSS)

Objective J = Σk=1K Σxi ∈ Ck || xi − μk ||²

K = number of clusters
Ck = set of points in cluster k
μk = centroid of cluster k
xi ∈ ℝd = a data point in d-dimensional space

7.2 Euclidean Distance

Distance between point and centroid d( xi, μk ) = √[ Σj=1d ( xij − μkj )² ]

Squared distance (used in the objective) d²( xi, μk ) = Σj=1d ( xij − μkj )²

7.3 Assignment Step (E-step)

Each point is assigned to the nearest centroid.

Assignment rule assign(i) = argmink || xi − μk ||²

This is the "E-step" (Expectation) of the EM algorithm under a hard-assignment assumption.

7.4 Update Step (M-step)

Each centroid is recomputed as the mean of all points assigned to it.

Centroid update μk = ( 1 / |Ck| ) · Σxi ∈ Ck xi

This is the "M-step" (Maximisation) — it minimises the objective given the current assignments.

7.5 The Alternating Minimisation View

K-Means is an instance of alternating minimisation (also called Block Coordinate Descent). Each step decreases the objective:

Monotone decrease J( assignmentst, centroidst ) ≥ J( assignmentst+1, centroidst ) ≥ J( assignmentst+1, centroidst+1 )

Because J is bounded below by 0, the algorithm must converge (to a local minimum, not necessarily global).

7.6 K-Means++ Initialisation

Random initialisation can be poor. K-Means++ chooses initial centroids that are far apart, which dramatically improves the final result.

Procedure 1. Choose the first centroid μ1 uniformly at random from the data.
2. For each point xi, compute D(xi) = squared distance to nearest already-chosen centroid.
3. Choose the next centroid μk with probability proportional to D(xi)²:
    P( choose xi ) = D(xi)² / Σj D(xj)²
4. Repeat steps 2–3 until K centroids are chosen.
5. Run standard K-Means from these initial centroids.

Guarantee K-Means++ yields an expected approximation ratio of O(log K) relative to the global optimum.

7.7 The Elbow Method (Kneedle Algorithm)

Formalises the visual "elbow" using the maximum curvature of the inertia curve.

Normalised inertia yk = ( Inertia(k) − min ) / ( max − min )

Line from first to last point L(k) = y1 + ( yKmax − y1 ) · ( k − 1 ) / ( Kmax − 1 )

Elbow at the point of maximum deviation Kelbow = argmaxk | yk − L(k) |

7.8 Silhouette Coefficient — Full Formula

Cohesion (a) a(i) = ( 1 / (|Ck| − 1) ) · Σj ∈ Ck, j ≠ i d( xi, xj )

Separation (b) b(i) = minl ≠ k ( 1 / |Cl| ) · Σj ∈ Cl d( xi, xj )

Silhouette of point i s(i) = ( b(i) − a(i) ) / max( a(i), b(i) )

Overall silhouette S = ( 1 / N ) · Σi=1N s(i)

7.9 Davies-Bouldin Index — Full Formula

Scatter of cluster k Sk = ( 1 / |Ck| ) · Σxi ∈ Ck || xi − μk ||

Distance between centroids j and k Mjk = || μj − μk ||

Similarity of clusters j and k Rjk = ( Sj + Sk ) / Mjk

DBI DBI = ( 1 / K ) · Σk=1K maxj ≠ k Rjk

7.10 Calinski-Harabasz Index — Full Formula

Between-cluster dispersion SSB = Σk=1K |Ck| · || μk − μ ||²

Within-cluster dispersion SSW = Σk=1K Σxi ∈ Ck || xi − μk ||²

CH Index CH = ( SSB / (K − 1) ) / ( SSW / (N − K) )

7.11 Complexity Analysis

Time per iteration O( N · K · d )

N = number of points, K = number of clusters, d = dimensions

Total time O( N · K · d · i )

i = number of iterations (typically < 100)

Space O( N + K · d )
(labels for each point + centroids)

8 Glossary of Acronyms & Terms

Every abbreviation used in this study guide, explained in plain English.

Algorithm & Model Concepts

K-Means
A partitional clustering algorithm that groups points into K clusters by iteratively assigning points to nearest centroids and updating centroids to cluster means.
Clustering
Unsupervised learning that groups similar data points together.
Unsupervised
Learning without labels — the algorithm discovers structure on its own.
Supervised
Learning with labels (contrast with unsupervised).
Centroid
The mean (average) position of all points in a cluster.
K-Medoids
A K-Means variant that uses actual data points as cluster representatives instead of means. More robust to outliers.
K-Modes
A K-Means variant for categorical data, using mode instead of mean.
K-Prototypes
Combines K-Means and K-Modes for mixed numeric/categorical data.
Mini-Batch K-Means
K-Means on random mini-batches — much faster for huge datasets.
Fuzzy C-Means
Soft clustering — each point has a membership degree to each cluster (rather than hard assignment).
DBSCAN
Density-based clustering that finds arbitrary-shaped clusters and flags outliers.
Gaussian Mixture
Probabilistic clustering using a mixture of Gaussian distributions.
Spectral Clustering
Graph-based clustering using eigenvectors of the similarity matrix.
Hierarchical Clustering
Builds a nested tree (dendrogram) of clusters.
K-Means++
A smart initialisation that spreads initial centroids apart, improving results.
Elbow Method
A heuristic for choosing K by looking at where inertia stops decreasing rapidly.
Lloyd's Algorithm
The original K-Means algorithm (assign → update → repeat).
EM Algorithm
Expectation-Maximisation — the general framework K-Means instantiates in the hard-assignment limit.

Clustering Metrics

Inertia
Also called WCSS. The sum of squared distances from each point to its centroid. Lower is better.
WCSS
Within-Cluster Sum of Squares — the K-Means objective.
SSE
Sum of Squared Errors — same as WCSS.
SSB
Between-cluster sum of squares — used in Calinski-Harabasz.
SSW
Within-cluster sum of squares — same as inertia.
Silhouette
Per-point score measuring how well it fits its cluster vs. the next-closest.
Cohesion
How close points are within a cluster (a in silhouette).
Separation
How far apart clusters are (b in silhouette).
DBI
Davies-Bouldin Index — ratio of within-cluster scatter to between-cluster separation. Lower is better.
CH
Calinski-Harabasz Index — ratio of between-cluster to within-cluster dispersion. Higher is better.
Dunn Index
Ratio of minimum inter-cluster distance to maximum intra-cluster diameter. Higher is better.
Gap Statistic
Compares observed dispersion to a uniform reference. Rigorous but expensive.
ARI
Adjusted Rand Index — external metric comparing clusterings to ground truth, corrected for chance.
NMI
Normalised Mutual Information — external metric measuring shared information between clusterings.
FMI
Fowlkes-Mallows Index — geometric mean of pairwise precision and recall.
Purity
Fraction of points whose label matches the majority label in their cluster.
Homogeneity
Each cluster contains only points of one true class.
Completeness
All points of a true class end up in the same cluster.
V-measure
Harmonic mean of homogeneity and completeness.

Mathematics & Computation

Euclidean
The straight-line distance √Σ(xᵢ − yᵢ)². Default metric for K-Means.
Manhattan
Also called city-block or L1 distance: Σ|xᵢ − yᵢ|.
Chebyshev
L∞ distance: max|xᵢ − yᵢ|.
Cosine
1 − cos(angle between vectors). Common for text.
Lp Norm
Generalisation: (Σ|xᵢ − yᵢ|p)1/p.
Local Optimum
A solution that's optimal within a neighbourhood but not globally. K-Means converges to one of these.
Global Optimum
The best possible solution across all possible partitions.
Convergence
When the algorithm stops changing — centroids stop moving or assignments stop switching.
Alternating Minimisation
Optimising one set of variables while holding others fixed, then swapping. K-Means is an example.
Block Coordinate Descent
Another name for the alternating minimisation approach.
NP-hard
Finding the globally optimal K-Means solution is NP-hard. That's why we use heuristics like Lloyd's algorithm.
Approximation Ratio
How close an algorithm's solution is to the optimum. K-Means++ has O(log K) expected approximation.

Data & Preprocessing

Feature
An input variable (column in the dataset).
Feature Scaling
Transforming features to a comparable range (e.g., standardisation). Required for K-Means.
Standardisation
Mean 0, standard deviation 1 (z-score).
Normalisation
Min-max scaling to [0, 1].
Curse of Dimensionality
In high dimensions, distances become less discriminative. Reduces K-Means effectiveness.
PCA
Principal Component Analysis — linear dimensionality reduction. Often used before K-Means.
UMAP
Uniform Manifold Approximation and Projection — nonlinear dimensionality reduction.
t-SNE
t-distributed Stochastic Neighbour Embedding — nonlinear visualisation technique.
Dendrogram
A tree diagram showing hierarchical clustering merges.
Elbow
The point on the inertia curve where the slope changes — a heuristic for K.
Knee
Another name for the elbow point.

Monitoring & Deployment

KPI
Key Performance Indicator — a measurable value tracking model or business performance.
PSI
Population Stability Index — measures distribution shift between training and production.
KS Test
Kolmogorov-Smirnov test — statistical test for whether two distributions differ.
KL Divergence
Kullback-Leibler divergence — measures how one probability distribution diverges from another.
CSI
Characteristic Stability Index — the per-feature version of PSI.
Data Drift
A change in the distribution of input features over time.
Concept Drift
A change in the underlying data-generating process.
Centroid Drift
Movement of a centroid between training and production.
Assignment Drift
Change in how points are distributed across clusters.
CUSUM
Cumulative Sum Control Chart — sequential analysis for change detection.
MLOps
Machine Learning Operations — deploying and monitoring ML in production.
Shadow Deployment
Running a new model alongside the old one without acting on its output.
Champion / Challenger
The current production model vs. a candidate model.
