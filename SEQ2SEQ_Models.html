Sequence-to-Sequence (Seq2Seq) models transform one sequence into another using an encoder-decoder framework. 📊 Seq2Seq with Attention overview — encoder, attention mechanism, and autoregressive decoder

🎯

① Attention Heads (num_heads)

Number of parallel attention mechanisms. Each head attends to different representation subspaces, enabling the model to capture diverse token relationships.

class MultiHeadAttention(nn.Module):
self.num_heads = 8
self.d_k = d_model // num_heads
💡Use 8 heads for base models. Ensure d_model is divisible by num_heads (e.g., 512/8=64).
🏢

② Model Depth (Encoder/Decoder Layers)

Number of stacked encoder and decoder layers. More layers increase representational capacity but also training time and overfitting risk.

# Transformer base: 6 encoder + 6 decoder layers
num_encoder_layers = 6
num_decoder_layers = 6
✅6/6 is the classic Transformer-base config. GPT-style decoder-only models use 12–96 layers.
📐

③ Embedding Size (d_model)

Dimensionality of token embeddings and all sub-layer outputs. Larger d_model captures richer representations at the cost of memory and compute.

# Transformer base vs big
d_model_base = 512 # ~65M params
d_model_big = 1024 # ~213M params
💡Common values: 256 (small), 512 (base), 768 (BERT-base), 1024 (big), 4096+ (LLMs).
🎲

④ Dropout Rate

Applied to attention weights, residual connections, and feed-forward outputs. Crucial for preventing overfitting in Seq2Seq models.

# Applied after every sub-layer
dropout = 0.1 # Typical for Transformer-base
x = self.dropout(sublayer_output) + x # residual
✅0.1 is the standard for Transformer-base. Increase to 0.2–0.3 for smaller datasets.
🎯

⑤ Learning Rate

The most critical hyperparameter. Transformers use a specialized schedule: linear warmup followed by inverse-square-root decay.

def transformer_lr(step, d_model, warmup):
return d_model**-0.5 * min(step**-0.5, step * warmup**-1.5)
💡Peak LR of ~0.0007 for base Transformer. Without warmup, training often diverges.
📦

⑥ Batch Size

Number of source-target sequence pairs per update. Transformers benefit from large batches but require gradient accumulation on memory-limited hardware.

# Token-level batching: ~25k source + 25k target tokens per batch
batch_size = 64 # sequence pairs
# Or use dynamic batching by token count
max_tokens_per_batch = 4096
⚠️Too-small batches cause noisy gradients. Use gradient accumulation to simulate larger effective batch sizes.
🔥

⑦ Warmup Steps

Number of initial training steps where the learning rate linearly increases from 0 to the peak value. Essential for Transformer stability.

# Typical warmup: 4000 steps for Transformer-base
warmup_steps = 4000
lr = d_model**-0.5 * min(step**-0.5, step * warmup**-1.5)
✅Start with 4000 warmup steps. For fine-tuning pretrained models, use 0–500 warmup steps.
🔧

⑧ Optimizer

Adam is the standard optimizer for Transformers, with specific β values (β₁=0.9, β₂=0.98, ε=10⁻⁹) recommended in the original paper.

# Original Transformer optimizer
optimizer = AdamW(lr=lr_schedule, betas=(0.9, 0.98), eps=1e-9)
💡AdamW (Adam with decoupled weight decay) is preferred in modern implementations (HuggingFace, PyTorch).
📏

⑨ Maximum Sequence Length

Limits input and output sequence length. Longer sequences allow more context but quadratic attention cost (O(n²)) makes this expensive.

# Typical values for different tasks
max_src_len = 512 # Machine translation
max_tgt_len = 512
max_len = 2048 # GPT-style models
⚠️Self-attention is O(n²·d). Doubling sequence length quadruples compute and memory for attention.
📉

⑩ Loss Function & Label Smoothing

Cross-entropy loss with optional label smoothing. Smoothing prevents the model from becoming overconfident, improving generalization and BLEU scores.

# Label smoothing in cross-entropy
loss_fn = CrossEntropyLoss(label_smoothing=0.1)
# ε=0.1 means: target prob = 0.9 for correct, 0.1/(V-1) for others
💡ε=0.1 label smoothing improves BLEU by ~0.5–1.0 points. Use 0.0 for tasks requiring sharp probability estimates.

🏗️ Seq2Seq Architecture & Attention Mechanism

The Seq2Seq model consists of an encoder that processes the source sequence, an attention mechanism that computes context vectors, and a decoder that autoregressively generates the target sequence. Modern implementations use the Transformer architecture with multi-head self-attention and cross-attention.

🔬 Core Attention & Seq2Seq Equations
Scaled Dot-Product Attention:
Attention(Q,K,V) = softmax(QKT / √dk) V
Multi-Head Attention:
MultiHead(Q,K,V) = Concat(head1, …, headh) WO
where headi = Attention(QWQi, KWKi, VWVi)
Encoder Self-Attention:
zi = LayerNorm(MultiHead(xi, x≤i, x≤i) + xi)
Decoder Cross-Attention:
ct = MultiHead(st, henc, henc)
Query from decoder, Key/Value from encoder

📖 Architecture Element Breakdown — Every component explained

Understanding each component of the attention mechanism and encoder-decoder architecture is essential for tuning Seq2Seq models effectively.

🔹 Scaled Dot-Product Attention
Q (Query)
The vector representing "what am I looking for?" — derived from the current decoder state or target token.
Shape: (batch, seq_len, d_k)
K (Key)
The vector representing "what can I match against?" — derived from encoder outputs for cross-attention.
Shape: (batch, src_len, d_k)
V (Value)
The actual information to aggregate. Weighted by attention scores to produce the context vector.
Shape: (batch, src_len, d_v)
√dk
Scaling factor to prevent dot products from growing too large. Without it, softmax saturates and gradients vanish.
Scalar: d_k = d_model / num_heads
softmax(·)
Converts raw attention scores into a probability distribution over source positions, summing to 1.
Output: (batch, seq_len, src_len)
WQ, WK, WV
Learned projection matrices that map inputs into query, key, and value subspaces for each attention head.
Shape: (d_model, d_k) each
🔹 Multi-Head & Encoder-Decoder Components
num_heads (h)
Number of parallel attention heads. Each head learns different token relationship patterns (syntax, semantics, position).
Typical: 8 (base), 16 (large)
WO
Output projection matrix that combines all head outputs back into d_model dimensions.
Shape: (h·d_v, d_model)
Encoder (BiLSTM/Transformer)
Processes source sequence bidirectionally (or with unmasked self-attention) to create contextualized representations.
Output: (batch, src_len, d_model)
Decoder (LSTM/Autoregressive)
Generates target tokens one-by-one using masked self-attention (prevents peeking at future tokens) + cross-attention to encoder outputs.
Uses causal/masked attention
🔹 Positional Encoding & Feed-Forward
PE(pos,2i)
Sinusoidal positional encoding: sin(pos/100002i/d_model) for even indices, cos for odd. Adds sequence order information.
Shape: (max_len, d_model)
FFN(x)
Position-wise feed-forward network: FFN(x) = ReLU(xW₁ + b₁)W₂ + b₂. Applied identically to each position.
d_ff = 2048 (4× d_model for base)
💡 Key insight: The Transformer's power comes from multi-head attention allowing each token to directly attend to every other token in O(1) path length, unlike RNNs' O(n) sequential path.
🔍

Self-Attention vs Cross-Attention

Self-attention: Q, K, V all from the same sequence (encoder or decoder). Cross-attention: Q from decoder, K, V from encoder — this is where source-target alignment happens.

💡Masked self-attention in the decoder prevents the model from seeing future tokens during autoregressive generation.
🔄

Residual Connections + LayerNorm

Every sub-layer (attention and FFN) uses residual connections followed by layer normalization: Output = LayerNorm(x + Sublayer(x)).

✅Pre-LN (LayerNorm before sublayer) is now preferred over post-LN for training stability in deep Transformers.

⚡ Training Process Hyperparameters

These settings govern how the Seq2Seq model learns alignments and generates fluent target sequences.

🎯

Learning Rate Schedule

The Transformer uses a warmup-then-decay schedule. Without warmup, training often diverges in early steps due to large gradient variance.

class TransformerLR:
def __call__(self, step):
arg1 = step ** -0.5
arg2 = step * self.warmup ** -1.5
return self.d_model**-0.5 * min(arg1, arg2)
✅The LR peaks at warmup_steps then decays. This is the single most important training trick for Transformers.
📦

Token-Based Batching

Group sequences by approximate length to minimize padding waste. Dynamic batching maximizes GPU utilization.

# Bucket sequences by length, batch ~4096 tokens
bucket_boundaries = [16, 32, 64, 128, 256]
batch_size_by_bucket = [256, 128, 64, 32, 16]
📊

Gradient Accumulation

Simulates larger batches by accumulating gradients over multiple mini-batches before each optimizer step. Essential for GPU-limited setups.

# Effective batch = batch_size × accum_steps
accumulation_steps = 4
if (step + 1) % accumulation_steps == 0:
optimizer.step()
optimizer.zero_grad()
🏷️

Label Smoothing

Softens one-hot targets to prevent overconfidence. The model assigns ε probability mass to incorrect classes, improving generalization.

# Label smoothing ε=0.1
smooth_target = (1.0 - 0.1) * one_hot + 0.1 / vocab_size
loss = -sum(smooth_target * log(probs))

🛡️ Regularization & Tuning Techniques

Use these techniques to prevent overfitting and improve Seq2Seq generalization.

🎲

Dropout (Attention + Residual)

Dropout is applied to attention weights, residual connections, and FFN outputs. It is the primary regularizer for Transformers.

# Three dropout locations in each Transformer sub-layer
attn_weights = dropout(attn_weights) # attention dropout
sublayer_out = dropout(sublayer(x)) # residual dropout
ffn_out = dropout(self.ffn(x)) # FFN dropout
💡Standard dropout=0.1. For small datasets (<100k examples), increase to 0.2–0.3.
🏷️

Label Smoothing

Reduces model overconfidence by softening targets. Crucial for translation tasks — improves BLEU by preventing peaky distributions.

# PyTorch built-in label smoothing
loss_fn = nn.CrossEntropyLoss(label_smoothing=0.1)
✅ε=0.1 is standard. Label smoothing also helps calibration — predicted probabilities better reflect real accuracy.
⚖️

Weight Decay (L2 Regularization)

Adds an L2 penalty to prevent weights from growing too large. AdamW decouples weight decay from adaptive learning rates.

# AdamW with weight decay
optimizer = AdamW(params, lr=lr, weight_decay=0.01)
💡Weight decay of 0.01–0.1 is common. Larger models often need smaller weight decay values.
📏

Layer Normalization

Normalizes activations across the feature dimension. Essential for stable Transformer training — used after every sub-layer.

# Pre-LN: normalize before sublayer (modern default)
x = x + sublayer(layer_norm(x))
# Post-LN: normalize after (original paper)
x = layer_norm(x + sublayer(x))
✅Pre-LN (norm first) is more stable for deep models and is the default in most modern implementations.

4000 # ⑦ LR warmup steps batch_size = 64 # ⑥ Batch size (sequence pairs) label_smooth = 0.1 # ⑩ Label smoothing epsilon class PositionalEncoding(nn.Module): def __init__(self, d_model, max_len=512): super().__init__() pe = torch.zeros(max_len, d_model) pos = torch.arange(0, max_len).unsqueeze(1).float() div = torch.exp(torch.arange(0, d_model, 2).float() * -(math.log(10000.0) / d_model)) pe[:, 0::2] = torch.sin(pos * div) pe[:, 1::2] = torch.cos(pos * div) self.register_buffer('pe', pe.unsqueeze(0)) def forward(self, x): return x + self.pe[:, :x.size(1)] class MultiHeadAttention(nn.Module): def __init__(self, d_model, num_heads, dropout): super().__init__() assert d_model % num_heads == 0 self.d_k = d_model // num_heads self.num_heads = num_heads self.W_q = nn.Linear(d_model, d_model) self.W_k = nn.Linear(d_model, d_model) self.W_v = nn.Linear(d_model, d_model) self.W_o = nn.Linear(d_model, d_model) self.dropout = nn.Dropout(dropout) def forward(self, Q, K, V, mask=None): batch = Q.size(0) # Linear projections + reshape for multi-head Q = self.W_q(Q).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2) K = self.W_k(K).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2) V = self.W_v(V).view(batch, -1, self.num_heads, self.d_k).transpose(1, 2) # Scaled dot-product attention scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k) if mask is not None: scores = scores.masked_fill(mask == 0, -1e9) attn = self.dropout(torch.softmax(scores, dim=-1)) out = torch.matmul(attn, V) # Concatenate heads + output projection out = out.transpose(1, 2).contiguous().view(batch, -1, d_model) return self.W_o(out) class TransformerEncoderLayer(nn.Module): def __init__(self, d_model, num_heads, d_ff, dropout): super().__init__() self.self_attn = MultiHeadAttention(d_model, num_heads, dropout) self.ffn = nn.Sequential( nn.Linear(d_model, d_ff), nn.ReLU(), nn.Dropout(dropout), nn.Linear(d_ff, d_model) ) self.norm1 = nn.LayerNorm(d_model) self.norm2 = nn.LayerNorm(d_model) self.dropout1 = nn.Dropout(dropout) self.dropout2 = nn.Dropout(dropout) def forward(self, x, mask=None): x = x + self.dropout1(self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), mask)) x = x + self.dropout2(self.ffn(self.norm2(x))) return x class TransformerDecoderLayer(nn.Module): def __init__(self, d_model, num_heads, d_ff, dropout): super().__init__() self.self_attn = MultiHeadAttention(d_model, num_heads, dropout) self.cross_attn = MultiHeadAttention(d_model, num_heads, dropout) self.ffn = nn.Sequential( nn.Linear(d_model, d_ff), nn.ReLU(), nn.Dropout(dropout), nn.Linear(d_ff, d_model) ) self.norm1 = nn.LayerNorm(d_model) self.norm2 = nn.LayerNorm(d_model) self.norm3 = nn.LayerNorm(d_model) self.dropout1 = nn.Dropout(dropout) self.dropout2 = nn.Dropout(dropout) self.dropout3 = nn.Dropout(dropout) def forward(self, x, enc_out, src_mask=None, tgt_mask=None): x = x + self.dropout1(self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), tgt_mask)) x = x + self.dropout2(self.cross_attn(self.norm2(x), enc_out, enc_out, src_mask)) x = x + self.dropout3(self.ffn(self.norm3(x))) return x class Seq2SeqTransformer(nn.Module): def __init__(self, src_vocab, tgt_vocab, d_model, num_heads, num_layers, d_ff, dropout, max_seq_len): self.encoder_layers = nn.ModuleList([ TransformerEncoderLayer(d_model, num_heads, d_ff, dropout) for _ in range(num_layers) ]) self.decoder_layers = nn.ModuleList([ TransformerDecoderLayer(d_model, num_heads, d_ff, dropout) for _ in range(num_layers) ]) self.output_proj = nn.Linear(d_model, tgt_vocab) self.dropout = nn.Dropout(dropout) def forward(self, src, tgt, src_mask=None, tgt_mask=None): src = self.dropout(self.pos_encoding(self.encoder_embed(src))) for layer in self.encoder_layers: src = layer(src, src_mask) tgt = self.dropout(self.pos_encoding(self.decoder_embed(tgt))) for layer in self.decoder_layers: tgt = layer(tgt, src, src_mask, tgt_mask) return self.output_proj(tgt) # ═══════════════════════════════════════════════ # TRAINING SETUP # rate: warmup + inverse-sqrt decay class TransformerLR(torch.optim.lr_scheduler._LRScheduler): def __init__(self, optimizer, d_model, warmup_steps): self.d_model = d_model self.warmup = warmup_steps
