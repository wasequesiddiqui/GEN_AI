① Bias in Training Data

Historical biases in training data are the primary source of AI unfairness. Models learn and amplify patterns present in the data they are trained on.

# Check for representation imbalance
import pandas as pd
df.groupby('protected_attribute').size().plot(kind='bar')
⚠️Even large datasets can contain systematic biases. Always audit data distributions across demographic groups.
🎯

② Fairness Metrics

Quantitative measures to assess whether a model treats different groups equitably. Common metrics include demographic parity, equalized odds, and equal opportunity.

from fairlearn.metrics import demographic_parity_difference
dp_diff = demographic_parity_difference(y_true, y_pred, sensitive_features=groups)
💡Use multiple fairness metrics — no single metric captures all aspects of fairness.

③ Transparency & Explainability

The ability to understand and interpret how an AI system makes decisions. Black-box models create accountability gaps that undermine trust.

⑤ Privacy & Data Protection

AI systems often process sensitive personal data. Privacy-preserving techniques like differential privacy and federated learning are essential.

🏗️ Ethical AI — Foundational Frameworks

Ethical AI rests on well-established principles and mathematical formulations. These frameworks provide the vocabulary and metrics for evaluating AI systems.

⚖️ Core Fairness Equations
Demographic Parity:
|P(ŷ=1 | G=a) − P(ŷ=1 | G=b)| ≤ ε
Equalized Odds:
|P(ŷ=1 | Y=y, G=a) − P(ŷ=1 | Y=y, G=b)| ≤ ε   ∀y
Differential Privacy (ε):
P(M(D) ∈ S) ≤ eε · P(M(D′) ∈ S) + δ
AI Ethics Principle:
Ethical AI = Fairness + Transparency + Accountability + Privacy + Safety

📖 Ethics Framework — Term Breakdown

Each ethical principle has a measurable dimension. Understanding these terms is essential for the CGAI exam.

🔹 Fairness Metrics
Demographic Parity
Requires equal prediction rates across groups regardless of ground truth. Simplest fairness metric but may ignore merit-based differences.
Threshold: gap ≤ 0.05 typically
Equalized Odds
Requires equal TPR and FPR across groups. More nuanced than demographic parity — balances fairness with accuracy.
Both TPR & FPR gaps ≤ ε
Equal Opportunity
Equal TPR across groups: P(ŷ=1|Y=1,G=a) = P(ŷ=1|Y=1,G=b). Focuses on qualified individuals.
Only TPR gap constrained
Individual Fairness
Similar individuals should receive similar predictions: D(f(xᵢ), f(xⱼ)) ≤ d(xᵢ, xⱼ). Harder to formalize.
Requires task-specific metric d(·,·)
🔹 Privacy & Safety
ε (Privacy Budget)
Controls the strength of differential privacy. Lower ε = stronger privacy. Typical range: 0.1–10.
ε ≤ 1: strong; ε ≤ 10: moderate
δ (Failure Probability)
Probability that the privacy guarantee fails. Should be cryptographically small: δ ≪ 1/N.
Typically δ ≤ 10⁻⁵
Adversarial Robustness
Model stability under perturbed inputs: argmax f(x+δ) = argmax f(x) for small ‖δ‖. Critical for safety.
ε-perturbation bounded
💡 Key insight: Ethical AI is not a single metric — it's a multi-dimensional framework requiring tradeoffs between fairness, accuracy, privacy, and transparency.

⚡ Implementing Ethical AI

Practical steps to integrate ethics into the AI development lifecycle — from data collection through deployment.

📊

Bias Audit Pipeline

Systematically evaluate training data and model outputs for bias across protected attributes before deployment.

def bias_audit(model, data, groups):
preds = model.predict(data)
for g in groups.unique():
mask = groups == g
print(f"Group {g}: accuracy={accuracy(preds[mask], y[mask]):.3f}")
✅Audit at multiple stages: pre-training (data), during training (gradients), and post-training (predictions).
🔄

Fairness-Aware Training

Incorporate fairness constraints directly into the training objective. Penalize the model when predictions diverge across protected groups.

def fairness_loss(preds, groups):
gap = demographic_parity_difference(preds, groups)
return task_loss + λ * gap

Create standardized documentation covering intended use, out-of-scope applications, training data provenance, and fairness evaluation results.

🛡️ Bias Mitigation Strategies

Proven techniques to reduce bias and improve fairness at every stage of the AI pipeline.

🧹

Pre-processing: Data Reweighting

Adjust sample weights to balance representation across groups. Underrepresented groups get higher weights during training.

from sklearn.utils import compute_sample_weight
weights = compute_sample_weight(class_weight='balanced', y=groups)
model.fit(X, y, sample_weight=weights)
💡Combine reweighting with stratified sampling for maximum pre-processing fairness.
⚡

In-processing: Adversarial Debiasing

Train an adversary to predict protected attributes; penalize the main model when the adversary succeeds. Forces group-invariant representations.

class GradientReversal(torch.autograd.Function):
def forward(ctx, x): return x
def backward(ctx, grad): return -grad
📉

Post-processing: Threshold Adjustment

Adjust decision thresholds per group to equalize fairness metrics. Simple but effective when retraining isn't possible.

def fair_thresholds(probs, groups, target='demographic_parity'):
for g in groups.unique():
thresholds[g] = optimize_threshold(probs[groups==g], target)
🔄

Continuous Monitoring

Model fairness degrades over time as data distributions shift. Implement automated monitoring dashboards to track fairness metrics in production.

def monitor_fairness(predictions, groups, window=1000):
dp_gap = demographic_parity_difference(predictions[-window:], groups[-window:])
if dp_gap > 0.05: trigger_alert(dp_gap)
⚠️Set up automatic alerts when fairness metrics drift beyond acceptable thresholds.

FAIRNESS-AWARE TRAINING LOOP # ══════════════════════════════════════════ model = FairClassifier(input_dim=50) task_criterion = nn.BCEWithLogitsLoss() fairness_criterion = nn.CrossEntropyLoss() optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3) for epoch in range(50): for x_batch, y_batch, g_batch in dataloader: task_pred, group_pred = model(x_batch) task_loss = task_criterion(task_pred.squeeze(), y_batch) fair_loss = fairness_criterion(group_pred, g_batch) total_loss = task_loss + fair_loss # Minimize both optimizer.zero_grad() total_loss.backward() optimizer.step() # ══════════════════════════════════════════ # 4. POST-TRAINING FAIRNESS AUDIT # ══════════════════════════════════════════ model.eval() with torch.no_grad(): all_preds, all_groups = [], [] for x_batch, _, g_batch in test_loader: task_pred, _ = model(x_batch) all_preds.extend((torch.sigmoid(task_pred) > 0.5).int().tolist()) all_groups.extend(g_batch.tolist()) dp_gap = demographic_parity_difference( y_true=[0]*len(all_preds), y_pred=all_preds, sensitive_features=all_groups ) print(f"✅ Demographic Parity Gap: {dp_gap:.4f}") print(f"⚖️ Fairness check: {'PASS' if dp_gap < 0.05 else 'FAIL — needs mitigation'}")
