Basics of Natural Language Generation – Hyperparameters

Master the transformer decoder hyperparameters that power modern text generation — from attention heads to warmup schedules.

Natural Language Generation (NLG) uses autoregressive transformer decoders to produce coherent, context-aware text. This guide covers the 10 most important hyperparameters for NLG models, from attention heads and embedding size to learning rate warmup and label smoothing, with practical PyTorch examples and a runnable GPT-style training demo.

🔍

① Attention Heads

Number of parallel attention heads in each multi-head attention layer. More heads capture more diverse token relationships.

from torch.nn import MultiheadAttention
attn = MultiheadAttention(embed_dim=512, num_heads=8)
💡Use 8–16 heads. Embedding dimension must be divisible by num_heads. GPT-2 uses 12–16 heads per layer.
🏢

② Model Depth (Decoder Layers)

Number of stacked transformer decoder blocks. Deeper models learn richer linguistic representations but are harder to train.

# GPT-2 Small: 12 layers, GPT-2 XL: 48 layers
num_decoder_layers = 12
decoder = nn.TransformerDecoder(
decoder_layer, num_layers=num_decoder_layers)
✅6–12 layers for small models; 24–48 for large. Depth correlates strongly with NLG quality.
📐

③ Embedding Size (d_model)

Dimensionality of token embeddings and hidden states throughout the decoder. Larger embeddings capture more nuanced semantics.

class GPTConfig:
vocab_size = 50257
n_embd = 768 # GPT-2 Small
💡Common sizes: 512 (small), 768 (GPT-2), 1024 (GPT-2 Medium), 1600 (GPT-2 XL). Scale d_model with num_heads.
🎲

④ Dropout Rate

Probability of dropping activations during training. Applied to attention weights, residual connections, and embeddings.

config = GPTConfig(
embd_pdrop=0.1,
attn_pdrop=0.1,
resid_pdrop=0.1)
💡GPT-2 uses 0.1 dropout throughout. For smaller datasets, increase to 0.2–0.3 to prevent overfitting.
🎯

⑤ Learning Rate

The peak learning rate after warmup. Transformer decoders are sensitive to LR — too high causes instability, too low stalls learning.

# GPT-2: peak LR = 6e-4 (AdamW)
optimizer = AdamW(
model.parameters(), lr=6e-4,
betas=(0.9, 0.95))
⚠️GPT uses 6e-4; for smaller models start at 3e-4. Too high causes loss spikes in transformer decoders.
📦

⑥ Batch Size

Number of sequences per gradient update. NLG models benefit from large batches for stable gradient estimates.

# GPT-2: batch_size=512 sequences
dataloader = DataLoader(
dataset, batch_size=64,
shuffle=True)
💡Use 32–128 per GPU. Combine with gradient accumulation to simulate larger effective batch sizes (e.g., 512).
🔥

⑦ Warmup Steps

Gradually increases the learning rate from near-zero to the peak value. Critical for transformer stability early in training.

def lr_schedule(step):
if step < WARMUP_STEPS:
return peak_lr * step / WARMUP_STEPS
return peak_lr * decay_factor
✅GPT uses 2000–4000 warmup steps. Without warmup, transformer decoders often diverge in the first few hundred steps.
🔧

⑧ Optimizer (AdamW)

AdamW decouples weight decay from the Adam update, improving generalization. The standard optimizer for GPT-style NLG models.

from torch.optim import AdamW
optimizer = AdamW(
model.parameters(),
lr=6e-4,
weight_decay=0.1,
betas=(0.9, 0.95))
💡AdamW with β1=0.9, β2=0.95 is standard for GPT. Weight decay of 0.1 controls overfitting in large models.
📏

⑨ Sequence Length (Context Window)

Maximum token length processed by the model. Longer contexts capture more text but increase memory quadratically (O(n²) due to attention).

# GPT-2: 1024 token context; GPT-3: 2048
block_size = 1024
# Positional embeddings must match
pos_emb = nn.Embedding(block_size, n_embd)
⚠️Memory scales with O(n²) in attention. Use 256–512 for smaller models; 1024–2048 for production NLG.
📉

⑩ Loss Function (Cross-Entropy + Label Smoothing)

Next-token prediction uses cross-entropy loss. Label smoothing prevents overconfidence by softening the target distribution.

import torch.nn.functional as F
loss = F.cross_entropy(
logits.view(-1, vocab_size),
targets.view(-1),
label_smoothing=0.1)
💡Label smoothing of 0.1 is common. It distributes 10% of the probability mass uniformly across non-target tokens, improving calibration.

🏗️ NLG Transformer Decoder Architecture

Modern NLG models use a stack of transformer decoder blocks. Each block applies masked self-attention followed by a feed-forward network, with residual connections and layer normalization. The causal mask ensures each token only attends to previous tokens, enabling autoregressive generation.

📐 NLG Core Equations
Scaled Dot-Product Attention:
Attention(Q,K,V) = softmax(QKT/√dk + Mask) V
Multi-Head Attention:
MultiHead(Q,K,V) = Concat(head1, …, headh) WO
Autoregressive Probability:
P(x) = ∏t=1T P(xt | x1, …, xt-1)
Feed-Forward Network (FFN):
FFN(x) = W2·GELU(W1x + b1) + b2

📖 Equation Element Breakdown – What every symbol means

Understanding the attention mechanism and autoregressive structure is key to tuning NLG model performance.

🔹 Attention Mechanism
Q, K, V
Query, Key, Value matrices — all derived from the same input through learned linear projections WQ, WK, WV.
Shape: (batch, seq_len, d_k). d_k = d_model / num_heads
QKT/√dk
Scaled dot-product. The scaling factor √dk prevents large dot products from pushing softmax into saturated regions.
Output: (batch, num_heads, seq_len, seq_len) attention matrix
Causal Mask
Upper-triangular matrix of −∞ values that prevents token t from attending to tokens > t. Enforces autoregressive property.
Shape: (seq_len, seq_len). mask[i,j] = −∞ if j > i
softmax(·)
Converts raw attention scores into a probability distribution over previous tokens. Each row sums to 1.
Applied row-wise along the last dimension
🔹 Multi-Head & FFN
headi
Output of the i-th attention head, computed with its own Q,K,V projections. Each head learns distinct token relationships.
Shape: (batch, seq_len, d_k). d_k = d_model / num_heads
WO
Output projection matrix that combines all head outputs back into d_model space. Learned during training.
Shape: (d_model, d_model)
GELU
Gaussian Error Linear Unit — the activation used in GPT's FFN. Smoother than ReLU, better for transformer training.
GELU(x) = x·Φ(x) where Φ is the standard Gaussian CDF
Autoregressive P(x)
The joint probability is factorized as a product of conditional next-token probabilities. Each step depends on all previous tokens.
Chain rule: P(x₁,…,x_T) = ∏ P(x_t | x_{
🔹 Residual & Normalization
Residual Connection
Adds the input of a sublayer to its output: out = x + Sublayer(LayerNorm(x)). Enables training of very deep transformers.
Identity shortcut preserves gradient flow through deep networks
LayerNorm
Normalizes activations across the feature dimension. Pre-LN (applied before attention/FFN) is more stable than Post-LN.
Normalizes over d_model features per token position
💡 Key insight: The causal mask is what makes the decoder autoregressive — without it, attention would be bidirectional (like BERT's encoder) and the model couldn't generate text left-to-right.
🔍

Decoder-Only Architecture

GPT models use decoder-only transformers — no encoder stack. The decoder handles both representation learning and generation in a single stack of layers.

💡Decoder-only is simpler than encoder-decoder (T5, BART) and scales better for pure generation tasks.
🔄

Autoregressive Generation

During inference, tokens are generated one at a time, with each new token appended to the context for predicting the next. This sequential process defines NLG.

💡Use temperature, top-k, and top-p (nucleus) sampling to control generation diversity vs. determinism.

⚡ Training Process Hyperparameters

NLG training uses teacher forcing and careful learning rate scheduling to stabilize the autoregressive objective.

🎯

Learning Rate Schedule

Linear warmup followed by cosine or linear decay. The schedule is as important as the peak LR value for transformer convergence.

# Cosine decay after warmup
scheduler = CosineAnnealingLR(
optimizer, T_max=max_steps - warmup)
✅GPT uses: warmup for 2000 steps to 6e-4, then cosine decay to 10% of peak by the end of training.
📝

Teacher Forcing

During training, the ground-truth previous tokens are fed as input regardless of model predictions. This stabilizes early training.

# Teacher forcing: use real targets as input
def train_step(x):
# x = [t0, t1, t2, ..., tn]
logits = model(x[:-1]) # predict next token
loss = CE(logits, x[1:]) # compare with actual next
⚠️Teacher forcing creates a train-inference mismatch. Scheduled sampling can help bridge the gap for seq2seq models.
📦

Gradient Accumulation

Simulates larger batch sizes by accumulating gradients over multiple micro-batches before updating weights. Essential for GPU-memory-constrained NLG training.

# Accumulate over 4 micro-batches for effective BS=256
micro_batch = 64
accum_steps = 4
loss = loss / accum_steps
loss.backward()
if (step + 1) % accum_steps == 0: optimizer.step()
💡Effective batch = micro_batch × accum_steps. GPT-2 used ~512; GPT-3 used millions of tokens per batch.
🔧

Mixed Precision Training (FP16/BF16)

Uses half-precision floating point to reduce memory and speed up training. Nearly all modern NLG models train with mixed precision.

from torch.cuda.amp import autocast, GradScaler
scaler = GradScaler()
with autocast():
loss = model(x)
scaler.scale(loss).backward()

🛡️ Regularization & Tuning Techniques

Transformer decoders are prone to overfitting on small datasets. These techniques improve generalization and calibration.

🏷️

Label Smoothing

Softens the one-hot target distribution, distributing probability mass to non-target tokens. Improves calibration and reduces overconfidence.

# Label smoothing: ε=0.1
# P'(x_t = w) = (1-ε) if w is target else ε/(V-1)
loss = F.cross_entropy(
logits, targets,
label_smoothing=0.1)
💡ε=0.1 is standard. Larger values (0.2) for small datasets. Helps with perplexity and BLEU scores.
⚖️

Weight Decay

AdamW's decoupled weight decay penalizes large weights without interfering with the adaptive learning rate. Crucial for NLG generalization.

# AdamW decouples weight decay from Adam
optimizer = AdamW(
model.parameters(),
weight_decay=0.1) # GPT-2 standard
⚠️Standard Adam's L2 regularization is not equivalent to weight decay. Always use AdamW for transformer NLG.
✂️

Dropout Placement

Dropout is applied at three points in GPT: embedding dropout, attention dropout (on softmax weights), and residual dropout (after each sublayer).

# Three dropout rates in GPT-style models
embd_dropout = 0.1 # After token+position embeddings
attn_dropout = 0.1 # Within attention softmax
resid_dropout = 0.1 # After each residual connection
✅Keep all three dropout rates equal (0.1). On very small datasets, increase to 0.2–0.3.
📏

Gradient Clipping

Clips gradients to a maximum norm to prevent loss spikes. Standard for training large transformer decoders stably.

# Clip gradients to max norm of 1.0
torch.nn.utils.clip_grad_norm_(
model.parameters(),
max_norm=1.0)
💡max_norm=1.0 is the GPT standard. Monitor gradient norms — if spikes occur, lower to 0.5.

💻 Full Code – GPT-Style Text Generation with PyTorch

A minimal GPT decoder training script. All hyperparameters annotated with numbered labels matching the cards above.

#!/usr/bin/env python3 """Minimal GPT-style text generation – all hyperparameters labeled.""" import torch import torch.nn as nn import torch.nn.functional as F from torch.optim import AdamW # ── Hyperparameter Configuration ── VOCAB_SIZE = 50257 # GPT-2 vocabulary size N_EMBD = 768 # ③ Embedding dimension (d_model) N_HEAD = 12 # ① Number of attention heads N_LAYER = 12 # ② Decoder layers (depth) BLOCK_SIZE = 1024 # ⑨ Maximum sequence length DROPOUT = 0.1 # ④ Dropout rate PEAK_LR = 6e-4 # ⑤ Peak learning rate BATCH_SIZE = 64 # ⑥ Batch size WARMUP_STEPS = 2000 # ⑦ LR warmup steps WEIGHT_DECAY = 0.1 # ⑧ Weight decay (AdamW) LABEL_SMOOTH = 0.1 # ⑩ Label smoothing ε class CausalSelfAttention(nn.Module): def __init__(self): super().__init__() assert N_EMBD % N_HEAD == 0 self.c_attn = nn.Linear(N_EMBD, 3 * N_EMBD) # Q, K, V projection self.c_proj = nn.Linear(N_EMBD, N_EMBD) # Output projection W^O self.attn_dropout = nn.Dropout(DROPOUT) self.resid_dropout = nn.Dropout(DROPOUT) # Causal mask (upper triangular −∞) self.register_buffer("bias", torch.tril(torch.ones(BLOCK_SIZE, BLOCK_SIZE)) .view(1, 1, BLOCK_SIZE, BLOCK_SIZE)) def forward(self, x): B, T, C = x.size() qkv = self.c_attn(x).split(N_EMBD, dim=2) q, k, v = [t.view(B, T, N_HEAD, C // N_HEAD).transpose(1, 2) for t in qkv] att = (q @ k.transpose(-2, -1)) * (1.0 / ((C // N_HEAD) ** 0.5)) # Scale by 1/√d_k att = att.masked_fill(self.bias[:,:,:T,:T] == 0, float('-inf')) # Causal mask att = F.softmax(att, dim=-1) att = self.attn_dropout(att) y = att @ v y = y.transpose(1, 2).contiguous().view(B, T, C) return self.resid_dropout(self.c_proj(y)) class GPTBlock(nn.Module): def __init__(self): super().__init__() self.ln_1 = nn.LayerNorm(N_EMBD) self.attn = CausalSelfAttention() self.ln_2 = nn.LayerNorm(N_EMBD) self.mlp = nn.Sequential( nn.Linear(N_EMBD, 4 * N_EMBD), nn.GELU(), nn.Linear(4 * N_EMBD, N_EMBD), nn.Dropout(DROPOUT), ) def forward(self, x): x = x + self.attn(self.ln_1(x)) # Residual + attention x = x + self.mlp(self.ln_2(x)) # Residual + FFN return x class GPT(nn.Module): def __init__(self): super().__init__() self.tok_emb = nn.Embedding(VOCAB_SIZE, N_EMBD) self.pos_emb = nn.Embedding(BLOCK_SIZE, N_EMBD) self.drop = nn.Dropout(DROPOUT) self.blocks = nn.Sequential(*[GPTBlock() for _ in range(N_LAYER)]) self.ln_f = nn.LayerNorm(N_EMBD) self.lm_head = nn.Linear(N_EMBD, VOCAB_SIZE, bias=False) def forward(self, idx): B, T = idx.shape tok_emb = self.tok_emb(idx) pos_emb = self.pos_emb(torch.arange(T, device=idx.device)) x = self.drop(tok_emb + pos_emb) x = self.blocks(x) x = self.ln_f(x) return self.lm_head(x) model = GPT() optimizer = AdamW(model.parameters(), lr=PEAK_LR, betas=(0.9, 0.95), weight_decay=WEIGHT_DECAY) # ── ⑦ LR schedule: linear warmup → cosine decay ── def get_lr(step): if step < WARMUP_STEPS: return PEAK_LR * step / WARMUP_STEPS progress = (step - WARMUP_STEPS) / (max_steps - WARMUP_STEPS) return PEAK_LR * 0.5 * (1.0 + math.cos(math.pi * progress)) # ── Training loop ── for step, (x,) in enumerate(dataloader): lr = get_lr(step) for param_group in optimizer.param_groups: param_group['lr'] = lr logits = model(x[:, :-1]) # Predict next token loss = F.cross_entropy( # ⑩ Cross-entropy loss logits.reshape(-1, VOCAB_SIZE), x[:, 1:].reshape(-1), label_smoothing=LABEL_SMOOTH) optimizer.zero_grad() loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0) optimizer.step() print(f"Step {step} | Loss: {loss:.4f} | LR: {lr:.2e}")

⬆️ Complete GPT decoder training loop. All ⑩ hyperparameters annotated. Causal masking + GELU activation + Pre-LN architecture.
