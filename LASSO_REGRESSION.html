1 Algorithm Description

Real-life analogy: Imagine a hiring committee with 100 applicants. A naive manager (OLS) would give every applicant a little bit of the workload — even the useless ones. A ruthless manager (Lasso) says: "If you don't add real value, you're out." The final team is small, focused, and every member earns their spot. That's Lasso — it selects the few features that matter and sets the rest to exactly zero.

What is Lasso Regression?

Lasso stands for Least Absolute Shrinkage and Selection Operator. It is a variant of linear regression that adds a penalty proportional to the sum of absolute coefficient values (the L1 norm) to the cost function. This penalty does two things: it shrinks coefficients toward zero and it sets many of them to exactly zero — performing automatic feature selection.

It solves two problems simultaneously:

  • Overfitting — the penalty discourages complex models.
  • Feature selection — irrelevant features get coefficient = 0 and are dropped from the model entirely.

The Core Idea in Three Sentences

1. Fit a linear model, but add a penalty for large absolute coefficients: Cost = SSE + λ·Σ|βⱼ|.

2. Because the L1 penalty has a sharp "corner" at zero, many coefficients end up exactly 0 — the model performs feature selection automatically.

3. Choose λ by cross-validation: larger λ = sparser model, smaller λ = closer to OLS.

How the Algorithm Learns (Step by Step)

Step 1 — Standardise features

Like Ridge, Lasso is sensitive to feature scale because the penalty treats all coefficients equally. Centre each feature to mean 0 and scale to standard deviation 1. Also centre the target y.

Step 2 — State the penalised cost function

J(β) = Σi=1N ( yi − β0 − Σj=1p βjxij )² + λ · Σj=1p |βj|

Note: the intercept β₀ is not penalised — only the slope coefficients are.

Step 3 — Solve using coordinate descent

Unlike Ridge, Lasso has no closed-form solution. The L1 penalty |β| is not differentiable at β = 0, so we cannot just set the gradient to zero. Instead, Lasso is solved by coordinate descent: optimise one coefficient at a time while holding the others fixed. Each update is a simple formula called the soft-thresholding operator:

βj ← Sλ( ρj )   /   ( Σi xij² )

where ρj = Σi xij ( yi − ŷi(−j) )  (partial residual correlation)

Sλ(z) = sign(z) · max( |z| − λ, 0 )  (soft-thresholding)

Iterate over all j = 1…p, then repeat until convergence. Each coefficient either stays at its current value (if |ρⱼ| > λ), shrinks toward zero, or snaps to exactly 0 (if |ρⱼ| ≤ λ). This is where the sparsity comes from.

Step 4 — Choose λ by cross-validation

λ controls the trade-off between fit and sparsity. Use K-fold CV to find the λ that minimises out-of-sample error. Two common rules:

  • λmin — the λ that gives the lowest CV error. More features.
  • λ1SE — the largest λ within 1 standard error of λmin. Sparser model, often preferred when interpretability matters.

Step 5 — Refit and evaluate

Refit Lasso with the chosen λ on the full training set. Only the non-zero coefficients are the "selected features". Evaluate on a held-out test set or via cross-validation.

2 Applications

Lasso is the go-to tool whenever you have many features, sparse signals, and a need for interpretability. It is the workhorse of high-dimensional statistics.

🧬 Genomics & Bioinformatics

  • SNP selection (GWAS) — identify the few genetic variants associated with a disease out of millions.
  • Gene expression classifiers — pick biomarkers from 20,000 genes with only 100 samples.
  • Microbiome analysis — sparse selection of bacterial taxa.
  • Single-cell RNA-seq — feature selection from thousands of genes.

📝 Text & NLP

  • Document classification — Lasso on TF-IDF features picks the most discriminative words.
  • Spam filtering — sparse model using only informative tokens.
  • Sentiment analysis — sparse feature selection from n-grams.
  • Topic modelling — sparse topic-word associations.
  • Named entity recognition — sparse feature sets.

🏥 Healthcare & Epidemiology

  • Biomarker discovery — from hundreds of clinical variables.
  • Risk score construction — sparse, interpretable medical scores.
  • Radiomics feature selection — from hundreds of image features.
  • Drug response prediction — sparse genomic signatures.

💰 Finance & Economics

  • Sparse portfolio construction — few assets, easier to trade.
  • Index tracking — pick a small subset to replicate an index.
  • Factor selection — identify which factors matter for returns.
  • Credit scoring — sparse interpretable scorecards.

📈 Marketing & Business

  • Marketing mix modelling — identify which channels actually drive sales.
  • Customer segmentation — sparse behavioural features.
  • Feature selection for downstream models — Lasso as a preprocessing step.
  • A/B test analysis — sparse covariate adjustment.

🏭 Engineering & Signal Processing

  • Compressed sensing — recover sparse signals from few measurements.
  • Sensor selection — choose informative sensors out of many.
  • System identification — sparse models of dynamical systems.
  • Image denoising — sparse wavelet coefficients.
When is Lasso the right tool? If you have many features, you suspect only a few matter, and you want an interpretable sparse model, Lasso is the natural choice. It is the modern default for high-dimensional regression in genomics, text, and signal processing.

3 Advantages

  • Automatic feature selection — the biggest selling point. Lasso drives many coefficients to exactly zero, so the model only uses the features that matter.
  • Sparse, interpretable models — with only a handful of non-zero coefficients, the model is easy to explain and audit.
  • Works when p > N — with more features than samples, Lasso still produces a unique sparse solution (unlike OLS which is ill-posed).
  • Handles high-dimensional data — designed for the p ≫ N regime. Genomics, text, and imaging are all natural fits.
  • Reduces overfitting — the L1 penalty provides strong regularisation, especially for noisy or sparse problems.
  • Faster than L0 regularisation — exact L0 (best subset selection) is NP-hard. Lasso is a convex relaxation solvable in polynomial time.
  • Coordinate descent is very fast — for typical p, Lasso trains in milliseconds to seconds.
  • Handles multicollinearity by picking one — when two features are correlated, Lasso drops one and keeps the other, producing a simpler model (though which one is arbitrary).
  • Produces exact zero coefficients — the model file is smaller because zero coefficients don't need to be stored.
  • Theoretical guarantees — under the irrepresentable condition, Lasso recovers the true support with high probability.
  • Foundation for advanced methods — Adaptive Lasso, Group Lasso, Fused Lasso, Sparse Group Lasso, and Elastic Net all build on Lasso.
  • Used as a feature selector for other models — run Lasso, keep the non-zero features, then fit a nonlinear model (e.g. XGBoost) on just those.

4 Disadvantages

  • Unstable with correlated features — when two features are highly correlated, Lasso arbitrarily picks one and drops the other. The chosen feature can flip across runs, which is bad for interpretation.
  • No grouping of correlated features — Ridge keeps correlated features together (splitting the weight), Lasso drops all but one. Use Group Lasso or Elastic Net if grouping matters.
  • Biased estimates — the L1 penalty introduces bias. Lasso is great for prediction but not for estimating unbiased effects.
  • No closed-form solution — requires iterative coordinate descent. Slower than Ridge's single matrix inversion on moderate p.
  • Requires standardisation — because the penalty treats coefficients equally, features must be on the same scale.
  • Sensitive to λ — λ must be tuned by cross-validation. Poor λ gives either overfitting (small λ) or over-sparse models (large λ).
  • Inconsistent feature selection under collinearity — even with large samples, Lasso may pick the "wrong" correlated feature. Adaptive Lasso fixes this asymptotically.
  • Limited to p < N for consistent selection — support recovery requires strong conditions (irrepresentable condition). Under weaker conditions, Lasso may not find the true features.
  • Can drop true signals if they're correlated with irrelevant features — this is the "double-edged sword" of L1.
  • No p-values or confidence intervals directly — the estimates are biased, so standard OLS inference doesn't apply. Use bootstrap or post-selection inference.
  • Cannot represent smooth effects — if a feature's true effect is smooth but weak, Lasso may drop it. Fusion penalties or smoothing splines help.
  • Sensitive to outliers — squared error loss means outliers dominate. Use Huber-Lasso or quantile-Lasso for robustness.
  • Assumes linearity — inherits all the linear-regression assumptions (linearity, independence, homoscedasticity).
The correlated-features trap: Imagine you have "Income" and "Salary" — two features with 0.98 correlation. Lasso will randomly drop one and keep the other. Run the model again on a new sample and it might flip. Your prediction is fine, but you cannot confidently say "Income matters more than Salary." For that, use Ridge, Elastic Net, or Group Lasso.

5 Pre-Deployment KPIs — Detailed with Formulas

These are measured before the model goes live, using a held-out test set or cross-validation. They answer: "Is this model good enough to ship?"

5.1 Regression Accuracy KPIs

MAE (Mean Absolute Error) Regression

What it measures: The average size of the prediction error, in the same units as the target. Robust to outliers.

Formula MAE = (1/N) · Σi=1N | yi − ŷi |
Worked example: Actual = [100, 200, 300], Predicted = [110, 190, 320]
Errors = |−10|, |10|, |−20| = 10, 10, 20
MAE = (10 + 10 + 20) / 3 = 13.33
Interpretation: On average, the prediction is off by 13.33 units. Easy to explain to stakeholders.
✔ Use when You want an easy-to-explain metric and all errors have equal importance.
✘ Avoid when Large errors are dramatically worse than small ones (use RMSE).

MSE (Mean Squared Error) Regression

What it measures: The average of squared errors. Lasso minimises this plus the L1 penalty.

Formula MSE = (1/N) · Σi=1N ( yi − ŷi )²
Worked example: Errors = [−10, 10, −20]
MSE = (100 + 100 + 400) / 3 = 200

RMSE (Root Mean Squared Error) Regression

What it measures: The square root of MSE, bringing the metric back to the original units of the target.

Formula RMSE = √[ (1/N) · Σi=1N ( yi − ŷi )² ]
Worked example: MSE = 200
RMSE = √200 = 14.14
Interpretation: RMSE ≥ MAE always. The ratio RMSE/MAE ≈ 1.25 suggests roughly Gaussian residuals.
✔ Use when Large errors are genuinely worse (e.g. financial forecasting).
✘ Avoid when The target has outliers you don't care about — use MAE.

R² (Coefficient of Determination) Regression

What it measures: The proportion of the target's variance that the model explains.

Formula R² = 1 − ( SSres / SStot )

SSres = Σ ( yi − ŷi )²   (residual sum of squares)
SStot = Σ ( yi − ȳ )²   (total sum of squares)
Worked example: y = [100, 200, 300], ŷ = [110, 190, 320], ȳ = 200
SSres = 600, SStot = 20,000
R² = 1 − (600 / 20,000) = 0.97
Interpretation: R² = 1 → perfect; R² = 0 → no better than predicting the mean.
✔ Use when You want a scale-free measure of how well the model fits.
✘ Avoid when Comparing models with different numbers of features — use Adjusted R².

Adjusted R² Regression

What it measures: R² penalised for the number of predictors. Useful when comparing Lasso models with different active-set sizes.

Formula Adjusted R² = 1 − [ (1 − R²) · (N − 1) ] / (N − pactive − 1)

pactive = number of non-zero coefficients (the active set size)
Worked example: R² = 0.97, N = 100, pactive = 5
Adjusted R² = 1 − [(1 − 0.97) · 99] / 94 = 1 − 2.97/94 = 0.968
Interpretation: Use pactive (non-zero coefficients) — not the total number of features — for Lasso.

MAPE (Mean Absolute Percentage Error) Regression

Formula MAPE = (100% / N) · Σi=1N | ( yi − ŷi ) / yi |
Worked example: y = [100, 200, 300], ŷ = [110, 190, 320]
Errors % = 0.10, 0.05, 0.0667
MAPE = (0.10 + 0.05 + 0.0667) / 3 × 100 = 7.22%
✔ Use when Reporting to business stakeholders and actual values are well above zero.
✘ Avoid when Actual values can be zero — MAPE explodes.

SMAPE (Symmetric Mean Absolute Percentage Error) Regression

Formula SMAPE = (100% / N) · Σi=1N | yi − ŷi | / [ (|yi| + |ŷi|) / 2 ]
Interpretation: Range 0% to 200% (lower is better). Handles zero values better than MAPE.

MSLE (Mean Squared Logarithmic Error) Regression

Formula MSLE = (1/N) · Σi=1N ( log(1 + yi) − log(1 + ŷi) )²
✔ Use when The target spans several orders of magnitude.

5.2 Lasso-Specific KPIs

Sparsity Ratio Lasso-Specific

What it measures: The fraction of coefficients that are exactly zero. Higher = sparser model = fewer features needed at inference.

Formula Sparsity = ( # of zero coefficients ) / ( total # of coefficients ) = ( p − pactive ) / p

Interpretation Sparsity = 0 → OLS (no features dropped)
Sparsity = 1 → no features used (all dropped)
Typical: 0.7–0.99 in high-dimensional problems
Interpretation: If sparsity is 0.98, only 2% of features are used in the final model. This is a huge win for interpretability and inference speed.

Active Set Size (pactive) Lasso-Specific

What it measures: The number of non-zero coefficients. This is the "true" number of parameters used.

Formula pactive = Σj=1p 𝟙( β̂j ≠ 0 )

Relationship to λ Larger λ → smaller pactive (monotonically decreasing).
At λ = 0, pactive = p (OLS).
At λ = λmax, pactive = 0 (all coefficients zero).
Interpretation: pactive is the Lasso model's effective complexity. It's what you report to stakeholders: "Our model uses 12 features out of 500."

λmax — the Smallest Penalty that Zeroes Everything Lasso-Specific

What it measures: The value of λ at which all coefficients become exactly zero. This is the natural upper bound for λ search.

Formula λmax = maxj | Σi=1N xij yi |

(assuming standardised features and centred y)

Typical λ grid Log-spaced from λmax down to λmax × 10−4.
Interpretation: Never search for λ above λmax — the model would be all-zero. Most software (glmnet, sklearn) generates the path automatically.

Support Recovery (When True Model is Known) Lasso-Specific

What it measures: How well the Lasso-selected features match the true non-zero features (in simulation studies).

Precision of Selection Precisionsel = |Strue ∩ Sest| / |Sest|

Recall of Selection Recallsel = |Strue ∩ Sest| / |Strue|

F1 of Selection F1sel = 2 · P · R / (P + R)

Strue = true set of non-zero coefficients
Sest = estimated set (Lasso non-zeros)
Interpretation: Precision high = few false discoveries. Recall high = few missed features. F1 balances both.

λ (Lambda) — Regularisation Strength Lasso-Specific

Range λ ∈ [0, λmax]

Special cases λ = 0 → OLS (no penalty, all features)
λ → λmax → all βj = 0 (empty model)

Selection method K-fold CV. Choose λmin (min CV error) or λ1SE (largest λ within 1 SE of the minimum).
Interpretation: λ1SE is often preferred because it gives a sparser, more interpretable model with almost identical predictive performance.

L1 Norm of Coefficients ||β||₁ Lasso-Specific

What it measures: The total absolute magnitude of the coefficients.

Formula ||β||₁ = Σj=1p |βj|

Effect of λ As λ increases, ||β||₁ monotonically decreases.
Interpretation: Track ||β||₁ across λ values to see how aggressively Lasso is shrinking. It hits 0 at λ = λmax.

5.3 Model Quality & Robustness KPIs

Cross-Validation Score Robustness

K-Fold CV Score CV = (1/K) · Σk=1K Metrick

Standard deviation (stability) σCV = √[ (1/K) · Σk ( Metrick − CV )² ]
Interpretation: The CV curve over λ is what tells you the optimal penalty. Always plot CV error vs. log(λ).

Train–Test Gap (Overfitting Indicator) Robustness

Formula Gap = Metrictest − Metrictrain

For R²: Gap = R²train − R²test
Rule of thumb:
• Gap < 5% → healthy
• Gap 5–10% → mild overfitting, increase λ
• Gap > 10% → serious overfitting, increase λ significantly

Residual Diagnostics Robustness

What it measures: Whether the linear-model assumptions hold.

  • Residuals vs. Fitted — random scatter around 0. Curves = non-linearity. Funnels = heteroscedasticity.
  • QQ Plot — residuals should lie on a 45° line.
  • Residuals vs. Order — check for autocorrelation (Durbin-Watson).
  • Residuals vs. Selected Features — patterns indicate misspecification.

VIF (Variance Inflation Factor) Multicollinearity

Formula VIFj = 1 / (1 − R²j)

R²j = R² from regressing feature j on the other selected features.
Interpretation:
• VIF = 1 → no correlation
• VIF 1–5 → moderate
• VIF 5–10 → concerning
• VIF > 10 → severe multicollinearity

Lasso reduces VIF by dropping correlated features, but the remaining features may still have high VIF.

AIC / BIC for Lasso Model Selection

AIC (approx.) AIC = 2·pactive − 2·ℓ̂ + constant

BIC (approx.) BIC = ln(N)·pactive − 2·ℓ̂ + constant
Interpretation: Use pactive (non-zero coefficients) as the effective degrees of freedom. Lower AIC/BIC is better.

6 Post-Deployment KPIs — Detailed with Formulas

Once the model is live, you're no longer asking "is it accurate?" — you're asking "is it still accurate today, and is anything silently breaking?"

6.1 Data & Model Health KPIs

PSI (Population Stability Index) Data Drift

Formula PSI = Σi=1B ( Actual%i − Expected%i ) · ln( Actual%i / Expected%i )

B = number of bins (usually 10 deciles)
Expected%i = % of training samples in bin i
Actual%i = % of production samples in bin i
Interpretation thresholds:
• PSI < 0.10 → no significant change, model is stable ✅
• 0.10 ≤ PSI < 0.25 → moderate shift, monitor closely ⚠️
• PSI ≥ 0.25 → major shift, retrain the model 🚨

KS Statistic (Kolmogorov–Smirnov) Data Drift

Formula KS = maxx | Ftrain(x) − Fprod(x) |

F(x) = empirical cumulative distribution function
Interpretation: Range 0 to 1. Higher = more drift. A p-value < 0.05 indicates statistically significant drift.

KL Divergence (Kullback–Leibler) Data Drift

Formula DKL(P ‖ Q) = Σi P(i) · log( P(i) / Q(i) )

P = production distribution  |  Q = training distribution
Interpretation: 0 = identical distributions. Higher = more drift. Not symmetric.

Concept Drift (Performance Decay) Model Health

Formula Drift Magnitude = Metricvalidation − Metriclive

Relative decay Decay % = ( Metricvalidation − Metriclive ) / Metricvalidation × 100
Interpretation: Decay > 10% typically triggers a retraining investigation.

Prediction Distribution Shift Model Health

Formula PSIpred = Σ ( ProdPred%i − TrainPred%i ) · ln( ProdPred%i / TrainPred%i )
Interpretation: A sudden jump signals a pipeline problem or concept drift.

Active Set Stability Model Health

What it measures: Whether the same features remain selected across production retrains. Highly relevant for Lasso because feature selection can be unstable.

Stability Stability = |Strain ∩ Sprod| / |Strain ∪ Sprod|

Jaccard index between the training active set and the production refit active set.
Interpretation: Stability close to 1 = the same features keep getting selected. Low values suggest collinearity or drift.

Missing Value Rate Model Health

Formula Missing % = ( Missing values / Total values ) × 100
Interpretation: Lasso cannot handle missing values natively, so a spike in missingness directly degrades predictions.

6.2 Live Performance KPIs

Live RMSE / MAE / R² Performance

Same formulas as pre-deployment Live RMSE = √[ (1/Nlive) · Σ ( ylive − ŷlive )² ]
Live R² = 1 − SSres,live / SStot,live

CUSUM (cumulative sum control chart) CUSUMt = max(0, CUSUMt−1 + Deltat − k)
Interpretation: A steadily rising CUSUM indicates systematic drift.

Model Age / Time Since Retrain Performance

Formula Model Age = Current Date − Last Retrain Date
Interpretation: Many teams set a hard limit (e.g. 90 days) as a retraining trigger.

Latency Percentiles (p50, p95, p99) Operational

Definition p95 = the latency value below which 95% of requests fall
Target example: Lasso with a sparse model is extremely fast. p50 < 1 ms, p95 < 5 ms, p99 < 20 ms is typical.

7 Mathematical Formulas — How Lasso Regression Actually Works

The core idea: minimise the sum of squared errors subject to a penalty on the sum of absolute coefficients. Here are the formulas.

7.1 The Lasso Cost Function

Cost function J(β) = Σi=1N ( yi − β0 − Σj=1p βjxij )² + λ · Σj=1p |βj|

Matrix form J(β) = ||y − Xβ||² + λ · ||β||₁

Note The intercept β0 is not penalised.

7.2 No Closed-Form Solution

Unlike Ridge, Lasso cannot be solved by a single matrix inversion. The reason: the L1 penalty |β| has a kink at β = 0, so it is not differentiable there. The gradient is:

Subgradient of |β| at 0 ∂|β| / ∂β =
    +1   if β > 0
    −1   if β < 0
    [−1, +1]   if β = 0

Why this matters Because the subgradient at 0 contains the entire interval [−1, +1],
the optimal solution can have βⱼ = 0 exactly (unlike Ridge, where the gradient is smooth).

7.3 Constrained (Lagrangian) Form

Constrained optimisation minimise   Σi=1N ( yi − ŷi )²
subject to   Σj=1p |βj| ≤ t

Lagrangian L(β, λ) = Σ ( yi − ŷi )² + λ ( Σ |βj| − t )

Relationship Larger λ ↔ smaller t ↔ sparser solution.

7.4 Coordinate Descent Algorithm

Lasso is solved one coefficient at a time, holding all others fixed.

For each j = 1, …, p, repeat until convergence:

1. Compute the partial residual (excluding feature j):
    ri(−j) = yi − Σk ≠ j βk xik

2. Compute the correlation of feature j with the partial residual:
    ρj = Σi=1N xij · ri(−j)

3. Apply the soft-thresholding operator:
    βj ← Sλ( ρj ) / ( Σi xij² )

Soft-thresholding operator Sλ(z) = sign(z) · max( |z| − λ, 0 )

Interpretation If |ρj| ≤ λ → βj = 0  (feature dropped)
If |ρj| > λ → βj shrunk by λ toward zero

7.5 Soft-Thresholding Explained

This is the key operator that makes Lasso sparse.

Definition Sλ(z) =
    z − λ   if z > λ
    0      if −λ ≤ z ≤ λ
    z + λ   if z < −λ

Compact form Sλ(z) = sign(z) · max( |z| − λ, 0 )

Why it produces zeros Any |z| ≤ λ is forced to 0. The larger λ, the wider the "dead zone".
This is fundamentally different from Ridge's multiplicative shrinkage
(Ridge shrinks by a factor; Lasso shifts by a constant).

7.6 Ridge vs. Lasso Shrinkage Operators

Ridge (L2) shrinkage β̂Ridge,j = ρj / ( 1 + λ )
(multiplicative — shrinks by a constant factor, never reaches zero)

Lasso (L1) shrinkage β̂Lasso,j = sign(ρj) · max( |ρj| − λ, 0 )
(additive — shifts by λ, produces exact zeros)

This is the fundamental difference Multiplicative shrinkage → smooth, non-sparse (Ridge).
Additive shrinkage → piecewise-linear, sparse (Lasso).

7.7 λmax — The Upper Bound for λ

Formula λmax = maxj | Σi=1N xij yi |

(assuming standardised features and centred y)

Interpretation At λ ≥ λmax, all soft-thresholded correlations are zero → all β̂j = 0.
The typical λ grid runs log-spaced from λmax down to λmax × 10−4.

7.8 Bayesian Interpretation

Lasso is the MAP estimate under a Laplace prior on the coefficients (Ridge uses a Gaussian prior).

Prior on coefficients P(βj) ∝ exp( − |βj| / b )   (Laplace / double-exponential)

MAP estimate β̂MAP = argmaxβ [ log P(y | X, β) + log P(β) ]
         = argminβ [ ||y − Xβ||² + λ||β||₁ ]

Key insight The Laplace prior has a sharp peak at 0, which is why the posterior mode
puts many coefficients at exactly zero.

7.10 Adaptive Lasso (Addressing the Instability)

Adaptive Lasso adds per-feature weights to make selection consistent even with correlated features.

Adaptive Lasso objective J(β) = Σ ( yi − ŷi )² + λ · Σj wj |βj|

Common weight choice wj = 1 / |β̂jinit|γ

β̂init is an initial estimate (often from OLS or Ridge)
γ > 0 is a tuning parameter (γ = 1 is common)

Effect Features with strong initial coefficients get small weights (less penalised).
Features with weak initial coefficients get large weights (more likely to be dropped).
Result: consistent selection, oracle property asymptotically.

7.11 Group Lasso (Handling Correlated Groups)

When features come in natural groups, Group Lasso selects entire groups at once.

Group Lasso objective J(β) = Σ ( yi − ŷi )² + λ · Σg=1G √pg · ||βg||₂

βg = coefficient subvector for group g
pg = number of features in group g
||βg||₂ = L2 norm of the group's coefficients

Effect Entire groups are either all-in or all-out — correlated features within a group
are kept together, fixing Lasso's instability problem.

7.12 Elastic Net (Combining Ridge and Lasso)

Elastic Net uses both L1 and L2 penalties to get the best of both worlds.

Elastic Net objective J(β) = Σ ( yi − ŷi )² + λ [ (1 − α) · Σβj² + α · Σ|βj| ]

α ∈ [0, 1] controls the L1/L2 mix:
α = 0 → pure Ridge (dense)
α = 1 → pure Lasso (sparse)
0 < α < 1 → hybrid

Why use it Elastic Net groups correlated features (like Ridge) while still producing sparse solutions (like Lasso).
It's the recommended default when you have correlated features.

8 Glossary of Acronyms & Terms

Every abbreviation used in this study guide, explained in plain English.

Algorithm & Model Concepts

ML
Machine Learning — a field of AI where systems learn patterns from data instead of being explicitly programmed.
Lasso
Least Absolute Shrinkage and Selection Operator — linear regression with an L1 penalty that produces sparse models.
OLS
Ordinary Least Squares — standard linear regression without any penalty.
Ridge
Ridge Regression — linear regression with an L2 penalty. Shrinks coefficients but never zeroes them.
Elastic Net
Linear regression with both L1 and L2 penalties combined.
L1
Penalty on the sum of absolute coefficients: Σ|βⱼ|. Used by Lasso.
L2
Penalty on the sum of squared coefficients: Σβⱼ². Used by Ridge.
L0
Penalty on the number of non-zero coefficients. NP-hard; Lasso is its convex relaxation.
Adaptive Lasso
Lasso with feature-specific weights for consistent selection under collinearity.
Group Lasso
Lasso that selects entire groups of features at once.
Fused Lasso
Lasso variant that penalises differences between adjacent coefficients — useful for ordered features (e.g. time).
Sparse Group Lasso
Combines Lasso (within-group sparsity) with Group Lasso (between-group sparsity).
Compressed Sensing
A signal-processing field where Lasso is used to recover sparse signals from few measurements.

Final tip: Lasso is the right tool when you suspect the true model is sparse and you want an interpretable, minimal feature set. If features are highly correlated and grouping matters, use Elastic Net or Group Lasso. If you need maximum predictive accuracy without caring about sparsity, use Ridge. If you want to select features and then fit a nonlinear model, use Lasso as a preprocessing step.
