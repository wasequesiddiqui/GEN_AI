① ZSL Image Classification

Classify images into categories never seen during training by leveraging semantic descriptions (attributes, word vectors, or text prompts).

import clip
model, preprocess = clip.load("ViT-B/32")
image = preprocess(img).unsqueeze(0)
text = clip.tokenize(["a photo of a zebra"])
logits = model(image, text)
💡CLIP achieves ~76% zero-shot accuracy on ImageNet without any ImageNet training — purely from 400M image-text pairs.
🔍

② Cross-Modal Retrieval

Search images using text queries (or vice versa) in a shared embedding space. Powers Google Images, stock photo search, and e-commerce.

# Text-to-image retrieval via CLIP
img_embeds = model.encode_image(images)
txt_embeds = model.encode_text(queries)
similarity = img_embeds @ txt_embeds.T
top_k = similarity.topk(k=10)
✅Dual-encoder models (CLIP, ALIGN) enable sub-second retrieval across millions of images via precomputed embeddings.
❓

③ Visual Question Answering (VQA)

Answer natural language questions about images by fusing visual and textual representations. BLIP, LLaVA, and GPT-4V are state-of-the-art.

# VQA: image + question → answer
from transformers import pipeline
vqa = pipeline("visual-question-answering")
answer = vqa(image, "How many cats?")
💡Modern VQA uses multimodal fusion — cross-attention between visual tokens and text tokens in a unified transformer decoder.

🏗️ Multimodal & Zero-Shot Architecture Patterns

Modern ZSL and multimodal systems use dual-encoder or fusion-based architectures that project different modalities into a shared embedding space for zero-shot transfer.

🌐 Multimodal Core Equations
Dual-Encoder Similarity (CLIP):
s(I,T) = fimg(I)T · ftxt(T) / τ
Contrastive Loss (InfoNCE):
L = −log exp(s(I,T)/τ) / Σk exp(s(I,Tk)/τ)
Multimodal Fusion (Cross-Attn):
hfused = CrossAttn(Qtxt, Kimg, Vimg)
Zero-Shot Prediction:
ŷ = argmaxc s(I, prompt(c))

📖 Architecture Breakdown – Dual-Encoder, Fusion, and Contrastive Learning

Understanding how modalities are aligned and fused is central to building effective ZSL and multimodal systems.

🔹 Dual-Encoder Architecture
fimg(I)
Image encoder (ViT/ResNet) that maps an image to a normalized embedding vector in the shared space.
Shape: (batch, d). d=512 (CLIP ViT-B/32), d=768 (ViT-L/14)
ftxt(T)
Text encoder (transformer) that maps a text prompt to a normalized embedding in the same space.
Shape: (batch, d). Same dimension as image encoder output
τ (temperature)
Learnable temperature parameter that scales the logits. Controls the sharpness of the similarity distribution.
CLIP learns τ ≈ 0.07 (initialized at log(1/0.07) ≈ 2.66)
Shared Space
Both encoders project into a unit hypersphere (L2-normalized). Similarity = cosine distance on the sphere.
All embeddings lie on Sd-1 — the d-dimensional unit sphere
🔹 Contrastive Training & Fusion
InfoNCE Loss
Contrastive objective: pulls matched (I,T) pairs together while pushing all other pairs apart in the batch.
Batch of N pairs → N positive pairs, N²−N negative pairs
Cross-Attention
Text tokens attend to image patch tokens (or vice versa). Enables fine-grained multimodal reasoning beyond global similarity.
Q from text, K/V from image. Used in BLIP-2, LLaVA, Flamingo
Prompt Engineering
Crafting text prompts (e.g., "a photo of a {class}") drastically affects zero-shot accuracy. Prompt ensembles improve robustness.
CLIP: 80 prompt templates averaged. CuPL: LLM-generated prompts per class
💡 Key insight: The shared embedding space is what makes zero-shot transfer possible — any new class can be classified by simply encoding its text description, with no additional training needed.
🔍

Dual-Encoder (CLIP-style)

Separate image and text encoders produce independent embeddings. Fast retrieval via precomputed embeddings; best for classification and search.

💡Dual-encoder: O(1) per query after indexing. Best for retrieval, zero-shot classification, and moderation at scale.
🔄

Fusion-Based (BLIP-2, LLaVA)

Cross-attention between vision and language tokens enables deeper reasoning. Better for VQA, captioning, and detailed visual understanding.

✅Fusion models outperform dual-encoders on VQA and captioning but require running the full model for each query (no pre-indexing).

⚡ Training Strategies for Multimodal & ZSL Models

Training multimodal models requires large-scale contrastive learning with careful batch construction and data curation.

⚖️

Contrastive Pretraining (CLIP-style)

Train on millions of (image, text) pairs using symmetric InfoNCE loss. The large batch size provides abundant negative examples.

# Symmetric contrastive loss
logits = img_emb @ txt_emb.T * exp(t)
labels = arange(N)
loss = (CE(logits, labels, axis=0) + CE(logits, labels, axis=1)) / 2
✅CLIP was trained on 400M image-text pairs with batch size 32,768. Scale of data and batch size are the most important factors.
📦

Large-Scale Data Curation

Multimodal models need diverse, high-quality paired data. Web-scraped alt-text (LAION, COYO) is standard for pretraining.

# LAION-5B: 5.85 billion image-text pairs
from datasets import load_dataset
dataset = load_dataset("laion/laion400m")
# Filter by aesthetic score, resolution, safety
💡Data quality filtering (CLIP score, aesthetic score, resolution) improves zero-shot transfer by 3–5% vs unfiltered data.
🎯

Prompt Engineering & Ensembling

Zero-shot accuracy varies dramatically with prompt wording. Prompt ensembles average over multiple templates for robust predictions.

# CLIP prompt ensembling (80 templates)
templates = ["a photo of a {}.",
"a blurry photo of a {}.",
"a {} in the wild."]
text_features = mean([f_txt(t.format(c)) for t in templates])

Two-Stage Training (BLIP-2)

Stage 1: Train a Q-Former to bridge frozen vision encoder and frozen LLM. Stage 2: Fine-tune on instruction-following data.

🛡️ Regularization & Tuning for Multimodal Models

Key techniques to prevent overfitting and improve zero-shot generalization in multimodal learning.

🌡️

Temperature Scaling

The learnable temperature τ in contrastive loss controls the concentration of the similarity distribution. Critical for calibration.

# Learnable log-temperature
self.logit_scale = nn.Parameter(torch.ones([]) * np.log(1/0.07))
logits = img_emb @ txt_emb.T * self.logit_scale.exp()
💡CLIP initializes τ at 0.07 (logit_scale ≈ 2.66). The learned value converges to ~0.01–0.02 during training.
🔀

Modality Dropout

Randomly drops one modality during training to prevent the model from over-relying on a single modality. Improves robustness.

# Drop visual modality with probability p
if random() < 0.1:
visual_features = zeros_like(visual_features)
# Forces reliance on text when vision is absent
✅Modality dropout (p=0.05–0.15) improves robustness to missing modalities at inference time. Standard in multimodal transformers.
📐

L2 Normalization + Weight Decay

Embeddings are L2-normalized to the unit sphere. Weight decay on projection layers prevents overfitting to training class distribution.

# L2-normalize embeddings
img_emb = F.normalize(img_emb, dim=-1)
txt_emb = F.normalize(txt_emb, dim=-1)
# Cosine similarity = dot product on sphere
📏

Gradient Clipping & Large-Batch Stability

Large contrastive batches (32K+) need gradient clipping and careful LR warmup to prevent training instability.

# CLIP training stability
clip_grad_norm_(model.parameters(), 1.0)
# LR warmup over first 2000 steps
lr = peak_lr * min(1.0, step / warmup)

💻 Full Code – CLIP-style Zero-Shot Classification with PyTorch

A minimal CLIP-style dual-encoder implementation for zero-shot image classification. All key hyperparameters annotated.

#!/usr/bin/env python3 """Minimal CLIP-style dual encoder for zero-shot classification.""" import torch import torch.nn as nn import torch.nn.functional as F import torch.optim as optim import torchvision.models as models # ── Hyperparameters ── EMBED_DIM = 512 # Shared embedding dimension TEMPERATURE = 0.07 # τ — temperature for contrastive loss BATCH_SIZE = 256 # Batch size for contrastive pairs LR = 5e-4 # Peak learning rate WARMUP = 2000 # LR warmup steps EPOCHS = 30 # Training epochs WEIGHT_DECAY = 0.2 # AdamW weight decay class ImageEncoder(nn.Module): def __init__(self): super().__init__() backbone = models.resnet50(pretrained=True) self.backbone = nn.Sequential(*list(backbone.children())[:-1]) self.projection = nn.Linear(2048, EMBED_DIM) def forward(self, x): feat = self.backbone(x).flatten(1) # (batch, 2048) emb = self.projection(feat) # (batch, 512) return F.normalize(emb, dim=-1) # L2-normalize to unit sphere class TextEncoder(nn.Module): def __init__(self, vocab_size=49408): super().__init__() self.token_embed = nn.Embedding(vocab_size, 512) self.transformer = nn.TransformerEncoder( nn.TransformerEncoderLayer(d_model=512, nhead=8, batch_first=True), num_layers=6) self.projection = nn.Linear(512, EMBED_DIM) def forward(self, tokens): x = self.token_embed(tokens) x = self.transformer(x) # (batch, seq_len, 512) emb = x[torch.arange(x.size(0)), tokens.argmax(dim=-1)] # EOT token emb = self.projection(emb) # (batch, 512) return F.normalize(emb, dim=-1) class CLIP(nn.Module): def __init__(self): super().__init__() self.image_encoder = ImageEncoder() self.text_encoder = TextEncoder() self.logit_scale = nn.Parameter(torch.ones([]) * torch.log(torch.tensor(1/TEMPERATURE))) def forward(self, images, text_tokens): img_emb = self.image_encoder(images) # (N, 512) txt_emb = self.text_encoder(text_tokens) # (N, 512) logits = img_emb @ txt_emb.T * self.logit_scale.exp() return logits def contrastive_loss(logits): # Symmetric InfoNCE: image→text + text→image labels = torch.arange(logits.size(0), device=logits.device) loss_i = F.cross_entropy(logits, labels) # image→text loss_t = F.cross_entropy(logits.T, labels) # text→image return (loss_i + loss_t) / 2 model = CLIP().to(device) optimizer = optim.AdamW(model.parameters(), lr=LR, weight_decay=WEIGHT_DECAY) # ── Training ── for epoch in range(EPOCHS): for images, texts in dataloader: logits = model(images, texts) loss = contrastive_loss(logits) optimizer.zero_grad(); loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0) optimizer.step() # ── Zero-Shot Inference ── def zero_shot_classify(image, class_descriptions): with torch.no_grad(): img_emb = model.image_encoder(image) # (1, 512) prompts = [f"a photo of a {c}" for c in class_descriptions] txt_emb = model.text_encoder(tokenize(prompts)) # (num_classes, 512) scores = (img_emb @ txt_emb.T).squeeze() # Cosine similarity pred = scores.argmax().item() return class_descriptions[pred], scores print(f"Zero-shot prediction: {zero_shot_classify(img, ['cat','dog','bird'])}")

⬆️ Minimal CLIP-style dual encoder. Dual-encoder architecture + symmetric InfoNCE loss + temperature-scaled cosine similarity for zero-shot classification.

🧠 Dual-Encoder Models

Separate encoders, shared embedding space

  • ✅ Fast retrieval (pre-indexed)
  • ✅ Excellent for zero-shot classification
  • ✅ Scalable to billions of images
  • 📌 CLIP, ALIGN, SigLIP

⚙️ Fusion-Based Models

Cross-attention between modalities

  • 🔧 Deeper reasoning capability
  • 🔧 Better for VQA & captioning
  • 🔧 No pre-indexing (slower retrieval)
  • 📌 BLIP-2, LLaVA, Flamingo
