Basics of Sequence to Sequence Models – Hyperparameters

Master the encoder-decoder architecture with attention — the backbone of translation, summarization, and multimodal learning.

Sequence-to-Sequence (Seq2Seq) models map an input sequence to an output sequence using an encoder-decoder framework with attention. This guide covers the 10 most important hyperparameters for Seq2Seq models, from hidden sizes and attention mechanisms to teacher forcing and beam search, with practical PyTorch examples and a runnable translation demo.

🧩

① Encoder Hidden Size

Dimensionality of the encoder RNN hidden state. Larger sizes capture richer source representations but increase computation.

class EncoderRNN(nn.Module):
self.gru = nn.GRU(input_size, hidden_size=256,
bidirectional=True)
💡Common range: 256–1024. Bidirectional encoders double the effective hidden size (2× hidden concatenated).
🔧

② Decoder Hidden Size

Dimensionality of the decoder RNN hidden state. Must match the encoder's output size when using attention.

class DecoderRNN(nn.Module):
self.gru = nn.GRU(embed_dim + enc_hidden,
hidden_size=512)
✅For bidirectional encoder (hidden=256 per direction), set decoder hidden=512 to match concatenated encoder output.
🎯

③ Attention Mechanism (Bahdanau / Luong)

Computes alignment scores between decoder state and encoder outputs. Additive (Bahdanau) and dot-product (Luong) are the two main types.

# Bahdanau (additive) attention
score = vT·tanh(W1h + W2s)
# Luong (dot-product) attention
score = sT·h
💡Bahdanau uses a learnable alignment model. Luong is simpler but requires matching dimensions. Prefer Bahdanau for complex tasks.
📐

④ Embedding Size

Dimensionality of the token embedding vectors for source and target vocabularies. Shared embeddings can reduce parameters.

self.src_embed = nn.Embedding(
src_vocab_size, embed_size=256)
self.tgt_embed = nn.Embedding(
tgt_vocab_size, embed_size=256)
💡Common range: 128–512. Embedding size should be significantly smaller than vocab size. Tie embeddings when vocab is shared.
🎲

⑤ Dropout Rate

Dropout applied to RNN layers and embeddings. Essential for preventing overfitting in Seq2Seq models, especially with small parallel corpora.

self.dropout = nn.Dropout(p=0.3)
# Apply after embedding and between RNN layers
embedded = self.dropout(self.embedding(x))
⚠️Seq2Seq models with small data (<100k pairs) benefit from higher dropout (0.3–0.5). Reduce for large datasets.
📈

⑥ Learning Rate

Seq2Seq models use moderate learning rates. RNN-based models are less sensitive than transformers but still need careful tuning.

optimizer = Adam(
model.parameters(),
lr=0.001)
✅Start with 0.001 (Adam default). Reduce to 5e-4 if loss oscillates. Halve when BLEU plateaus during validation.
📦

⑦ Batch Size

Seq2Seq batches contain variable-length sequences. Dynamic batching with bucketing groups similar-length sequences for efficiency.

# Bucket sequences by length for efficient padding
train_iter = BucketIterator(
dataset, batch_size=64,
sort_key=lambda x: len(x.src))
💡Use 32–128 depending on GPU memory. Bucketing reduces wasted computation on padding tokens by ~30–50%.
🏗️

⑧ Number of Encoder/Decoder Layers

Stacked RNN layers increase representational capacity. Typically 2–4 layers for both encoder and decoder.

self.encoder = nn.GRU(
input_size, hidden_size,
num_layers=2,
dropout=0.3, bidirectional=True)
✅2–4 layers for most translation tasks. Deeper encoders (>4 layers) risk vanishing gradients without residual connections.
📏

⑨ Sequence Length (Max Input/Output)

Maximum token length for source and target sequences. Longer sequences capture more context but increase memory and training time.

# Filter or truncate long sequences
SRC_MAX_LEN = 50
TGT_MAX_LEN = 50
dataset = [p for p in dataset
if len(p.src) <= SRC_MAX_LEN
and len(p.tgt) <= TGT_MAX_LEN]
⚠️RNN training time scales linearly with sequence length (unlike transformer's O(n²)). Use 30–80 tokens for balanced efficiency.
📉

⑩ Loss Function (Cross-Entropy)

Next-token cross-entropy with padding ignored. The standard objective for autoregressive Seq2Seq training.

# Ignore token in loss
loss = F.cross_entropy(
output.view(-1, tgt_vocab_size),
target.view(-1),
ignore_index=PAD_IDX)
💡Always set ignore_index=PAD_IDX. Without it, the model wastes capacity learning to predict padding tokens.

🏗️ Seq2Seq Architecture & Attention Mechanism

A Seq2Seq model has three core components: an encoder that compresses the source sequence into hidden states, an attention mechanism that computes alignment weights, and a decoder that autoregressively generates the target sequence.

🔄 Seq2Seq Core Equations
Encoder Recurrence:
ht = RNNenc(xt, ht−1)   t=1,…,T
Attention Score (Bahdanau):
et,i = vT·tanh(Wa·st + Ua·hi)
Context Vector:
ct = Σi=1T αt,i·hi   where   αt,i=softmax(et,i)
Decoder Recurrence:
st = RNNdec([yt−1; ct], st−1)

📖 Equation Element Breakdown – Encoder, Attention & Decoder

Every symbol in the Seq2Seq architecture explained — from encoder recurrence to attention-weighted decoding.

🔹 Encoder Components
xt
Source token embedding at position t. Looked up from the source embedding matrix.
Shape: (batch, embed_size)
ht
Encoder hidden state at time t. Bidirectional encoders produce [ht→; ht←] concatenated.
Shape: (batch, hidden_size) or (batch, 2×hidden_size)
RNNenc
Recurrent cell (GRU/LSTM). Processes the input token-by-token, building contextualized representations.
GRU: 3 gates. LSTM: 4 gates (forget, input, cell, output)
h0 (initial)
Initial encoder hidden state, typically zeros. The decoder's initial state s0 is set from the final encoder state.
Shape: (num_layers×directions, batch, hidden_size)
🔹 Attention Mechanism
et,i
Unnormalized attention score — how relevant encoder state hi is for decoder step t.
Scalar per source position i
αt,i
Normalized attention weight after softmax. Σi αt,i = 1. Represents the probability distribution over source positions.
Shape: (batch, src_len). Each row sums to 1
Wa, Ua, v
Learnable parameters of the additive attention model. Wa projects decoder state; Ua projects encoder states; v computes the scalar score.
Wa: (attn_dim, dec_hidden); Ua: (attn_dim, enc_hidden); v: (attn_dim,)
ct (context)
Weighted sum of encoder hidden states using attention weights αt. Provides the decoder with a focused summary of the source.
Shape: (batch, enc_hidden_size)
🔹 Decoder Components
yt−1
Previously generated token embedding. During training, this is the ground-truth token (teacher forcing).
Shape: (batch, embed_size)
st
Decoder hidden state at step t. Updated based on previous token, previous state, and attention context.
Shape: (batch, dec_hidden_size)
[yt−1; ct]
Concatenation of the embedded previous token and the attention context vector. Fed as input to the decoder RNN.
Shape: (batch, embed_size + enc_hidden_size)
Output Projection
Linear layer + softmax: P(yt) = softmax(Wout·st + b). Maps hidden state to vocabulary distribution.
Wout: (vocab_size, dec_hidden_size)
💡 Key insight: Attention solves the bottleneck problem of fixed-length context vectors. Instead of compressing the entire source into one vector, the decoder dynamically attends to relevant source positions at each generation step.
🔍

Bahdanau (Additive) Attention

Uses a learnable feed-forward network to compute alignment scores. More flexible but slightly more parameters than Luong.

💡Preferred for most Seq2Seq tasks. Works with different encoder and decoder hidden sizes.
🔄

Bidirectional Encoder

Processes the source sequence both forward and backward, producing richer context-aware representations at each position.

✅Almost always use bidirectional encoders. They consistently improve BLEU scores by 1–3 points over unidirectional encoders.

⚡ Training Process for Seq2Seq Models

Seq2Seq training uses teacher forcing with scheduled sampling and careful sequence handling for efficient learning.

📝

Teacher Forcing & Scheduled Sampling

During training, the ground-truth token (not the model's prediction) is fed as the next input. Scheduled sampling gradually transitions to using model predictions.

def train_step(src, tgt):
enc_out, hidden = encoder(src)
for t in range(tgt_len - 1):
decoder_input = tgt[:, t] # Teacher forcing
output, hidden = decoder(
decoder_input, hidden, enc_out)
✅Start with 100% teacher forcing. Introduce scheduled sampling (p=0.05–0.25) to bridge the train-inference mismatch.
📐

Sequence Bucketing / Padding

Group sequences of similar length into buckets. Minimizes wasted computation on padding tokens within each batch.

# BucketIterator groups similar-length seqs
train_iter = BucketIterator(
dataset, batch_size=64,
sort_within_batch=True,
sort_key=lambda x: len(x.src))
💡Bucketing reduces padding overhead by ~30–50%. Essential for efficient training with variable-length sequences.
🎯

Learning Rate Scheduling

Reduce LR when validation BLEU/accuracy plateaus. Seq2Seq models benefit from step-based or plateau-based decay.

from torch.optim.lr_scheduler import ReduceLROnPlateau
scheduler = ReduceLROnPlateau(
optimizer, mode='max', factor=0.5,
patience=2) # Halve LR if BLEU stalls
✅Monitor validation BLEU or loss. Reduce LR by factor 0.5–0.7 when metric plateaus for 2–3 epochs.
🔍

Beam Search Decoding

Keeps top-k most probable partial sequences at each decoding step. Beam width trades quality for speed during inference.

def beam_search(encoder_out, beam_width=5):
beams = [([SOS], 0.0)] # (sequence, log_prob)
for t in range(max_len):
# Expand each beam, keep top-k
candidates = expand_beams(beams)
beams = top_k(candidates, beam_width)
💡Beam width 3–5 is standard for translation. Width 1 = greedy decoding. Width > 10 gives diminishing returns.

🛡️ Regularization & Tuning for Seq2Seq

RNN-based Seq2Seq models need strong regularization, especially with limited parallel data. These techniques prevent overfitting and improve generalization.

🎲

Dropout (Input & Recurrent)

Apply dropout to embedding layers, between RNN layers, and on recurrent connections. Higher rates for smaller datasets.

self.gru = nn.GRU(
input_size, hidden_size,
dropout=0.3) # Between stacked layers
# Recurrent dropout (Gal & Ghahramani)
self.rnn_dropout = nn.Dropout(0.2)
💡Use 0.2–0.3 embedding dropout, 0.2–0.3 RNN dropout, and 0.1–0.2 recurrent dropout for small parallel corpora.
📏

Gradient Clipping

Clips gradients to a maximum norm. Essential for RNN-based models to prevent exploding gradients in long sequences.

# Clip gradients before optimizer.step()
torch.nn.utils.clip_grad_norm_(
model.parameters(),
max_norm=1.0)
⚠️Without clipping, RNN gradients can explode to 1000+ during early training. max_norm=1.0 is standard for Seq2Seq.
🏷️

Label Smoothing

Softens one-hot targets by reserving probability mass for non-target tokens. Reduces overconfidence in Seq2Seq output distributions.

# Label smoothing with ε=0.1
loss = F.cross_entropy(
output, target,
label_smoothing=0.1)
✅ε=0.1 is standard. Improves BLEU by preventing the model from assigning near-zero probability to plausible alternatives.
⏳

Early Stopping & Validation Monitoring

Stop training when validation BLEU or loss plateaus. Restore best weights for optimal generalization.

class EarlyStopping:
if val_loss < best_loss:
best_loss = val_loss; patience = 0
save_checkpoint(model)
else:
patience += 1
if patience >= 5: break

A complete Seq2Seq model with bidirectional GRU encoder, additive attention, and GRU decoder. All hyperparameters annotated.

#!/usr/bin/env python3 """Seq2Seq with Bahdanau Attention – all hyperparameters labeled.""" import torch import torch.nn as nn import torch.nn.functional as F import torch.optim as optim import random # ── Hyperparameters ── ENC_HIDDEN = 256 # ① Encoder hidden size (per direction) DEC_HIDDEN = 512 # ② Decoder hidden size (= 2×ENC_HIDDEN for bidirectional) EMBED_SIZE = 256 # ④ Embedding dimension ATTN_DIM = 256 # ③ Attention projection dimension DROPOUT = 0.3 # ⑤ Dropout rate LEARNING_RATE = 0.001 # ⑥ Learning rate BATCH_SIZE = 64 # ⑦ Batch size NUM_LAYERS = 2 # ⑧ Encoder/Decoder layers MAX_SRC_LEN = 50 # ⑨ Max source sequence length MAX_TGT_LEN = 50 # ⑨ Max target sequence length CLIP = 1.0 # Gradient clipping LABEL_SMOOTH = 0.1 # ⑩ Label smoothing class Encoder(nn.Module): def __init__(self, src_vocab): super().__init__() self.embedding = nn.Embedding(src_vocab, EMBED_SIZE) self.dropout = nn.Dropout(DROPOUT) self.gru = nn.GRU(EMBED_SIZE, ENC_HIDDEN, num_layers=NUM_LAYERS, bidirectional=True, dropout=DROPOUT if NUM_LAYERS > 1 else 0) def forward(self, src): embedded = self.dropout(self.embedding(src)) outputs, hidden = self.gru(embedded) return outputs, hidden # outputs: (src_len, batch, 2×ENC_HIDDEN) class BahdanauAttention(nn.Module): def __init__(self): super().__init__() self.W_a = nn.Linear(DEC_HIDDEN, ATTN_DIM, bias=False) self.U_a = nn.Linear(2 * ENC_HIDDEN, ATTN_DIM, bias=False) self.v = nn.Linear(ATTN_DIM, 1, bias=False) def forward(self, dec_hidden, enc_outputs): # dec_hidden: (batch, DEC_HIDDEN) # enc_outputs: (src_len, batch, 2×ENC_HIDDEN) src_len = enc_outputs.shape[0] dec_hidden = dec_hidden.unsqueeze(0).repeat(src_len, 1, 1) energy = torch.tanh(self.W_a(dec_hidden) + self.U_a(enc_outputs)) attention = F.softmax(self.v(energy).squeeze(2), dim=0) # (src_len, batch) return attention.unsqueeze(1) class Decoder(nn.Module): def __init__(self, tgt_vocab): super().__init__() self.embedding = nn.Embedding(tgt_vocab, EMBED_SIZE) self.dropout = nn.Dropout(DROPOUT) self.attention = BahdanauAttention() self.gru = nn.GRU(EMBED_SIZE + 2 * ENC_HIDDEN, DEC_HIDDEN, num_layers=NUM_LAYERS, dropout=DROPOUT if NUM_LAYERS > 1 else 0) self.fc_out = nn.Linear(DEC_HIDDEN + EMBED_SIZE + 2 * ENC_HIDDEN, tgt_vocab) def forward(self, input, hidden, enc_outputs): input = input.unsqueeze(0) # (1, batch) embedded = self.dropout(self.embedding(input)) attn_weights = self.attention(hidden[-1], enc_outputs) context = attn_weights.bmm(enc_outputs.transpose(0, 1)).transpose(0, 1) rnn_input = torch.cat([embedded, context], dim=2) output, hidden = self.gru(rnn_input, hidden) output = torch.cat([output.squeeze(0), embedded.squeeze(0), context.squeeze(0)], dim=1) prediction = self.fc_out(output) return prediction, hidden, attn_weights class Seq2Seq(nn.Module): def __init__(self, encoder, decoder, device): super().__init__() self.encoder = encoder self.decoder = decoder self.device = device def forward(self, src, tgt): # Teacher forcing: use ground-truth target as decoder input enc_outputs, hidden = self.encoder(src) outputs = [] for t in range(tgt.size(1) - 1): output, hidden, _ = self.decoder(tgt[:, t], hidden, enc_outputs) outputs.append(output) return torch.stack(outputs, dim=0) # ── Training setup ── encoder = Encoder(SRC_VOCAB_SIZE).to(device) decoder = Decoder(TGT_VOCAB_SIZE).to(device) model = Seq2Seq(encoder, decoder, device).to(device) optimizer = optim.Adam(model.parameters(), lr=LEARNING_RATE) scheduler = ReduceLROnPlateau(optimizer, mode='min', factor=0.5, patience=2) EPOCHS = 20 for epoch in range(EPOCHS): model.train() for src, tgt in dataloader: output = model(src, tgt) loss = F.cross_entropy( # ⑩ Loss output.view(-1, TGT_VOCAB_SIZE), tgt[:, 1:].reshape(-1), ignore_index=PAD_IDX, label_smoothing=LABEL_SMOOTH) optimizer.zero_grad() loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), CLIP) # Gradient clipping optimizer.step() val_loss = evaluate(model, val_dataloader) scheduler.step(val_loss) print(f"Epoch {epoch+1}/{EPOCHS} | Train Loss: {loss:.3f} | Val Loss: {val_loss:.3f}")
