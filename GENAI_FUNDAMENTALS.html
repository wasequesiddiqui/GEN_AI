What is Generative AI?
Generative AI models learn the statistical patterns in data and use that knowledge to create entirely new, original content — text, images, code, audio, and beyond.
Traditional AI vs Generative AI
🔍 Traditional AI
  • Classification (spam vs. not spam)
  • Prediction (house prices, churn rates)
  • Detection (object recognition, fraud)
  • Discriminative: maps input → label
  • Requires labelled training data
✨ Generative AI
  • Content creation (text, images, code)
  • Data generation & augmentation
  • Simulation & synthetic data
  • Creative synthesis across modalities
  • Learns probability distributions P(X)
ℹ️ Core Idea: A generative model learns the probability distribution of data — P(X) or P(X|Y) — and can sample new instances from that distribution. The model doesn't just categorise; it creates.

Glossary — Overview Terms
P(X)
Unconditional probability distribution over data X. The model learns what X looks like across the entire dataset.
P(X|Y)
Conditional probability: the distribution of X given context or condition Y. Used in text-to-image models.
Latent Space
A compressed, lower-dimensional representation of data learned by the model (VAEs, diffusion models).
Discriminative Model
Learns P(Y|X) — the boundary between classes. Traditional classifiers like logistic regression.
Generative Model
Learns P(X) — the full distribution of data, enabling new sample generation.
Sampling
Drawing a new data point from the learned distribution — the act of "generating" content.

Step-by-Step Training Process

👆 Click any step to expand its details and worked example.

1
Collect Massive DatasetsData

The foundation of any generative model is data. Models like GPT-4 are trained on hundreds of billions of tokens sourced from web crawls (Common Crawl), books, Wikipedia, code repositories, and curated datasets. Data quality is as important as quantity — noise and biases in data directly affect model behaviour.

Example: GPT-3 trained on ~300B tokens
Sources: CommonCrawl (60%), WebText2 (22%), Books (16%), Wikipedia (3%)
Pre-processing: deduplication, quality filtering, toxic content removal
2
Tokenize DataPre-process

Raw text is split into tokens — subword units using algorithms like Byte-Pair Encoding (BPE) or WordPiece. Each token maps to a unique integer ID in the model's vocabulary. Images are "tokenised" as patches; audio as spectrograms.

"Generative AI is powerful" →
["Generate", "ive", "▁AI", "▁is", "▁powerful"]
→ [12543, 851, 9468, 318, 4505]

Typical vocabulary size: 32,000 – 100,000 tokens
3
Train Neural NetworkTraining

The model (typically a Transformer) processes token sequences through multiple layers of self-attention and feed-forward networks. For language models, the objective is next-token prediction: given tokens 1…n, predict token n+1. Gradients are computed via backpropagation.

Input: "The cat sat on the"
Target: "mat"
Model output: probability distribution over vocabulary
P("mat") = 0.62 | P("floor") = 0.18 | P("roof") = 0.04 …
4
Compute LossEvaluation

The Cross-Entropy Loss measures how wrong the model's predictions are compared to the true labels. Lower loss = better predictions. The formula is:

L = −Σ y · log(ŷ)

Where y = true label (1-hot), ŷ = predicted probability
If true token is "mat" and model assigns P=0.62:
L = −log(0.62) ≈ 0.478
5
BackpropagationOptimise

The loss is propagated backwards through the network using the chain rule of calculus. Each parameter (weight) receives a gradient telling it which direction to move to reduce loss. Optimisers like Adam use these gradients with momentum and adaptive learning rates.

∂L/∂W = gradient of loss with respect to weight W
Adam update: W ← W − α · m̂ / (√v̂ + ε)
Where m̂, v̂ = bias-corrected first/second moment estimates
6
Update WeightsIterate

Billions of parameters are nudged slightly in the direction that reduces loss. A single forward + backward pass over a mini-batch constitutes one iteration. One full pass through the dataset is an epoch. Pre-training runs for hundreds of thousands of steps across thousands of GPUs.

GPT-3: 175B parameters, ~300B tokens, ~1000 A100 GPUs
Estimated training cost: $4–12M USD
Training time: weeks to months
7
Repeat for Billions of IterationsScale

The cycle of forward pass → compute loss → backprop → update is repeated billions of times. Convergence is tracked via validation loss. Techniques like learning rate schedules, gradient clipping, and mixed-precision training keep the process stable at scale.

Autoregressive objective: P(x) = Π P(xₜ | x<t)
Each step conditions on ALL previous tokens
Context window: 4K → 32K → 128K+ tokens over generations

Attention Mechanism
Attention is the engine of modern AI. It lets the model focus on the most relevant parts of its context when processing any token — the key innovation in the landmark "Attention Is All You Need" (2017) paper.
Interactive Attention Demo

Click any word below to see what the model "attends to" when processing it:

Self-Attention Formula
Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) · V Where: Q = Query matrix (what am I looking for?) K = Key matrix (what do I offer?) V = Value matrix (what information do I carry?) dₖ = dimension of key vectors (scaling factor)
⚠️ Exam Note: The √dₖ denominator prevents the dot-products from growing too large (which would push softmax into regions with very small gradients). This is called scaled dot-product attention.
Q, K, V Intuition
  • Query: Current word asking "who should I pay attention to?"
  • Key: Each word saying "here's what I represent"
  • Value: The actual information to pass if selected
  • Attention score = how well Q matches each K
Multi-Head Attention
  • Run h=8 (or 16, 32…) attention heads in parallel
  • Each head learns different relationship patterns
  • Concatenate outputs → linear projection
  • Captures syntax, semantics, coreference simultaneously

Glossary — Attention Terms
Softmax
Converts raw attention scores to probabilities that sum to 1. Amplifies high scores, suppresses low ones.
Dot-Product
Q·Kᵀ — measures similarity between query and key vectors. High dot-product = high relevance.
Head
One parallel attention computation. Multi-head attention runs several simultaneously.
Positional Encoding
Sinusoidal or learned vectors added to embeddings so the model knows token order (attention itself is permutation-invariant).
Context Window
Maximum sequence length the model can attend over. Quadratic memory complexity (O(n²)) limits this.
KV Cache
Cached Key and Value matrices from previous tokens, enabling fast autoregressive inference.

Transformer Architecture
The Transformer (Vaswani et al., 2017) revolutionised AI by replacing recurrence with self-attention. It remains the dominant foundation for nearly all modern generative models.
Core Transformer Components
🔤
Tokenisation
Text → integer token IDs using BPE or WordPiece. First stage of all processing.
📐
Embeddings
Token IDs → dense vectors (e.g. 768 or 4096-dim). Similar concepts cluster together in this space.
🎯
Attention Mechanism
Multi-head self-attention lets each token gather context from all other positions in parallel.
🔁
Feed-Forward Networks
Two linear transformations with a ReLU/GELU activation applied position-by-position after attention.
📍
Positional Encoding
Injects position information (sinusoidal or learned RoPE) — attention itself has no built-in order.
⚖️
Layer Normalisation
Stabilises training by normalising activations. Applied before (Pre-LN) or after (Post-LN) sub-layers.
🚀
Residual Connections
Skip connections (x + sublayer(x)) allow gradients to flow through deep networks without vanishing.
📤
Output Head
Linear layer + softmax projects hidden states to vocabulary probabilities for generation.
Four Generative Model Architectures
Autoregressive
Language Models
Generate tokens sequentially left-to-right. Each token conditions on all previous ones. Mathematical objective: P(x) = Π P(xₜ | x<t)
GPT-4 · Claude · Llama · Gemini
VAE
Variational Autoencoders
Encoder compresses input x to latent z ~ qφ(z|x). Decoder reconstructs x' ~ pθ(x|z). Enables controlled generation via latent interpolation.
β-VAE · VQ-VAE · VQGAN
GAN
Generative Adversarial Nets
Generator G creates fake samples from noise z. Discriminator D distinguishes real from fake. Trained via minimax game: min_G max_D E[log D(x)] + E[log(1−D(G(z)))]
StyleGAN · CycleGAN · DCGAN
Diffusion
Diffusion Models
Forward: gradually add Gaussian noise to data over T steps. Reverse: train model to denoise step-by-step. xₜ = √(1−βₜ)xₜ₋₁ + √βₜ ε
DALL-E · Stable Diffusion · Midjourney

Core Concept Deep-Dives
🔢  Tokens & Embeddings ▼

Tokens are the fundamental units of text for a language model — subwords, words, or characters depending on the tokeniser. The vocabulary maps each token to an integer ID.

Embeddings convert token IDs into dense real-valued vectors. The famous example: "king" − "man" + "woman" ≈ "queen" — vectors encode semantic relationships. Embedding dimensions range from 512 (small models) to 12,288 (GPT-4).

✅Exam: Tokens ≠ words. "unbelievable" may be 3 tokens: ["un", "believ", "able"]. 1 token ≈ 4 characters on average in English.
📉  Loss Functions (Cross-Entropy) ▼

Cross-Entropy Loss: L = −Σ y · log(ŷ). Measures the difference between the model's predicted probability distribution and the true distribution (one-hot). Lower loss = better calibrated predictions.

Perplexity = exp(cross-entropy loss). A perplexity of 10 means the model is as "confused" as if choosing uniformly between 10 options. Lower perplexity = better language model.

✅Exam: For GANs, the loss is different — the discriminator minimises classification loss, while the generator minimises log(1 − D(G(z))) or maximises log(D(G(z))).
🎛️  Fine-Tuning & Alignment (RLHF / SFT) ▼

After pre-training on massive datasets, models are adapted to specific tasks and human preferences:

  • Supervised Fine-Tuning (SFT): Train on curated (prompt, ideal response) pairs. Teaches the model the desired format and behaviour.
  • RLHF: Human raters compare model outputs → train a reward model → use PPO reinforcement learning to maximise reward. Used by ChatGPT, Claude.
  • DPO: Direct Preference Optimisation — simpler alternative to RLHF without a separate reward model.
✅Exam: SFT = teaches WHAT to say. RLHF = teaches HOW to say it (helpfully, harmlessly, honestly). Used heavily by OpenAI and Anthropic.
👻  Hallucination in Generative AI ▼

Hallucination occurs when the model generates factually incorrect or fabricated information with apparent confidence. Root causes:

  • Probabilistic prediction: Models sample from distributions — the most probable token ≠ the true token
  • Imperfect training data: Misinformation in web data gets absorbed
  • Lack of grounding: No real-time access to verified facts

Mitigations: RAG (retrieval-augmented generation), tool use, chain-of-thought, fine-tuning on factual datasets, human-in-the-loop verification.

✅Exam: Hallucination is a key challenge and ethical concern. Know both causes AND solutions for the exam.
📚  RAG — Retrieval-Augmented Generation ▼

RAG combines a retrieval system (vector database + semantic search) with a generative LLM. When a query arrives, relevant documents are fetched and injected into the prompt — grounding the LLM in current, verified information.

User → "What is Anthropic's latest model?"
Retriever → [fetches docs from vector DB about recent Anthropic releases]
LLM → generates answer grounded in retrieved documents
  • Reduces hallucination by providing context
  • Enables knowledge updates without retraining
  • Used in: enterprise AI, search assistants, document QA
🌐  Multimodal Generative AI ▼

Modern systems can process and generate across multiple modalities — text, images, audio, video, documents — in a unified framework. This is achieved by:

  • Encoding each modality into a shared embedding space
  • Cross-modal attention bridges modalities
  • Separate decoders for each output modality

Applications: Image captioning, speech-to-text, text-to-video (Sora), vision-language models (GPT-4V, Gemini).

⚠️  Challenges: Technical & Ethical ▼
Technical Challenges
  • Hallucinations & factual errors
  • Bias inherited from training data
  • Extremely high compute costs
  • Data quality & provenance issues
  • Context window limitations
Ethical Challenges
  • Deepfakes & synthetic media abuse
  • Copyright infringement of training data
  • Misinformation at scale
  • Privacy risks from data memorisation
  • Bias amplification & fairness concerns
🚨 Exam Must-Know Tips
🎯
Know the 4 Model Types
Autoregressive, VAE, GAN, Diffusion — know each one's mechanism, strengths, and a real-world example.
🧮
Attention Formula
Memorise Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V. Know what Q, K, V stand for and why we scale by √dₖ.
📊
Transformers vs RNNs
Transformers use parallel processing (attention) vs RNNs which process sequentially. Transformers handle long-range dependencies better.
🔄
Training vs Inference
Training: forward + backward + weight update. Inference: forward pass only. RLHF adds a reward model and RL loop on top.
📝
RLHF Steps
1) SFT → 2) Collect preference data → 3) Train reward model → 4) Fine-tune LLM with PPO. OpenAI and Anthropic both use this.

Glossary — Advanced Terms
RLHF
Reinforcement Learning from Human Feedback. Aligns model behaviour with human preferences using PPO optimization.
Perplexity
exp(cross-entropy). Measures model uncertainty — lower = better. GPT-2 had ~29; GPT-3 achieved ~20 on Penn Treebank.
Temperature
Scales logits before softmax. T→0: deterministic. T=1: default. T>1: random/creative.
KL Divergence
Measures difference between two probability distributions. Used in VAE loss and RLHF penalty term.
Mode Collapse
GAN failure where generator produces limited variety — maps all inputs to few outputs. Training instability issue.
Zero-Shot / Few-Shot
Zero-shot: no examples given. Few-shot: 1–5 examples in context. Both leverage in-context learning.
