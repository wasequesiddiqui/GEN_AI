Maximum Likelihood Estimation (MLE)

The fundamental principle that powers training of LLMs, VAEs, Diffusion Models — making data most probable under your model.

📌 What is Maximum Likelihood Estimation?

MLE is a method for estimating the parameters θ of a statistical model by maximising the likelihood function — the probability of observing the given data under those parameters. It is the statistical engine behind almost all modern generative AI training.

🎯 Core objective: θ* = argmaxθ P(D | θ)

⚖️ MLE vs Alternatives

MethodObjectivePriorUse Case
MLEMax P(D|θ)NoGenerative AI, classic stats
MAPMax P(θ|D) ∝ P(D|θ)P(θ)YesBayesian regularisation

💡 Worked Example: Gaussian

Data: [2, 4, 6] from N(μ, σ²). MLE for μ = sample mean = 4. MLE for σ² = 1/n Σ (xᵢ−μ)² = 8/3 ≈ 2.667.

μ̂ = (2+4+6)/3 = 4, σ̂² = ( (4+0+4) )/3 = 8/3

🔑 Glossary

Likelihood L(θ)
∏ p(xᵢ|θ) — probability of data given θ
Log‑Likelihood ℓ(θ)
∑ log p(xᵢ|θ) — stable, turns product into sum
Score Function
∇ℓ(θ) — gradient, set to zero for MLE
Fisher Information
Variance of score, measures curvature

🔁 MLE Pipeline — step by step

Click each step to expand details.

1
Model + Data
▼

Assume i.i.d observations D = {x₁,…,xₙ} from a parametric family p(x|θ). Example: coin toss (Bernoulli) with unknown p.

2
Write Likelihood
▼

L(θ) = ∏ p(xᵢ|θ). For coin with heads count H, L(p) = pᴴ(1-p)ⁿ⁻ᴴ.

3
Log‑Likelihood
▼

ℓ(θ)=∑ log p(xᵢ|θ). For coin: ℓ(p)= H log p + (n−H) log(1−p).

4
Optimise (Score = 0)
▼

∂ℓ/∂p = H/p − (n−H)/(1−p)=0 → p̂ = H/n. For neural networks, use gradient ascent.

5
MLE Estimate & Generation
▼

θ̂_MLE maximises data probability. In generative AI, sample from pθ̂(x) to create new realistic outputs.

✨ Concrete: 3 coin tosses: H,H,T → p̂ = 2/3. That's the MLE.

📈 Why MLE powers Generative AI

  • LLMs: maximise ∑ log P(wₜ | context)
  • VAEs: maximise ELBO (a lower bound to likelihood)
  • Diffusion: denoising objective = MLE of reverse process

📐 Gaussian MLE (closed form)

For N(μ,σ²): μ̂ = sample mean, σ̂² = (1/n)∑(xᵢ−μ̂)². Works because log‑likelihood is quadratic.

🏛️ MLE in Generative Model Architectures

Autoregressive (LLMs)
p(x) = ∏ p(xₜ|x<ₜ) → maximise cross‑entropy loss.
ℒ = -∑ log pθ(xₜ|x<ₜ)
VAE
ELBO = 𝔼[log p(x|z)] - D_KL(q(z|x)‖p(z)) → lower bound of log‑likelihood.
Diffusion
Denoising objective = variational bound on negative log‑likelihood. Equivalent to predicting added Gaussian noise.
GAN
Implicit MLE: generator indirectly maximises likelihood via adversarial training.

🔧 Component Breakdown

  • Data + parametric model family
  • Likelihood / log‑likelihood construction
  • Optimiser (SGD, Adam) maximises ℓ(θ)
  • MLE estimate → used for sampling / inference

📘 Key Formulas & Relationships

θ̂_MLE = argmax Σ log p(xᵢ|θ)    D_KL(P_data ‖ P_model) = 𝔼[log(P_data/P_model)]

Minimising KL divergence between data distribution and model distribution is equivalent to MLE.

✅ Advantages

  • Statistically consistent (converges to true θ as n→∞)
  • Asymptotically efficient (lowest variance)
  • Invariance: g(θ̂_MLE) = MLE of g(θ)

⚠️ Limitations

  • Overfits small datasets (MAP can help)
  • Local optima in deep models
  • Requires correct model specification
