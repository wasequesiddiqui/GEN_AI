🔧 Training GAN

Training General Adversarial Network – Hyperparameters

Master the delicate balance of generator and discriminator training for stable, high-quality image synthesis.

Training a GAN involves a two-player minimax game where the generator learns to fool the discriminator and the discriminator learns to tell real from fake. This guide covers the 10 most important hyperparameters for stable GAN training, from latent dimension to gradient penalty, with practical PyTorch examples and a runnable DCGAN demo.

📊 GAN training overview — noise sampling, generator synthesis, and discriminator feedback loop

🎲

① Latent Dimension (z-dim)

Size of the noise vector fed into the generator. Larger dimensions allow richer diversity but increase training complexity.

import torch
z = torch.randn(64, 100) # batch=64, z_dim=100
💡Start with 100 (DCGAN default). For higher resolution, try 128–256.
🏗️

② Generator Depth / Channels

Number of transposed convolution layers in the generator. Deeper generators synthesize higher-resolution details but are harder to train.

# DCGAN-style generator: 4-5 layers
gen_channels = [512, 256, 128, 64, 3]
✅4–6 layers work well for 64×64 images. Add layers for higher resolutions.
🔍

③ Discriminator Depth / Channels

Number of convolutional layers in the discriminator. Must be balanced with the generator to avoid overpowering it.

# DCGAN-style discriminator: 4-5 layers
disc_channels = [64, 128, 256, 512, 1]
⚠️A discriminator that is too strong can drive the generator loss to zero, halting learning.
🎯

④ Learning Rate (G & D)

Separate learning rates for generator and discriminator. Asymmetric rates often stabilize training.

g_optim = Adam(lr=0.0002, betas=(0.5, 0.999))
d_optim = Adam(lr=0.0002, betas=(0.5, 0.999))
💡Use 0.0002 with β1=0.5 as the DCGAN standard. Try D LR 2–5× higher than G LR.
📦

⑤ Batch Size

Number of real and fake samples per iteration. Larger batches give more stable gradient estimates for both networks.

dataloader = DataLoader(dataset, batch_size=64, shuffle=True)
💡Use 32–128 for image GANs. Larger batches improve discriminator gradient quality.
🔄

GANs typically require many iterations — often tens of thousands — because two networks train simultaneously.

How many discriminator updates per generator update. Training D more often can help it provide better gradient signals.

💡n_critic=5 is the WGAN standard. For vanilla GANs, use 1:1 ratio.
🔧

⑧ Optimizer Choice

Adam is standard for GANs. The β1 momentum term strongly affects training dynamics.

# DCGAN standard
Adam(lr=0.0002, betas=(0.5, 0.999))
# WGAN: RMSprop avoids momentum issues
RMSprop(lr=0.00005)
✅Adam with β1=0.5 (not 0.9) for DCGAN. RMSprop for WGAN to avoid oscillation.
📉

⑨ Loss Function

The adversarial loss defines the minimax objective. Choices: minimax, non-saturating, Wasserstein, or hinge loss.

# Non-saturating GAN loss (recommended)
d_loss = -torch.mean(log(D(real)) + log(1-D(fake)))
g_loss = -torch.mean(log(D(G(z))))
💡Use non-saturating loss for better generator gradients. WGAN loss for stability.
🛡️

⑩ Gradient Penalty / Spectral Norm

Enforces Lipschitz continuity on the discriminator. Crucial for WGAN-GP stability and mode collapse prevention.

gp = lambda * ((grad.norm(2) - 1) ** 2).mean()
d_loss = wasserstein_loss + 10.0 * gp
✅λ=10 is standard for WGAN-GP. Spectral norm is a lighter-weight alternative.

🏗️ GAN Architecture & Training Structure

A GAN is a two-player minimax game. The generator G maps a random noise vector z to a synthetic sample G(z), while the discriminator D outputs the probability that a given sample is real. Both networks are trained simultaneously through alternating gradient updates.

⚔️ GAN Core Equations
Generator Mapping:
G(z) = xfake   where   z ~ pz(z)
Discriminator Output:
D(x) = P(real | x)   ∈ [0, 1]
Minimax Objective:
minG maxD   Ex~pdata[log D(x)] + Ez~pz[log(1−D(G(z)))]
Non-Saturating G Loss:
LG = −Ez[log D(G(z))]

📖 Equation Element Breakdown – What every symbol means

The minimax formulation is the heart of GAN training. Understanding each component helps diagnose instability, mode collapse, and convergence issues.

🔹 Generator & Latent Space
z
Noise vector sampled from a prior distribution (typically Gaussian or uniform).
Shape: (batch_size, z_dim) — typically z_dim=100
pz(z)
Prior distribution over the latent space. Usually N(0, I) or U(−1, 1).
Standard normal or uniform
G(z)
Generator function: maps latent vector z to a synthetic data sample in the image space.
Shape: (batch_size, C, H, W) for images
xfake
Synthetic/fake sample produced by the generator. Should become indistinguishable from real data.
Same shape as real data
🔹 Discriminator & Objective
D(x)
Discriminator: outputs a scalar score representing the probability that x comes from the real data distribution.
Output: scalar probability ∈ [0, 1]
pdata
True (unknown) data distribution from which the training set is sampled.
Empirical distribution of training images
log D(x)
The discriminator is rewarded for assigning high probability to real samples.
Maximized by D, minimized by G (indirectly)
log(1−D(G(z)))
Penalizes the discriminator for being fooled by fake samples. Drives the generator to improve.
D tries to make this term 0; G tries to make it −∞
🔹 Training Dynamics
minG maxD
Two-player zero-sum game. D maximizes its ability to detect fakes; G minimizes D's success rate.
Alternating optimization — no single loss curve
LG (non-sat.)
Non-saturating generator loss: stronger gradients when D is confident, weaker when G is doing well.
Preferred over minimax G loss in practice
Nash Equilibrium
Ideal state where pg = pdata and D(x) = 0.5 everywhere. Rarely reached but guides tuning.
Theoretical optimum of the minimax game
💡 Key insight: GAN training succeeds when neither network dominates. If D loss → 0, the generator receives vanishing gradients. If G loss → 0, the discriminator is too weak. Balance is everything.
🔍

Generator Architecture

Uses transposed convolutions (or upsampling + conv) to progressively increase spatial resolution from the latent vector.

💡Use BatchNorm in G (not D) and ReLU in intermediate layers, tanh at output for normalized images.
🔄

Discriminator Architecture

Mirrors the generator but uses strided convolutions to downsample, outputting a single scalar probability.

💡Use LeakyReLU(0.2) instead of ReLU in D. Avoid BatchNorm in D's first and last layers.

⚡ Training Process Hyperparameters

These settings govern how the adversarial game unfolds and how quickly each network learns.

🎯

Learning Rate (Dual)

GANs use separate (often different) learning rates for G and D. Asymmetric rates can help when one network dominates.

g_optim = Adam(lr=0.0002, betas=(0.5, 0.999))
d_optim = Adam(lr=0.0002, betas=(0.5, 0.999))
✅Start both at 0.0002. If D converges too fast, lower D LR or raise G LR to 0.001.
📦

Batch Size

Large batches give the discriminator better gradient estimates, improving training signal quality.

dataloader = DataLoader(dataset, batch_size=64)
🔄

Epochs / Iterations

GANs need many iterations. Track sample quality — loss values alone are unreliable for GAN convergence.

for epoch in range(200):
for i, real_imgs in enumerate(dataloader):
# Alternating update loop
⚠️Loss values oscillate by design. Monitor generated image quality, not loss curves, to judge convergence.
🔧

Optimizer & Momentum

Adam with reduced β1 (0.5 vs. default 0.9) reduces momentum, helping the generator adapt to shifting discriminator landscapes.

# DCGAN standard: Adam, β1=0.5
Adam(lr=0.0002, betas=(0.5, 0.999))

🛡️ Regularization & Stabilization Techniques

GAN training is inherently unstable. These techniques prevent mode collapse and smooth the optimization landscape.

📐

Gradient Penalty (WGAN-GP)

Penalizes the discriminator for having gradients with norms deviating from 1, enforcing 1-Lipschitz continuity.

# Gradient penalty term
grad = autograd.grad(d_out, interpolates,
create_graph=True)[0]
gp = ((grad.norm(2) - 1) ** 2).mean()
d_loss += 10.0 * gp
💡λ=10 is the standard GP weight. WGAN-GP is the go-to for stable GAN training.
🔗

Spectral Normalization

Normalizes each discriminator layer's weight matrix by its spectral norm, enforcing Lipschitz constraint without gradient penalty.

from torch.nn.utils import spectral_norm
layer = spectral_norm(nn.Conv2d(64, 128, 4))
✅Lighter than WGAN-GP; pair with hinge loss for SNGAN. Standard in modern GAN architectures.
🏷️

Label Smoothing

Instead of using 1.0 for real and 0.0 for fake labels, use 0.9 and 0.1 to reduce discriminator overconfidence.

# One-sided label smoothing
real_labels = torch.ones(batch_size) * 0.9
fake_labels = torch.zeros(batch_size)
💡Smooth only real labels (0.9). Smoothing fake labels can push generated distribution away from real.
🪞

Feature Matching

Instead of maximizing D output, train G to match the expected features at an intermediate D layer. Reduces mode collapse.

# Match intermediate D features
real_feats = D.intermediate(real_imgs)
fake_feats = D.intermediate(fake_imgs)
g_loss = F.mse_loss(fake_feats, real_feats.mean(0))

💻 Full Code – DCGAN on CIFAR-10 with PyTorch

A runnable DCGAN training script. Key hyperparameters are annotated with numbers matching the cards above.

#!/usr/bin/env python3 """DCGAN Training on CIFAR-10 – all hyperparameters labeled.""" import torch import torch.nn as nn import torch.optim as optim import torchvision import torchvision.transforms as transforms from torch.utils.data import DataLoader # ── ① Latent dimension ── Z_DIM = 100 # ── ② Generator channel progression ── GEN_CHANNELS = [512, 256, 128, 64, 3] # ── ③ Discriminator channel progression ── DISC_CHANNELS = [64, 128, 256, 512] class Generator(nn.Module): def __init__(self): super().__init__() self.main = nn.Sequential( nn.ConvTranspose2d(Z_DIM, GEN_CHANNELS[0], 4, 1, 0, bias=False), nn.BatchNorm2d(GEN_CHANNELS[0]), nn.ReLU(True), # ...additional transposed conv layers... nn.ConvTranspose2d(GEN_CHANNELS[-2], GEN_CHANNELS[-1], 4, 2, 1, bias=False), nn.Tanh() ) def forward(self, z): return self.main(z.view(z.size(0), Z_DIM, 1, 1)) class Discriminator(nn.Module): def __init__(self): super().__init__() self.main = nn.Sequential( nn.Conv2d(3, DISC_CHANNELS[0], 4, 2, 1, bias=False), nn.LeakyReLU(0.2, inplace=True), # ...additional conv layers... nn.Conv2d(DISC_CHANNELS[-1], 1, 4, 1, 0, bias=False), nn.Sigmoid() ) def forward(self, x): return self.main(x).view(-1) # ── Dataset ── transform = transforms.Compose([ transforms.Resize(64), transforms.ToTensor(), transforms.Normalize([0.5]*3, [0.5]*3) ]) dataset = torchvision.datasets.CIFAR10(root='./data', train=True, download=True, transform=transform) dataloader = DataLoader(dataset, batch_size=64, shuffle=True) # ⑤ Batch size G = Generator() D = Discriminator() # ── ④ Learning rates & ⑧ Optimizer ── g_optim = optim.Adam(G.parameters(), lr=0.0002, betas=(0.5, 0.999)) d_optim = optim.Adam(D.parameters(), lr=0.0002, betas=(0.5, 0.999)) # ── ⑨ Loss function (non-saturating) ── criterion = nn.BCELoss() # ── ⑥ Epochs ── EPOCHS = 200 for epoch in range(EPOCHS): for real_imgs, _ in dataloader: batch_size = real_imgs.size(0) real_labels = torch.ones(batch_size) * 0.9 # Label smoothing fake_labels = torch.zeros(batch_size) # ── Train Discriminator ── D.zero_grad() d_real_loss = criterion(D(real_imgs), real_labels) z = torch.randn(batch_size, Z_DIM) # ① Latent dim d_fake_loss = criterion(D(G(z).detach()), fake_labels) d_loss = d_real_loss + d_fake_loss d_loss.backward(); d_optim.step() # ── ⑦ D/G update ratio (1:1 for DCGAN) ── # ── Train Generator ── G.zero_grad() z = torch.randn(batch_size, Z_DIM) g_loss = criterion(D(G(z)), real_labels) # Non-saturating g_loss.backward(); g_optim.step() print(f"Epoch {epoch+1}/{EPOCHS} | D Loss: {d_loss:.4f} | G Loss: {g_loss:.4f}")
