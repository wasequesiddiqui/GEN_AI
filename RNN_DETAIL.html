What is an RNN?

A Recurrent Neural Network (RNN) is built for sequential, ordered data. Unlike feedforward networks, it maintains a hidden state that carries information across time steps, giving it a form of memory.

Core Idea

At each time step t, the RNN processes current input xt and previous hidden state ht-1, producing new state ht.


Formula: ht = tanh(Whh · ht-1 + Wxh · xt + bh)


The same weights reuse at every step — weight sharing makes RNNs parameter-efficient and able to handle any sequence length.

Why RNNs Matter

  • Handle variable-length sequences natively
  • Capture temporal dependencies in ordered data
  • Parameter-efficient via weight sharing across time
  • Foundation for LSTM, GRU, and Seq2Seq models
  • Powers NLP, speech recognition, and time-series forecasting

Worked Example — Sentiment Analysis

Input: "The film was surprisingly brilliant."

t=1: The → h₁t=2: film → h₂ t=3: was → h₃t=4: surprisingly → h₄ t=5: brilliant → h₅

The final hidden state h₅ encodes the full sentence context. A Dense+Sigmoid layer maps it to Positive (0.91). "Surprisingly" modifies "brilliant" — the RNN must carry context from step 4 to handle this. This long-range dependency is exactly what LSTM and GRU are designed to preserve.

Glossary

Hidden State (h)

The "memory" vector passed between steps, encoding what the network has seen.

Time Step (t)

One position in the sequence — one word, data point, or audio frame.

Weight Sharing

The same W matrices applied at every step — the core efficiency of RNNs.

Unrolling

Visualising the RNN as a chain of repeated cells, one per time step, for computing gradients.

Many-to-One

Sequence input → single output (e.g. sentiment). Most common RNN topology.

Seq2Seq

Encoder compresses a sequence; decoder generates output sequence (e.g. translation).

RNN Processing Pipeline

Click each step to expand full detail. Follow the flow from raw data to a deployed, tuned RNN model.

1
Data Preparation & Tokenisation▼

Convert raw sequential data into numerical tensors.

  • NLP: tokenise → integer indices → embedding lookup
  • Time series: normalise values; create sliding windows of length T
  • Padding: pad_sequences(maxlen=50, padding='post')
  • Split: typically 70/15/15 train / val / test

Output tensor shape: (batch_size, sequence_length, n_features)

2
Choose RNN Variant & Topology▼

Select the right variant based on sequence length and task:

  • SimpleRNN — very short sequences (<20 steps), demos only
  • LSTM — long sequences, NLP, speech recognition
  • GRU — similar to LSTM but faster; excellent default for time series
  • Bidirectional — sees future context; best for NLP classification
  • Stacked layers — 2–4 layers; set return_sequences=True on all except last

Topologies: Many-to-one (sentiment), many-to-many sync (NER), one-to-many (captioning), async many-to-many (translation)

3
Initialise Hyperparameters▼

CGAI recommended starting defaults:

  • Hidden units: 64 | Layers: 1 | Learning rate: 0.001 (Adam)
  • Batch size: 32 | Dropout: 0.2
  • Epochs: 100 + EarlyStopping(patience=5)

Tuning order: LR → Hidden Units → Batch Size → Dropout → Layers. One at a time.

4
Forward Pass — Sequence Processing▼

At each time step t:

  • h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)
  • Optional: y_t = W_hy · h_t + b_y
  • Pass h_t to the next step

For many-to-one, only the final hT feeds the output Dense layer.

5
Loss Computation▼

Choose loss function to match output type:

  • Binary classification → binary_crossentropy + sigmoid
  • Multi-class → categorical_crossentropy + softmax
  • Regression / forecasting → mae or mse
  • Language modelling → sparse_categorical_crossentropy

Monitor: Training Loss, Validation Loss, Accuracy (clf), MAE/RMSE (regression).

6
Backpropagation Through Time (BPTT)▼

Gradients computed by "unrolling" the network and applying chain rule backwards through all steps.

  • Product of many small W multiplications → vanishing gradient
  • Product of large W multiplications → exploding gradient (NaN loss)
  • Truncated BPTT: limit backprop to k steps for very long sequences
  • Gradient clipping: Adam(clipvalue=0.5) prevents explosion
7
Evaluate, Diagnose & Iterate▼

Read learning curves and diagnose:

  • Both losses high: underfitting → more capacity or training time
  • Train << Val loss: overfitting → dropout, less capacity, early stopping
  • Unstable / NaN: exploding gradients → clip gradients, lower LR
  • Plateau early: vanishing gradient → switch to LSTM / GRU

Use Bayesian Optimisation (Optuna / Ray Tune) for systematic search.

Core Mechanism: Gradient Problems & Solutions

The central challenge of training RNNs — and the reason LSTM & GRU were invented. Select a scenario to explore.

⚡ Interactive: Gradient Scenarios

Healthy Training

Gradients flow cleanly from the loss back through all time steps. Each weight receives a proportional update — the network learns from both recent and distant sequence elements.

Signs of healthy training:
• Validation loss decreases steadily each epoch
• Train and val loss remain close together
• Model continues improving on long-range tasks

Typical stable gradient magnitude: 0.01 – 1.0

Vanishing Gradient

Gradients shrink exponentially as they travel backwards through time steps.

Root cause: With tanh and W eigenvalues <1, each backward step multiplies the gradient by a fraction. After 10–20 steps, the product approaches zero.


Effect: Early inputs stop influencing learning. The model forgets long-range context. Loss plateaus.

Exploding Gradient

Gradients grow exponentially — weights update in massive destabilising leaps.

Symptom: Loss spikes to NaN after a few batches. Weights become ±∞.


Fix: Gradient clipping caps the gradient norm before the update:
Adam(clipvalue=0.5) or clipnorm=1.0

BPTT

Backpropagation Through Time — chain rule applied across all unrolled time steps.

Vanishing Gradient

Gradient → 0 over many steps; early inputs stop contributing to weight updates.

Exploding Gradient

Gradient → ∞; training collapses with NaN loss and erratic weights.

Gradient Clipping

Clamps gradient magnitude before the optimiser update. Cheap fix for explosion.

LSTM's long-range memory highway — flows with near-linear, gated interactions.

Truncated BPTT

RNN Architecture Deep Dive

Click each card to expand gate equations, use-case guidance, and Keras syntax for each variant.

Simple

SimpleRNN

Single hidden state. One weight matrix. Minimal overhead.

  • Formula: ht = tanh(W·[ht-1, xt] + b)
  • Memory: Low — vanishes beyond ~10 steps
  • Tuning: ★☆☆ Easy

When to use: Demos and toy problems only. Rarely used in production.

Failure mode: Vanishing gradient prevents learning dependencies >10 steps.

SimpleRNN(64, activation='tanh', input_shape=(T, F))
Recommended

LSTM

Long Short-Term Memory — 3 gates + dedicated cell state highway.

  • Forget gate ft — erases irrelevant cell state entries
  • Input gate it — writes new info into cell state
  • Output gate ot — exposes relevant part as hidden state
f_t = σ(W_f·[h_{t-1},x_t] + b_f) ← forget
i_t = σ(W_i·[h_{t-1},x_t] + b_i) ← input
C_t = f_t⊙C_{t-1} + i_t⊙tanh(W_C·[h_{t-1},x_t]+b_C) ← cell
o_t = σ(W_o·[h_{t-1},x_t] + b_o) ← output
h_t = o_t ⊙ tanh(C_t)

Best for: NLP, speech, long-sequence classification, language modelling.

LSTM(128, return_sequences=True)  # stacked
LSTM(64)  # final layer
Efficient

GRU

Gated Recurrent Unit — 2 gates, no separate cell state. ~25% fewer parameters than LSTM.

  • Reset gate rt — how much past state to forget
  • Update gate zt — blend old h and new candidate
z_t = σ(W_z·[h_{t-1},x_t]) ← update gate
r_t = σ(W_r·[h_{t-1},x_t]) ← reset gate
h_t = (1-z_t)⊙h_{t-1} + z_t⊙tanh(W·[r_t⊙h_{t-1},x_t])

When GRU beats LSTM: Smaller datasets, time series, when training speed matters.

Stacked (Deep) RNNs

Multiple RNN layers stacked vertically. Each extracts higher-level sequence abstractions. All intermediate layers need return_sequences=True.

Risk: deeper stacks amplify vanishing gradients. Use LSTM/GRU, keep to ≤4 layers. Two stacked LSTMs is a common production baseline.

Bidirectional RNNs

Two RNNs run in parallel — forward (1→T) and backward (T→1). Outputs concatenated or summed, giving each position access to past and future context.

Best for NLP classification. Cannot be used for autoregressive generation where future tokens are unknown at inference.

Bidirectional(LSTM(64))

Forget Gate

LSTM gate deciding how much of C_{t-1} to discard at each step.

Cell State (C)

LSTM's long-term memory lane — flows through time with minimal modification.

Update Gate

GRU gate blending old hidden state with new candidate state at each step.

return_sequences

True = h at every step (needed for stacking). False = only final h.

Bidirectional

Keras wrapper running the cell forwards AND backwards, doubling context.

The 10 Core Hyperparameters (A–J)

A

Learning Rate

0.0001 → 0.1

Controls weight update size. Adam default: 0.001. Too high = instability. Too low = very slow convergence.

B

Hidden Units

32 → 512

Memory capacity per RNN cell. Start with 64. Large values risk overfitting on small datasets.

C

Number of Layers

1 → 4

Depth captures hierarchical patterns but adds vanishing gradient risk. Two stacked LSTMs is a common baseline.

D

Sequence Length

Task-dependent

How many past steps the model sees. Longer = more context but more memory and compute. Tune carefully.

E

Batch Size

16 → 256

Samples per gradient step. Small = noisier but better generalisation. Large = faster but rougher updates.

F

Epochs

10 → 200

Full dataset passes. Use Early Stopping with patience=5 in practice rather than a fixed epoch count.

G

Optimizer

Adam / RMSprop

Adam and RMSprop are best for RNNs. Adam adapts per-parameter learning rates automatically.

H

Dropout Rate

0.1 → 0.5

Randomly zeroes neurons to prevent overfitting. Too high = underfitting. 0.2 is a safe start.

I

Activation

tanh (default)

tanh is standard for RNN hidden states (outputs -1 to 1). LSTM gates use sigmoid. Output layer varies by task.

J

Gradient Clipping

clipnorm=1.0

Caps gradient magnitude to prevent explosion. Use for SimpleRNN and deep LSTM/GRU stacks.

Best Practices Checklist

  • Start simple: 1 layer, 64 units, Adam 0.001
  • Tune one hyperparameter at a time in recommended order
  • Always use Early Stopping on val_loss
  • Use LSTM/GRU for any sequence >20 steps
  • Never tune on the test set — use validation only
  • Analyse learning curves after every experiment
  • Normalise all numerical inputs (especially time series)
  • Use Bayesian Optimisation for systematic large-scale search

Task-Based Recommendations

Small Dataset — smaller network, higher dropout, aggressive early stopping
Large Dataset — deeper model, larger hidden states, lower regularisation
NLP Tasks — LSTM/GRU preferred, longer sequence windows, word embeddings
Time Series — GRU often best; tune sequence length carefully; normalise inputs

Glossary

Early Stopping

Stops training when val_loss stops improving; restore_best_weights reverts to optimal epoch.

Overfitting

Train loss << val loss — model memorised training data, fails to generalise.

Underfitting

Both train and val loss high — model too simple or insufficiently trained.

Bayesian Optimisation

Builds a probabilistic surrogate model to efficiently select the next HP trial point.

Optuna / Ray Tune

Leading libraries for automated HP search using Bayesian and other advanced strategies.

Learning Curve

Plot of train and val loss per epoch — the primary diagnostic for all tuning decisions.
