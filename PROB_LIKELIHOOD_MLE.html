Probability vs Likelihood vs MLE

Three related concepts, different perspectives — the foundation of statistical learning and generative AI training.
📊 Probability = P(Data|θ) 📈 Likelihood = L(θ|Data) 🎯 MLE = argmax L(θ) 🪙 Coin‑toss example 🤖 Generative AI foundation

📌 The Core Distinction

Probability answers: given known parameters, how likely is a specific outcome?
Likelihood answers: given observed data, which parameter values are most plausible?
Maximum Likelihood Estimation (MLE) finds the single parameter value that makes the data most probable.

💡 Key insight: Probability predicts data (parameters fixed). Likelihood evaluates parameters (data fixed). MLE chooses the best parameter.

💡 Worked Example: Coin Toss

Probability: If p=0.8, P(8 heads in 10 tosses) = C(10,8)·0.8⁸·0.2² ≈ 0.302

Likelihood: After observing 8 heads, L(p=0.8) = 0.302. Likelihood values change with p.

MLE: The p that maximises likelihood = 8/10 = 0.8.

MLE: θ* = argmaxθ L(θ) = argmaxθ P(Data|θ)

🔁 From Probability to MLE – Step by Step

Click each step to expand details.

1
Define a probability model
▼

Choose a family: e.g., Bernoulli for coin toss: P(x=1|p)=p, P(x=0|p)=1-p.

2
Observe data (fix the outcomes)
▼

Example: 10 tosses → 8 heads (H) and 2 tails (T). Data is fixed.

3
Write the likelihood function
▼

L(p) = p⁸ (1-p)². This is the probability of the data as a function of p.

4
Maximise the likelihood
▼

Take derivative d/dp log L = 8/p - 2/(1-p) = 0 → p̂ = 8/10 = 0.8.

5
Use the MLE for generation
▼

With p̂=0.8, you can generate new coin tosses (or in AI: generate images/text).

✨ This pipeline is exactly what LLMs, VAEs, and diffusion models do: define a probability model, observe training data, maximise likelihood, then generate.

🧬 Core Mechanism: Likelihood vs Probability

Interactive demo: adjust the observed number of heads and total tosses. The likelihood curve shows how different parameter values explain the data. The peak is the MLE.

Heads: 8/10
Likelihood L(p) = p^H (1-p)^(n-H)   →   MLE p̂ = H/n

📈 Probability (prediction)

If p=0.8, P(8 heads | p=0.8) = 0.302. This is a number that tells you how likely that outcome is under the assumed parameter.

📉 Likelihood (evaluation)

After observing 8 heads, L(p=0.8) = 0.302. But L(p=0.7) ≈ 0.233. Likelihood is a function of p; its maximum gives the MLE.

🏛️ How Probability, Likelihood, MLE Fit in Generative AI

Step 1 – Probability Model
Define p(x|θ) (e.g., Gaussian for images, Categorical for tokens).
Step 2 – Likelihood
Given training data D, compute L(θ)=∏ p(xᵢ|θ).
Step 3 – MLE Training
Maximise log L(θ) via SGD/Adam → optimal θ*.
Step 4 – Generation
Sample new x ∼ p(x|θ*) — produces realistic data.

🔧 Component Map

  • Data → fixed observations
  • Parameter space → θ (weights of neural net)
  • Likelihood function → training objective (e.g., cross‑entropy)
  • Optimiser → gradient ascent on log‑likelihood
  • MLE estimate → final trained model

📘 Crucial Distinctions & Pitfalls

  • Likelihood is not a probability – it doesn’t integrate to 1 over θ.
  • MLE can overfit – especially with small data. MAP adds a prior.
  • Log‑likelihood is used for numerical stability and to turn products into sums.
  • KL divergence minimisation is equivalent to MLE: D_KL(P_data || P_model).

✅ Advantages of MLE

  • Consistent (converges to true θ as n→∞)
  • Asymptotically efficient (lowest variance)
  • Invariant under reparameterisation

⚠️ Limitations

  • Overfits small datasets
  • Requires correct model specification
  • Can get stuck in local optima for deep nets
⚡ Exam must‑know: MLE = maximising log‑likelihood = minimising cross‑entropy = minimising KL(P_data ‖ P_model). This is the basis for training LLMs, VAEs, and diffusion models.
