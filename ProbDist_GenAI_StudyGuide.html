Overview
What probability distributions are, why they matter, and how they differ from alternatives

What Is a Probability Distribution?

A probability distribution is a mathematical function that describes how likely different outcomes are for a random variable. It models uncertainty, variability, and patterns in data — answering the question: "How probable is each possible value?"

Key Insight: Generative AI models do not memorise data. Instead, they learn the underlying probability distribution of the training data so they can sample new, realistic examples from it.

Formally, a model with parameters θ tries to learn a distribution p_θ(x) that approximates the true data distribution p_data(x).

Goal: p_θ(x) ≈ p_data(x)

🪙 Everyday Examples

  • Coin Toss: P(Heads) = 0.5, P(Tails) = 0.5 — uniform Bernoulli
  • Human Height: Approximately Gaussian (bell curve)
  • Word Occurrence: Follows complex statistical distributions (Zipf)
  • Pixel Values: High-dimensional joint distributions
  • Next Word Prediction: Categorical over a vocabulary of 50 k+ tokens

🎯 Why It Matters for AI

  • Capture Uncertainty: Real-world data is noisy; distributions model this naturally
  • Realistic Generation: Sampling from learned distributions creates diverse new data
  • Feature Relationships: Joint distributions encode correlations between variables
  • Avoid Memorisation: Models generalise beyond training examples
  • Principled Training: Objectives like MLE and KL divergence have clean mathematical foundations

Pipeline / Process
Step-by-step: how a generative model learns and uses probability distributions

How Generative Models Learn Distributions

Click each step to expand the detailed explanation and worked example using next-word prediction in a language model.

1
Collect & Represent Data as Samples
▼

Every training example is treated as a sample x ~ p_data(x). We never know p_data directly — we only see samples from it.

LLM Example: A sentence like "The cat sat on the mat" is a sample. Each token is an observation from the true language distribution.

  • Text → token IDs (discrete) → categorical distributions
  • Images → pixel arrays → continuous distributions
  • Audio → waveforms → continuous or discrete representations
# Represent sentence as token sequence x = ["The", "cat", "sat", "on", "the"] target = "mat" # next token to predict
2
Define the Model's Probability Distribution p_θ(x)
▼

The model chooses a distribution family (Gaussian, Categorical, etc.) and uses parameters θ (neural network weights) to specify that distribution for each input.

LLM Example: Given context "The cat sat on the", output a Categorical distribution over the 50,000-token vocabulary:

P(next_token | context) = Categorical([p₁, p₂, ..., p₅₀ₖ]) p("mat") = 0.45, p("chair") = 0.12, p("...") = ...

The neural network (transformer) computes these probabilities via a softmax output layer.

3
Define a Training Objective (Maximum Likelihood)
▼

We maximise the log-likelihood of the training data under the model — equivalent to minimising the cross-entropy loss.

L(θ) = (1/N) Σᵢ log p_θ(xᵢ)

This pushes the model distribution toward the true data distribution by making observed samples more probable.

# Cross-entropy loss in PyTorch (same as MLE for categoricals) loss = F.cross_entropy(logits, target_token_id) # Equivalent to: -log p_θ("mat" | context)
4
Optimise Parameters via Gradient Descent
▼

Backpropagation computes gradients of the loss with respect to θ. The optimiser (Adam, AdamW) updates weights to increase the probability of training examples.

  • Repeat over millions/billions of tokens
  • Learning rate schedules, weight decay regularise the process
  • Result: p_θ(x) steadily approaches p_data(x)
θ ← θ + α · ∇_θ log p_θ(x)
5
Sampling — Generate New Data
▼

Once trained, we sample from p_θ(x) to generate new content. Several strategies exist:

StrategyHow It WorksTrade-off
GreedyPick token with highest probabilityDeterministic, repetitive
Top-kSample from top k tokensBalanced quality/diversity
Top-p (Nucleus)Sample from smallest set summing to pDynamic, context-aware
TemperatureScale logits: high T = more randomControls creativity
# Temperature-scaled sampling logits = model(context) / temperature # T=1 normal, T→0 greedy, T>1 random probs = softmax(logits) next_token = multinomial_sample(probs)
6
Evaluate — KL Divergence & Metrics
▼

We evaluate how close p_θ is to p_data using:

  • KL Divergence: D_KL(p_data ‖ p_θ) — penalises model for assigning low probability to real data
  • Perplexity: exp(cross-entropy) — lower is better for language models
  • FID Score: Frechet Inception Distance — for image generators
  • ELBO: Evidence Lower BOund — used in VAEs
D_KL(P‖Q) = Σ P(x) · log[P(x)/Q(x)]

🔑 Pipeline Glossary

Log-Likelihood
log p_θ(x) — numerically stable version of likelihood used for training
Cross-Entropy
-Σ p(x)·log q(x) — equivalent to NLL for categorical distributions
Softmax
Converts raw logits to a valid probability distribution (sums to 1)
Perplexity
exp(NLL) — average branching factor; lower = better language model
ELBO
Evidence Lower BOund — variational objective for VAEs; tighter = better
The exam often asks: "What is the training objective of a generative model?" Answer: Maximum Likelihood Estimation (MLE) — maximise log p_θ(x) over training data, equivalent to minimising cross-entropy.

1. Gaussian (Normal) Distribution

X ~ N(μ, σ²) f(x) = (1/√(2πσ²)) · exp(-(x-μ)²/2σ²)

The most important distribution in generative AI. Natural data (heights, noise, errors) is approximately Gaussian. Critically, latent spaces in VAEs are constrained to Gaussian.

Use Cases: VAEs (latent space), Diffusion Models (noise process), weight initialisation, noise modelling
Why Gaussian? The Central Limit Theorem — sums of many independent effects converge to Gaussian. Also mathematically tractable (closed-form KL divergence).

2. Bernoulli Distribution

P(X=1) = p, P(X=0) = 1-p

Models binary (yes/no) outcomes. Generalisable to multiple classes via Categorical.

Use Cases: Pixel activation (black/white), token existence, spam/not-spam classification, binary neural network decisions

In image generation, pixel values can be modelled as Bernoulli for binary images, or through sigmoid output layers.

3. Categorical Distribution

P(X=k) = p_k, Σ pₖ = 1 Implemented via Softmax over logits

Generalises Bernoulli to K outcomes. The backbone of all language models — every token prediction is a categorical distribution over the vocabulary.

Use Cases: Next-token prediction (GPT, Llama), multi-class image labels, text generation at each position

4. Uniform Distribution

X ~ U(a, b) f(x) = 1/(b-a), a ≤ x ≤ b

All outcomes equally probable. Used as a starting point before learned structure emerges.

Use Cases: Random weight initialisation, sampling latent vectors (starting point), data augmentation, generating random numbers for noise injection

5. Poisson Distribution

P(X=k) = (e^(-λ) · λ^k) / k! λ = expected rate (mean = variance = λ)

Models count-based events in a fixed interval. Less central to deep learning but important in certain domains.

Use Cases: Event count modelling, traffic modelling in network simulation, gene count in biological data, queueing theory for system simulation

Architecture
How probability distributions are embedded into VAEs, GANs, Diffusion Models, and LLMs

🔷 VAEs — Variational Autoencoders

Core Idea: Encode data into a Gaussian latent distribution, then decode samples back to data space.

Encoder q_φ(z|x):

  • Takes input x, outputs μ and σ (parameters of a Gaussian)
  • Latent vector z ~ N(μ, σ²) is sampled via reparameterisation trick
  • z = μ + σ·ε, where ε ~ N(0,1)

Decoder p_θ(x|z):

  • Takes z, reconstructs x
  • Models p(x|z) as Gaussian (images) or Categorical (text)

Training Objective (ELBO):

L = E[log p_θ(x|z)] - D_KL(q_φ(z|x) ‖ N(0,I))

Term 1: Reconstruction quality. Term 2: Keep latent near standard Gaussian (regularisation).

The KL term ensures the latent space is continuous and smooth, enabling interpolation and generation.

⚔️ GANs — Generative Adversarial Networks

Core Idea: A Generator and Discriminator engage in adversarial training to match data and model distributions.
ComponentRoleProbability Connection
Generator GMaps noise z ~ N(0,I) to fake samplesImplicitly learns p_θ(x) through transformation
Discriminator DClassifies real vs fakeOutputs P(real | x) — a Bernoulli probability
Noise Vector zStarting point for generationDrawn from standard Gaussian or Uniform
Minimax LossTrain G to fool D, D to detect GGoal: G's distribution = data distribution
min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]

GANs are implicit density models — they don't explicitly compute p_θ(x) but can sample from it.

🌊 Diffusion Models

Core Idea: Gradually add Gaussian noise (forward), then learn to reverse the process (denoising).

Forward Process q(xₜ|xₜ₋₁):

  • Each step adds small Gaussian noise
  • After T steps: x_T ~ N(0, I)
  • Analytically tractable (closed form)
q(xₜ|xₜ₋₁) = N(xₜ; √(1-βₜ)xₜ₋₁, βₜI)

Reverse Process p_θ(xₜ₋₁|xₜ):

  • Neural network predicts denoised version
  • Modelled as Gaussian: N(μ_θ, Σ_θ)
  • Start from pure noise, iterate to data
p_θ(xₜ₋₁|xₜ) = N(μ_θ(xₜ,t), Σ_θ(xₜ,t))

Used in: Stable Diffusion, DALL-E, Imagen, Midjourney

🧠 Large Language Models (LLMs)

Core Idea: Predict the probability distribution over the next token given all previous tokens.
P(w₁,w₂,...,wₙ) = Π P(wᵢ | w₁,...,wᵢ₋₁) [Chain Rule]
ComponentDistribution UsedDetails
Output LayerCategorical (Softmax)Over vocabulary of 50k+ tokens
Attention weightsCategorical (Softmax)Distribution over keys/positions
DropoutBernoulliRandom neuron deactivation (regularisation)
Sampling strategyVarious (Categorical, Temperature)Controls diversity of generation

Model computes p_θ(x) directly (VAEs, GPT, Diffusion)

Key Concepts
Deep-dive on concepts from the reference infographic — exam must-knows and challenges

📌 The Big Picture (from Infographic)

The infographic centres on one core formula: p_θ(x) ≈ p_data(x)

  • p_data(x) = true data distribution (e.g., distribution over all natural images)
  • p_θ(x) = model's learned distribution (parameterised by neural network weights θ)
  • A data point x is a sample. The model learns the "shape of possibilities" not individual samples
  • Generation = drawing new samples from p_θ — they're novel but statistically consistent with training data
Simple Analogy (from infographic): Think of p_data(x) as a map of reality. Traditional programs memorise: "This exact image exists." Generative models learn: "These patterns are likely to appear together."

📉 KL Divergence (Deep Dive)

D_KL(P‖Q) = Σ P(x)·log[P(x)/Q(x)]
  • Always ≥ 0 (Gibbs' inequality)
  • Asymmetric: D_KL(P‖Q) ≠ D_KL(Q‖P)
  • = 0 only when P = Q
  • Forward vs Reverse KL have different behaviours (mode-seeking vs mean-seeking)
VAEs minimise D_KL(q_φ(z|x) ‖ N(0,I)) — forces posterior to match standard Gaussian prior.

🎯 Maximum Likelihood Estimation

θ* = argmax_θ Σᵢ log p_θ(xᵢ)
  • Find θ that makes training data most probable
  • Equivalent to minimising KL divergence from model to data
  • Equivalent to minimising cross-entropy
  • Foundation of training for most generative models

📊 Sampling Strategies

  • Greedy: argmax — deterministic, repetitive
  • Top-k: sample from k most likely tokens
  • Top-p: sample from tokens summing to p
  • Temperature T: logits/T — T→0: peaked, T→∞: flat
  • Beam Search: keep B best sequences
Temperature controls the "sharpness" of a categorical distribution before sampling.

🧠 Exam Must-Knows

Conceptual

  • All generative models learn p_θ(x) ≈ p_data(x)
  • Sampling ≠ memorisation — it is structured randomness
  • KL divergence is always ≥ 0; = 0 only when distributions match
  • VAEs encode to Gaussian distributions, not point estimates
  • LLMs apply Chain Rule of Probability for text generation
  • Diffusion models: forward = add noise, reverse = remove noise

Mathematical

  • MLE: θ* = argmax Σ log p_θ(xᵢ)
  • VAE ELBO: E[log p(x|z)] - D_KL(q(z|x) ‖ p(z))
  • Gaussian: X ~ N(μ, σ²)
  • KL: Σ P(x) log[P(x)/Q(x)]
  • Softmax: exp(zᵢ)/Σexp(zⱼ) — converts logits to probabilities
  • Temperature: divide logits by T before softmax
