1 Algorithm Description

Real-life analogy: Imagine you're trying to predict someone's salary based on how many years they've worked. You plot the data on a scatter chart — years on the X-axis, salary on the Y-axis. You then draw the single straight line that best fits through the middle of all the points. That line is your linear regression model. To predict a new person's salary, you simply read off the Y-value of the line at their years-of-experience. Simple, powerful, and the foundation of modern statistics.

What is Linear Regression?

Linear Regression is a supervised learning algorithm that models the relationship between one or more input features (X) and a continuous target variable (y) by fitting a straight line (or hyperplane in higher dimensions) through the data. It assumes the target is a linear combination of the inputs plus a random error term.

There are two main variants:

  • Simple Linear Regression — one input feature (X) predicts one target (y). Visually: a line through a 2-D scatter plot.
  • Multiple Linear Regression — two or more input features predict one target. Visually: a plane (3-D) or hyperplane (n-D) through the data.

The Core Idea in Three Sentences

1. Assume the target is a weighted sum of the input features plus a constant: y = β₀ + β₁x₁ + β₂x₂ + … + ε.

2. Find the weights (β values) that minimise the sum of squared differences between the predictions and the actual values.

3. Use that equation to predict new, unseen data.

How the Algorithm Learns (Step by Step)

Step 1 — State the hypothesis

Assume a linear relationship between the features and the target:

ŷ = β0 + β1x1 + β2x2 + … + βpxp

Here ŷ is the predicted value, xᵢ are the input features, and βᵢ are the coefficients we want to learn.

Step 2 — Define a cost function

Measure how wrong the model is using the Mean Squared Error (MSE):

J(β) = (1/N) · Σi=1N ( yi − ŷi )²

Step 3 — Find the best coefficients

Two main ways to minimise J(β):

  • Closed-form (Normal Equation) — solve a matrix equation directly. Exact solution, but slow for very large datasets or many features.
  • Gradient Descent — iteratively adjust the coefficients in the direction that reduces the cost. Approximate, but scales to huge datasets.

Step 4 — Predict

Plug new feature values into the learned equation to get predictions. Because the model is linear, we can also interpret each coefficient: "holding all other features fixed, increasing feature j by 1 unit changes the prediction by βj units."

Step 5 — Validate assumptions

Linear regression has strong assumptions (LINE): Linearity, Independence, Normality of residuals, and Equal variance (homoscedasticity). If they're violated, the coefficients may still be useful but the confidence intervals and p-values become unreliable.

2 Applications

Linear Regression is the most widely used statistical model in the world. It is the default tool whenever you need a fast, interpretable, and reliable way to predict a continuous value or quantify the effect of one variable on another.

🏠 Real Estate & Housing

  • House price prediction — from area, bedrooms, location, age.
  • Rent estimation — property features → monthly rent.
  • Property tax assessment — value estimation for taxation.
  • Land valuation — for urban planning.

🏦 Finance & Economics

  • CAPM (Capital Asset Pricing Model) — quantify a stock's beta vs. market.
  • GDP forecasting — from consumption, investment, exports.
  • Interest rate modelling — Taylor rule estimation.
  • Credit risk — estimate loss given default.
  • Sales forecasting — revenue from marketing spend.

🛒 Marketing & Business

  • Marketing mix modelling — sales from ad spend across channels.
  • Price elasticity — demand vs. price.
  • Customer lifetime value — CLV estimation.
  • A/B test analysis — effect size estimation.
  • Attribution modelling — channel contribution to conversions.

🏥 Healthcare & Biology

  • Dose-response curves — drug effect vs. dose.
  • Patient outcome prediction — length of stay, recovery time.
  • Epidemiology — relationship between risk factors and disease.
  • Genomics — gene expression vs. phenotype.

🏭 Engineering & Science

  • Sensor calibration — reading vs. true value.
  • Process optimisation — yield vs. temperature, pressure.
  • Physics experiments — fitting known linear laws.
  • Environmental modelling — pollution vs. traffic.

🎓 Social Sciences

  • Education research — test scores vs. study hours.
  • Psychology — behaviour relationships.
  • Sociology — income vs. education level.
  • Political science — voter turnout vs. demographics.
  • Sports analytics — performance metrics prediction.
Why is it everywhere? Because a straight line is the simplest non-trivial relationship two variables can have. Linear Regression is the first model every statistician learns, the baseline every ML engineer compares against, and the workhorse of causal inference, econometrics, and A/B testing. If a linear model can solve your problem, you should almost always use it.

3 Advantages

  • Extremely interpretable — each coefficient tells you exactly how much the prediction changes per unit change in that feature, holding all else fixed. This is unmatched by any complex model.
  • Fast to train and predict — closed-form solution is O(p³) in the number of features (or O(p²) if you precompute). Predictions are a single dot product.
  • Low memory footprint — you only need to store the coefficients and intercept, plus a few statistics. Models are typically only a few bytes.
  • Works well when relationships are truly linear — if the data follows a linear pattern, no other model will beat it.
  • Provides confidence intervals and p-values — you can quantify uncertainty in the coefficients, unlike most ML models.
  • Foundation for more advanced models — Ridge, Lasso, Elastic Net, GLMs, logistic regression, and neural networks all build on it.
  • No feature scaling required (for OLS) — gradient descent benefits from scaling, but the closed-form solution is scale-invariant.
  • Handles multicollinearity (with Ridge) — Ridge regression stabilises coefficients when features are correlated.
  • Extrapolates beyond training data — unlike tree-based models, a linear model extends the trend into unseen ranges (though this can be dangerous if the relationship breaks down).
  • Easy to regularise — add L1 (Lasso) or L2 (Ridge) penalties to prevent overfitting and perform feature selection.
  • Well-understood theory — 200+ years of statistical theory underpin it. Gauss-Markov theorem guarantees OLS is the best linear unbiased estimator under the standard assumptions.
  • Robust to small datasets — unlike deep learning, it works with as few as 10–20 observations if p is small.

4 Disadvantages

  • Assumes linearity — if the true relationship is curved, cyclical, or has interactions, linear regression will systematically misfit the data. Polynomial or nonlinear models are needed.
  • Sensitive to outliers — because it minimises squared error, a single extreme point can dramatically shift the line. Use Huber or quantile regression for robustness.
  • Struggles with multicollinearity — when features are highly correlated, coefficients become unstable and hard to interpret. Use Ridge, Lasso, or PCA.
  • Cannot capture complex interactions — you must manually add interaction terms (X₁ × X₂) if you want the model to learn them.
  • Assumes homoscedasticity — if the variance of residuals changes with the prediction (heteroscedasticity), standard errors are wrong. Use weighted least squares or robust standard errors.
  • Assumes independent residuals — for time-series data, autocorrelation invalidates standard inference. Use ARIMA or add lag features.
  • Assumes normally distributed residuals — matters for small samples and for confidence intervals. Larger samples relax this by CLT.
  • Cannot handle missing values natively — you must impute, drop, or use a model that handles missingness.
  • Poor at capturing nonlinearity without feature engineering — you must manually create polynomial, log, or interaction features.
  • Sensitive to feature scaling in gradient descent — OLS is scale-invariant, but gradient descent requires normalised features to converge quickly.
  • Cannot predict categorical targets — use logistic regression, multinomial regression, or a tree-based model instead.
  • Overfits with too many features relative to samples — when p > N, OLS is undefined. Use Ridge, Lasso, or PCA.
  • Assumes no measurement error in X — if the features are noisy, coefficients are biased toward zero (attenuation bias).
  • Extrapolation can be dangerous — the model will happily predict nonsense outside the training range.
The linearity trap: Imagine fitting a straight line to a U-shaped relationship. No straight line can capture both the downward and upward trends — the model will be wrong at both extremes and pass near the middle almost by accident. Always plot your data first; if you see curvature, add polynomial features or use a different model.

5 Pre-Deployment KPIs — Detailed with Formulas

These are measured before the model goes live, using a held-out test set or cross-validation. They answer: "Is this model good enough to ship?"

5.1 Regression Accuracy KPIs

MAE (Mean Absolute Error) Regression

What it measures: The average size of the prediction error, in the same units as the target. Robust to outliers because it doesn't square errors.

Formula MAE = (1/N) · Σi=1N | yi − ŷi |

yi = actual value  |  ŷi = predicted value  |  N = number of samples
Worked example: Actual = [100, 200, 300], Predicted = [110, 190, 320]
Errors = |−10|, |10|, |−20| = 10, 10, 20
MAE = (10 + 10 + 20) / 3 = 13.33
Interpretation: On average, the prediction is off by 13.33 units. Easy to explain to stakeholders.
✔ Use when You want an easy-to-explain metric and all errors have equal importance.
✘ Avoid when Large errors are dramatically worse than small ones (use RMSE).

MSE (Mean Squared Error) Regression

What it measures: The average of squared errors. Squaring heavily penalises large mistakes and is the loss function OLS minimises.

Formula MSE = (1/N) · Σi=1N ( yi − ŷi )²
Worked example: Errors = [−10, 10, −20]
MSE = (100 + 100 + 400) / 3 = 200
Interpretation: MSE is in squared units (₹², °C²), so it's hard to interpret directly. It's mostly used as a loss function during training.

RMSE (Root Mean Squared Error) Regression

What it measures: The square root of MSE, bringing the metric back to the original units of the target. Penalises large errors more than MAE.

Formula RMSE = √[ (1/N) · Σi=1N ( yi − ŷi )² ]
Worked example: MSE = 200
RMSE = √200 = 14.14
Interpretation: On average the model is off by 14.14 units, but large errors are penalised more than in MAE. RMSE ≥ MAE always. The ratio RMSE/MAE ≈ 1.25 suggests Gaussian residuals.
✔ Use when Large errors are genuinely worse (e.g. financial forecasting, demand planning).
✘ Avoid when The target has outliers you don't care about — use MAE.

R² (Coefficient of Determination) Regression

What it measures: The proportion of the target's variance that the model explains. Compares against the naive "always predict the mean" baseline.

Formula R² = 1 − ( SSres / SStot )

SSres = Σ ( yi − ŷi )²   (residual sum of squares)
SStot = Σ ( yi − ȳ )²   (total sum of squares)
ȳ = mean of the actual values
Worked example: y = [100, 200, 300], ŷ = [110, 190, 320], ȳ = 200
SSres = 100 + 100 + 400 = 600
SStot = 10,000 + 0 + 10,000 = 20,000
R² = 1 − (600 / 20,000) = 0.97
Interpretation: R² = 1 → perfect; R² = 0 → no better than predicting the mean; R² < 0 → worse than the mean (very bad).
✔ Use when You want a scale-free measure of how well the model fits.
✘ Avoid when Comparing models with different numbers of features — R² always increases with more features. Use Adjusted R².

Adjusted R² Regression

What it measures: R² penalised for the number of predictors. Only increases if a new feature adds more explanatory power than would be expected by chance.

Formula Adjusted R² = 1 − [ (1 − R²) · (N − 1) ] / (N − p − 1)

N = number of samples  |  p = number of predictors (excluding intercept)
Worked example: R² = 0.97, N = 100, p = 5
Adjusted R² = 1 − [(1 − 0.97) · 99] / 94 = 1 − 2.97/94 = 0.968
✔ Use when Comparing models with different numbers of features, or when you want to detect overfitting from feature bloat.

MAPE (Mean Absolute Percentage Error) Regression

What it measures: The average error expressed as a percentage of the actual value. Very intuitive for business reporting.

Formula MAPE = (100% / N) · Σi=1N | ( yi − ŷi ) / yi |
Worked example: y = [100, 200, 300], ŷ = [110, 190, 320]
Errors % = |−10/100|, |10/200|, |−20/300| = 0.10, 0.05, 0.0667
MAPE = (0.10 + 0.05 + 0.0667) / 3 × 100 = 7.22%
Interpretation: On average, predictions are off by 7.22% of the actual value. Range 0% to ∞ (lower is better).
✔ Use when Reporting to business stakeholders and actual values are well above zero.
✘ Avoid when Actual values can be zero or near-zero — MAPE explodes to infinity.

SMAPE (Symmetric Mean Absolute Percentage Error) Regression

What it measures: A symmetric version of MAPE that keeps errors bounded between 0% and 200%. Handles zero values better.

Formula SMAPE = (100% / N) · Σi=1N | yi − ŷi | / [ (|yi| + |ŷi|) / 2 ]
Interpretation: Range 0% to 200% (lower is better).

MSLE (Mean Squared Logarithmic Error) Regression

What it measures: Squared error on the log scale. Penalises under-prediction more than over-prediction.

Formula MSLE = (1/N) · Σi=1N ( log(1 + yi) − log(1 + ŷi) )²
✔ Use when The target spans several orders of magnitude (e.g. revenue, population counts).

5.2 Statistical Significance KPIs

t-statistic & p-value (per coefficient) Statistical

What it measures: Whether each coefficient is significantly different from zero. A small p-value means the feature reliably affects the target.

t-statistic for coefficient j tj = β̂j / SE(β̂j)

Standard error of coefficient j SE(β̂j) = √[ σ² · (XᵀX)−1jj ]

σ² = residual variance = SSres / (N − p − 1)

p-value (two-tailed) p = 2 · P( TN−p−1 > |tj| )
Interpretation:
• p < 0.05 → statistically significant at the 5% level
• p < 0.01 → strongly significant
• p > 0.10 → not significant — consider removing the feature

F-statistic Statistical

What it measures: Whether the model as a whole explains a significant amount of variance. Tests H₀: all coefficients (except intercept) are zero.

F-statistic F = ( (SStot − SSres) / p ) / ( SSres / (N − p − 1) )

p = number of predictors  |  N = number of samples

Degrees of freedom df₁ = p, df₂ = N − p − 1
Interpretation: A high F with a small p-value (e.g. < 0.05) means the model is significantly better than the intercept-only baseline.

VIF (Variance Inflation Factor) Statistical

What it measures: How much a coefficient's variance is inflated by multicollinearity with other features.

Formula VIFj = 1 / (1 − R²j)

R²j = R² from regressing feature j on all other features
Interpretation:
• VIF = 1 → no correlation
• VIF 1–5 → moderate, usually fine
• VIF 5–10 → concerning, consider removing or combining
• VIF > 10 → severe multicollinearity, must address

Durbin-Watson Statistic Statistical

What it measures: Whether residuals are autocorrelated (especially important for time-series data).

Formula DW = Σi=2N ( ei − ei−1 )² / Σi=1N ei²

ei = residual of the i-th observation
Interpretation: Range 0–4.
• DW ≈ 2 → no autocorrelation ✅
• DW < 1.5 → positive autocorrelation ⚠️
• DW > 2.5 → negative autocorrelation ⚠️

Confidence Interval (95% CI) Statistical

What it measures: A range that has a 95% chance of containing the true coefficient.

Formula CI95% = β̂j ± t0.025, N−p−1 · SE(β̂j)

t0.025, df = critical value from the t-distribution
Interpretation: If the CI excludes 0, the coefficient is significant at the 5% level.

5.3 Model Quality & Robustness KPIs

Cross-Validation Score Robustness

What it measures: The average metric (e.g. RMSE) across K different train/test splits. Gives a more reliable estimate than a single split.

K-Fold CV Score CV = (1/K) · Σk=1K Metrick

Standard deviation (stability) σCV = √[ (1/K) · Σk ( Metrick − CV )² ]

Train–Test Gap (Overfitting Indicator) Robustness

What it measures: How much better the model performs on training data than on unseen test data.

Formula Gap = Metrictest − Metrictrain

For R²: Gap = R²train − R²test
Rule of thumb:
• Gap < 5% → healthy
• Gap 5–10% → mild overfitting, consider Ridge/Lasso
• Gap > 10% → serious overfitting, reduce features or regularise

Residual Diagnostics Robustness

What it measures: Whether the four LINE assumptions hold. Check with plots:

  • Residuals vs. Fitted — should show no pattern (random scatter around 0). A funnel shape = heteroscedasticity. A curve = non-linearity.
  • QQ Plot of Residuals — should lie on a straight 45° line. Deviations = non-normal residuals.
  • Residuals vs. Order — should show no pattern. Patterns = autocorrelation.
  • Residuals vs. Each Feature — should show no pattern. Patterns = need to add polynomial terms or interactions.

6 Post-Deployment KPIs — Detailed with Formulas

Once the model is live, you're no longer asking "is it accurate?" — you're asking "is it still accurate today, and is anything silently breaking?"

6.1 Data & Model Health KPIs

PSI (Population Stability Index) Data Drift

What it measures: How much the distribution of a single feature (or the model's predictions) has shifted between training and production.

Formula PSI = Σi=1B ( Actual%i − Expected%i ) · ln( Actual%i / Expected%i )

B = number of bins (usually 10 deciles)
Expected%i = % of training samples in bin i
Actual%i = % of production samples in bin i
Interpretation thresholds:
• PSI < 0.10 → no significant change, model is stable ✅
• 0.10 ≤ PSI < 0.25 → moderate shift, monitor closely ⚠️
• PSI ≥ 0.25 → major shift, retrain the model 🚨

KS Statistic (Kolmogorov–Smirnov) Data Drift

What it measures: The maximum vertical distance between two cumulative distribution functions (training vs. production).

Formula KS = maxx | Ftrain(x) − Fprod(x) |

F(x) = empirical cumulative distribution function
Interpretation: Range 0 to 1. Higher = more drift. A p-value < 0.05 from the KS test indicates statistically significant drift.

KL Divergence (Kullback–Leibler) Data Drift

What it measures: How much one probability distribution diverges from another (asymmetric).

Formula DKL(P ‖ Q) = Σi P(i) · log( P(i) / Q(i) )

P = production distribution  |  Q = training distribution
Interpretation: 0 = identical distributions. Higher = more drift. Not symmetric.

Concept Drift (Performance Decay) Model Health

What it measures: How much the model's live performance has degraded vs. its validation performance.

Formula Drift Magnitude = Metricvalidation − Metriclive

Relative decay Decay % = ( Metricvalidation − Metriclive ) / Metricvalidation × 100
Interpretation: Decay > 10% typically triggers a retraining investigation.

Prediction Distribution Shift Model Health

What it measures: Whether the model's own output distribution has changed over time.

Formula PSIpred = Σ ( ProdPred%i − TrainPred%i ) · ln( ProdPred%i / TrainPred%i )
Interpretation: A sudden jump signals a pipeline problem or concept drift.

Coefficient Stability Model Health

What it measures: Whether the learned coefficients are drifting over time. If they change rapidly, the underlying relationship is unstable.

Stability Index Stability = 1 − ( || βtrain − βprod || / || βtrain || )

βtrain = coefficients from training
βprod = coefficients refit on recent production data
Interpretation: Stability close to 1 = stable. Values below 0.8 suggest the relationship has shifted.

Missing Value Rate Model Health

Formula Missing % = ( Missing values / Total values ) × 100
Interpretation: Linear regression cannot handle missing values natively, so a spike in missingness will directly degrade predictions.

6.2 Live Performance KPIs

Live RMSE / MAE / R² Performance

What it measures: The same regression metrics, recomputed on labelled production data as ground truth arrives.

Same formulas as pre-deployment Live RMSE = √[ (1/Nlive) · Σ ( ylive − ŷlive )² ]
Live R² = 1 − SSres,live / SStot,live
Interpretation: Ground truth often arrives with a delay. Set up automated pipelines to compute these as soon as labels arrive.

Actual vs. Predicted Monitoring Performance

Formula Deltat = Metricpredicted,t − Metricactual,t

CUSUM (cumulative sum control chart) CUSUMt = max(0, CUSUMt−1 + Deltat − k)
Interpretation: A steadily rising CUSUM indicates systematic drift. Alert when CUSUM crosses a threshold h.

Model Age / Time Since Retrain Performance

Formula Model Age = Current Date − Last Retrain Date
Interpretation: Many teams set a hard limit (e.g. 90 days) as a retraining trigger, regardless of measured drift.

Latency Percentiles (p50, p95, p99) Operational

Definition p95 = the latency value below which 95% of requests fall

Why not the average? Average latency hides tail problems. A few slow requests (p99) can ruin user experience even if the average looks fine.
Target example: Linear regression is extremely fast. p50 < 1 ms, p95 < 5 ms, p99 < 20 ms is typical for a well-optimised service.

6.3 Operational & Business KPIs

Throughput Operational

Formula Throughput = Total predictions served / Time window

Utilisation Utilisation % = (Actual throughput / Peak capacity) × 100

Error Rate / Failure Rate Operational

Formula Error Rate % = ( Failed requests / Total requests ) × 100
Interpretation: Should be near zero. A sudden spike usually means an upstream data pipeline broke or the model service is overloaded.

Uptime / Availability Operational

Formula Uptime % = ( Total time − Downtime ) / Total time × 100%

Common targets 99%  → 3.65 days downtime/year
99.9%  → 8.77 hours downtime/year
99.99% → 52.6 minutes downtime/year

Business Impact KPI Business

Example formulas Revenue Uplift = Revenuewith model − Revenuewithout model
Cost Saved = ( Errorswithout − Errorswith ) × Cost per error
Forecast Accuracy % = ( 1 − MAPE ) × 100

ROI (Return on Investment) Business

Formula ROI % = ( Net Gain / Total Cost ) × 100%

Net Gain = Business Value Generated − Total Cost
Total Cost = Development + Infrastructure + Maintenance + Monitoring
Worked example: Value generated = ₹5,00,000. Total cost = ₹1,00,000.
Net Gain = ₹4,00,000. ROI = (4,00,000 / 1,00,000) × 100 = 400%

Human Override Rate Business

Formula Override Rate % = ( Overrides / Total decisions ) × 100
Interpretation: A high override rate (e.g. > 30%) means users don't trust the model.

Alert / Incident Count Governance

Formula Alert Rate = Alerts triggered / Time period
Golden rule: A Linear Regression model is not "done" when it's deployed. It's done when it's retired. Post-deployment monitoring is what keeps it from silently degrading.

7 Mathematical Formulas — How Linear Regression Actually Works

The core idea: find the coefficients that minimise the sum of squared errors. Here are the formulas.

7.1 Simple Linear Regression

With one feature, the model is a straight line.

Model equation ŷ = β0 + β1x

Closed-form solution β1 = Σ (xi − x̄)(yi − ȳ) / Σ (xi − x̄)²
    = Cov(x, y) / Var(x)

β0 = ȳ − β1x̄

Interpretation of β₁ A one-unit increase in x is associated with a β₁-unit change in the predicted y.

7.2 Multiple Linear Regression (Matrix Form)

With p features, we stack all observations into a matrix equation.

Matrix equation y = Xβ + ε

y = (N × 1) vector of targets
X = (N × (p+1)) design matrix (first column of 1s for intercept)
β = ((p+1) × 1) vector of coefficients
ε = (N × 1) vector of errors

Prediction ŷ = Xβ̂

7.3 Ordinary Least Squares (OLS) — Closed Form

Minimising the sum of squared residuals gives the famous normal equation.

Cost function (MSE) J(β) = (1/N) · (y − Xβ)ᵀ (y − Xβ)

Normal equation (closed-form solution) β̂ = (XᵀX)−1 Xᵀy

Fitted values ŷ = Xβ̂ = X(XᵀX)−1Xᵀy = Hy

H = X(XᵀX)−1Xᵀ is called the "hat matrix" (it "puts the hat" on y).

Requires XᵀX to be invertible. If features are collinear, use Ridge regression: β̂ = (XᵀX + λI)−1Xᵀy.

7.4 Gradient Descent

For large datasets or when XᵀX is not invertible, gradient descent iteratively updates the coefficients.

Update rule βj ← βj − α · ∂J / ∂βj

Gradients ∂J / ∂β0 = (2/N) · Σ ( ŷi − yi )
∂J / ∂βj = (2/N) · Σ ( ŷi − yi ) · xij

α = learning rate (step size)
Repeat until convergence (change in J is below a threshold).

7.5 Assumptions (LINE)

OLS inference relies on four assumptions. Violating them doesn't necessarily break predictions, but it does break p-values and confidence intervals.

L
Linearity
The true relationship is linear
I
Independence
Errors are independent
N
Normality
Errors are normally distributed
E
Equal variance
Homoscedasticity (constant variance)

7.6 R² and ANOVA Decomposition

R² is derived from the decomposition of total sum of squares.

Total sum of squares SStot = Σ ( yi − ȳ )²

Residual sum of squares SSres = Σ ( yi − ŷi )²

Explained sum of squares SSreg = Σ ( ŷi − ȳ )²

ANOVA identity SStot = SSreg + SSres

Coefficient of determination R² = SSreg / SStot = 1 − SSres / SStot

7.7 Residual Standard Error & Standard Errors of Coefficients

Residual standard error (σ̂) σ̂ = √[ SSres / (N − p − 1) ]

Covariance matrix of coefficients Var(β̂) = σ̂² · (XᵀX)−1

Standard error of coefficient j SE(β̂j) = σ̂ · √[ (XᵀX)−1jj ]

7.8 Regularised Regression (Ridge & Lasso)

When OLS overfits or features are collinear, add a penalty term to the cost.

Ridge (L2 penalty) JRidge(β) = Σ ( yi − ŷi )² + λ · Σ βj²
β̂Ridge = (XᵀX + λI)−1 Xᵀy

Lasso (L1 penalty) JLasso(β) = Σ ( yi − ŷi )² + λ · Σ |βj|
No closed form — solved via coordinate descent. Performs feature selection (sets some βj = 0 exactly).

Elastic Net JEN(β) = Σ ( yi − ŷi )² + λ₁ · Σ |βj| + λ₂ · Σ βj²

7.9 F-statistic and t-statistic

F-statistic (overall model significance) F = ( SSreg / p ) / ( SSres / (N − p − 1) )

t-statistic (per coefficient) tj = β̂j / SE(β̂j)

Relationship For simple linear regression, F = t²

7.10 Gauss-Markov Theorem

Under the LINE assumptions (except normality), OLS is the Best Linear Unbiased Estimator (BLUE): among all linear unbiased estimators, it has the smallest variance.

8 Glossary of Acronyms & Terms

Every abbreviation used in this study guide, explained in plain English.

Algorithm & Model Concepts

ML
Machine Learning — a field of AI where systems learn patterns from data instead of being explicitly programmed.
LR
Linear Regression — a model that fits a straight line (or hyperplane) through data by minimising squared error.
OLS
Ordinary Least Squares — the standard method for estimating linear regression coefficients by minimising the sum of squared residuals.
WLS
Weighted Least Squares — a variant of OLS that weights observations differently to handle heteroscedasticity.
GLS
Generalised Least Squares — accounts for correlated and heteroscedastic errors.
Ridge
Ridge Regression — linear regression with an L2 penalty on coefficients.
Lasso
Least Absolute Shrinkage and Selection Operator — linear regression with an L1 penalty that performs feature selection.
Elastic Net
Linear regression combining both L1 and L2 penalties.
GLM
Generalised Linear Model — extends linear regression to non-normal targets (logistic, Poisson, Gamma).
CAPM
Capital Asset Pricing Model — a finance model that uses linear regression to relate stock returns to market returns.

Coefficients & Statistics

β (Beta)
Coefficient — the change in the predicted y for a one-unit change in x, holding all other features constant.
β₀
Intercept — the predicted y when all features are zero.
β̂ (Beta-hat)
The estimated value of a coefficient from the data.
SE
Standard Error — the standard deviation of a coefficient's sampling distribution. Smaller SE = more precise estimate.
t-stat
t-statistic — β̂ / SE(β̂). Tests whether the coefficient is significantly different from 0.
p-value
The probability of observing a t-statistic at least this extreme if the true coefficient were 0. Small p = significant.
CI
Confidence Interval — a range of plausible values for a coefficient, e.g. 95% CI = β̂ ± 1.96·SE.
F-stat
F-statistic — tests overall model significance (all coefficients = 0).
df
Degrees of Freedom — the number of independent pieces of information remaining after estimating parameters.
σ̂ (Sigma-hat)
Residual standard error — the estimated standard deviation of the residuals.
x̄ (x-bar)
Mean of the x values.
ȳ (y-bar)
Mean of the y values.

Fit & Residuals

y
The actual target value for a training example.
ŷ (y-hat)
The predicted target value from the model.
e
Residual — the difference y − ŷ. What the model got wrong.
ε
The true (unobserved) error term in the model equation.
SSres
Residual Sum of Squares — Σ(y − ŷ)².
SStot
Total Sum of Squares — Σ(y − ȳ)².
SSreg
Regression Sum of Squares — Σ(ŷ − ȳ)².
MSE
Mean Squared Error — SSres / N.
RMSE
Root Mean Squared Error — √MSE.
MAE
Mean Absolute Error — Σ|y − ŷ| / N.
R²
Coefficient of Determination — proportion of variance in y explained by the model.
Adj. R²
Adjusted R² — R² penalised for the number of predictors.

Regression Metrics

MAPE
Mean Absolute Percentage Error — average error as a percentage of the actual value.
SMAPE
Symmetric Mean Absolute Percentage Error — bounded version of MAPE (0–200%).
MSLE
Mean Squared Logarithmic Error — squared error on the log scale.
Huber Loss
A loss function that is quadratic for small errors and linear for large errors. Robust to outliers.
Quantile Loss
A loss function that estimates a specific quantile of the target distribution.
AIC
Akaike Information Criterion — a model selection metric that balances fit and complexity. Lower is better.
BIC
Bayesian Information Criterion — like AIC but penalises complexity more heavily.

Assumptions & Diagnostics

LINE
Linearity, Independence, Normality, Equal variance — the four OLS assumptions.
BLUE
Best Linear Unbiased Estimator — Gauss-Markov theorem guarantees OLS is BLUE under LINE assumptions.
Multicollinearity
When predictor features are highly correlated with each other, causing unstable coefficients.
VIF
Variance Inflation Factor — measures multicollinearity. VIF > 10 = severe.
Heteroscedasticity
Non-constant variance of residuals. Violates the "E" assumption. Detect with residual plots.
Homoscedasticity
Constant variance of residuals. The desired state.
Autocorrelation
Correlated residuals, often in time-series data. Violates the "I" assumption.
DW
Durbin-Watson — statistic for detecting autocorrelation in residuals. Target ≈ 2.
QQ Plot
Quantile-Quantile Plot — plots residuals against a normal distribution to check normality.
Leverage
How much a single observation influences the fitted line. High-leverage points are dangerous.
Influence
Combined measure of leverage and residual size (Cook's distance).
Cook's D
Cook's Distance — measures how much a single point affects the coefficients. D > 1 is concerning.

Monitoring & Deployment

KPI
Key Performance Indicator — a measurable value tracking model or business performance.
PSI
Population Stability Index — measures distribution shift between training and production.
KS Test
Kolmogorov–Smirnov Test — a statistical test for whether two distributions differ.
KL Divergence
Kullback–Leibler Divergence — measures how one probability distribution diverges from another.
CSI
Characteristic Stability Index — the per-feature version of PSI.
Data Drift
A change in the distribution of input features over time.
Concept Drift
A change in the relationship between features and the target over time.
CUSUM
Cumulative Sum Control Chart — sequential analysis for change detection.
MLOps
Machine Learning Operations — deploying, monitoring and maintaining ML models in production.
CI/CD
Continuous Integration / Continuous Deployment — automated pipelines for testing and shipping.
p50/p95/p99
Percentile latency — p95 = 95% of requests are faster than this value.
Uptime
The percentage of time a service is available and responding.
ROI
Return On Investment — (gain from investment − cost) ÷ cost.
Shadow Deployment
Running a new model alongside the old one without acting on its output.
A/B Test
Splitting live traffic between two model versions to measure which performs better.
Champion/Challenger
The current production model (champion) vs. a candidate model (challenger).

Data & Training Concepts

Feature
An input variable used by the model (also called predictor, regressor, or column).
Target
The output variable the model is trying to predict (also called response, label, or y).
Design Matrix
The matrix X of shape (N, p+1) containing all features plus a column of 1s for the intercept.
Overfitting
When a model learns the training data too well and performs poorly on new data.
Underfitting
When a model is too simple to capture the underlying pattern.
Bias
Error from overly simplistic assumptions. High bias = underfitting.
Variance
Error from sensitivity to small fluctuations in training data. High variance = overfitting.
Bias–Variance Tradeoff
The balance between a model that is too simple and one that is too complex.
Cross-Validation
Splitting data into K folds and training K times.
K-Fold
The specific cross-validation scheme using K folds.
Hyperparameter
A setting you choose before training (e.g. λ in Ridge).
Grid Search
Exhaustively trying every combination of hyperparameters.
Regularisation
Penalties on model complexity to prevent overfitting.
Feature Engineering
Creating new, more informative features (e.g. X², log(X), X₁×X₂).
One-Hot Encoding
Converting a categorical variable into multiple binary columns.
Standardisation
Rescaling features to mean 0 and standard deviation 1. Recommended for gradient descent.
Normalisation
Rescaling features to a 0–1 range.

Explainability & Interpretation

XAI
Explainable AI — methods that make model decisions understandable to humans.
SHAP
SHapley Additive exPlanations — game-theory-based feature attribution.
PDP
Partial Dependence Plot — shows the marginal effect of one feature.
White-box
A model whose internals are directly interpretable (linear regression is a white-box model).
Black-box
A model whose internals are opaque (e.g. a deep neural network).
Confounding
A third variable that correlates with both X and y, creating a spurious association.
Endogeneity
When a predictor is correlated with the error term, biasing OLS estimates.
Omitted Variable Bias
Bias that arises when a relevant variable is left out of the model.
