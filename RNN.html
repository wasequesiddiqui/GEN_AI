Recurrent Neural Network – Hyperparameters

Tune the core settings that shape vanilla RNN performance and stability.

A classic RNN processes sequential data by reusing hidden state across time steps. This guide covers the 10 most important hyperparameters for vanilla RNNs, from hidden units to gradient clipping, with practical Keras examples and a runnable sequence prediction demo.

📊 Vanilla RNN overview — input, recurrent state, and output flow

🧩

① Number of RNN Units (Hidden Units)

Defines the size of the hidden state vector. More units increase capacity but also computational cost and overfitting risk.

from tensorflow.keras.layers import SimpleRNN
SimpleRNN(128) # 128 hidden units
💡Start with 64 or 128. Increase only if underfitting persists.
🏢

② Number of Layers

Stack RNN layers for deeper sequence representations. Use return_sequences=True on intermediate layers.

model.add(SimpleRNN(128, return_sequences=True))
model.add(SimpleRNN(64))
✅1–2 layers usually work well for vanilla RNNs. More layers may increase training difficulty.
🎯

③ Learning Rate

Controls the step size for gradient descent. It is the most important training hyperparameter.

from tensorflow.keras.optimizers import Adam
optimizer = Adam(learning_rate=0.001)
💡Use 0.001 as a safe default and adjust from there.
⚠️Too high can blow up gradients; too low slows learning dramatically.
📦

④ Batch Size

Number of samples processed before updating weights. Smaller batches improve gradient stability for sequence data.

model.fit(X_train, y_train, batch_size=32)
💡Use 16–64 for time series tasks. Larger batches can hurt generalization.
🔄

⑤ Number of Epochs

How many full passes over the dataset. Monitor validation metrics and stop before overfitting.

model.fit(X_train, y_train, epochs=50)
✅Combine with EarlyStopping so training ends when performance plateaus.
🎲

⑥ Dropout & Recurrent Dropout

Dropout regularizes the input and recurrent connections to discourage overfitting.

SimpleRNN(128, dropout=0.2, recurrent_dropout=0.2)
💡Typical range: 0.1–0.3 for vanilla RNNs.
⚠️Large recurrent dropout may prevent the model from learning long dependencies.
📏

⑦ Sequence Length (Time Steps)

Number of past inputs fed to the network in each sample. It determines how far back the model can look.

# Use the last 20 time steps
input_shape=(20, 1)
⚠️Too long sequences make training slow and unstable; too short loses context.
⚡

⑧ Activation Function

Defines the nonlinearity in hidden state updates. RNNs commonly use tanh or ReLU.

SimpleRNN(128, activation='tanh')
✅Use tanh for stable sequence learning; use ReLU only with careful gradient control.
🔧

⑨ Optimizer

Chooses how weights update each step. Adam is a strong default for RNNs.

model.compile(optimizer='adam', loss='mse')
💡Adam is typically best, but try RMSprop for long sequences.
📉

⑩ Loss Function

Measures training error. Choose based on whether your task is regression or classification.

# Regression
model.compile(loss='mse')
# Classification
model.compile(loss='categorical_crossentropy')
💡Use MSE for numeric forecasting and crossentropy for sequence classification.

🏗️ RNN Architecture & Structure

A vanilla RNN updates its hidden state by combining the current input with the previous hidden state. This recurrence is what gives RNNs the power to process ordered sequences, but also what makes them sensitive to gradients over time.

🔬 RNN Core Equations
Hidden State Update:
ht = tanh(Wxt + Uht−1 + b)
Output Layer:
yt = Vht + c
Gradient Flow:
∂L/∂ht−1 = UT·diag(1−ht2)·∂L/∂ht
Sequence Input:
X = [x1, x2, …, xT]

📖 Equation Element Breakdown – What every symbol means

Understanding the recurrent update is key to tuning RNN performance. Each component plays a role in how the network remembers or updates sequence context.

🔹 Hidden State Update
tanh
Squashes the hidden state output to the range (-1, 1). Helps stabilize the recurrent update.
Output: (-1, 1)
W
Input-to-hidden weight matrix. Determines how the current input xt influences the new state.
Shape: (hidden_units, input_features)
xt
The input vector at time step t. Can be a scalar feature, embedding, or multivariate time step.
Shape: (batch_size, input_features)
U
Hidden-to-hidden weight matrix. Controls how much previous state ht−1 is reused.
Shape: (hidden_units, hidden_units)
ht-1
Previous hidden state. Carries sequence memory forward one step.
Shape: (batch_size, hidden_units)
b
Bias vector added to the hidden update. Helps the model learn offsets and baseline activity.
Shape: (hidden_units,)
🔹 Output Layer
V
Hidden-to-output weight matrix. Maps the recurrent state to the prediction space.
Shape: (output_dim, hidden_units)
c
Output bias. Offsets the final prediction before any output activation.
Shape: (output_dim,)
yt
The predicted output at time t. Can be used directly or passed through an activation for classification.
Shape: (batch_size, output_dim)
🔹 Gradient Flow
UT
The transpose of the recurrent weight. When repeated over many steps, its eigenvalues influence gradient growth or decay.
Shape: (hidden_units, hidden_units)
diag(1−ht2)
Derivative of tanh. If hidden values saturate, gradients vanish; if they stay near zero, gradients are preserved better.
Shape: (hidden_units, hidden_units)
∂L/∂ht
Gradient signal at the current time step. It must pass through the recurrent path to update earlier states.
Shape: (batch_size, hidden_units)
💡 Key insight: Vanilla RNNs learn by carrying gradients through the same hidden-to-hidden matrix repeatedly, so tuning hidden size, activation, and gradient clipping is essential for stability.
🔍

RNN Update Function

A single hidden state update blends current input and previous hidden state using a nonlinear activation.

💡Because the same weights are reused across time, RNNs can model sequence dynamics with a compact parameter set.
🔄

Recurrent Connection

The recurrent weight matrix uses ht-1 to carry information forward. It is the source of temporal memory.

💡Maintain moderate hidden sizes to avoid exploding or vanishing gradients over long sequences.

⚡ Training Process Hyperparameters

These settings govern how the RNN learns across time and how quickly it adapts to sequence patterns.

🎯

Learning Rate

Determines how large each weight update is. Too high destabilizes training; too low stalls learning.

from tensorflow.keras.optimizers import Adam
optimizer = Adam(learning_rate=0.001)
✅Adam with 0.001 is a strong default for vanilla RNNs.
📦

Batch Size

Controls gradient estimation noise. Smaller batches often help generalization for sequence tasks.

model.fit(X, y, batch_size=32)
🔄

Epochs

Number of full passes over the dataset. Monitor validation to stop before overfitting.

model.fit(X, y, epochs=100)
⚠️Vanilla RNNs can memorize quickly; use validation metrics to stop early.
🔧

Optimizer Choice

Adam is the default for most RNNs, while RMSprop can help with nonstationary sequence data.

# Adam: default
model.compile(optimizer='adam')
# RMSprop: good for sequential learning
model.compile(optimizer='rmsprop')

🛡️ Regularization & Tuning

Use these techniques to improve generalization and stabilize recurrent gradient flow.

🎲

Dropout (Input)

Drops inputs during training to prevent over-reliance on any single feature.

SimpleRNN(128, dropout=0.2)
💡Apply 0.1–0.3 input dropout to reduce overfitting while preserving signal.
🔁

Recurrent Dropout

Drops the recurrent state updates, which is more aggressive but can help with overfitting across time.

SimpleRNN(128, recurrent_dropout=0.2)
⚠️Use cautiously — too much recurrent dropout can wash out long-term dependencies.
⏳

Gradient Clipping

Limits gradient magnitude to prevent exploding gradients in long sequences.

optimizer = Adam(learning_rate=0.001, clipnorm=1.0)
📉

Early Stopping

Halts training once validation metrics stop improving, preventing overfitting.

from tensorflow.keras.callbacks import EarlyStopping
EarlyStopping(monitor='val_loss', patience=8, restore_best_weights=True)

💻 Full Code – Synthetic Sequence Forecasting with RNN

A runnable example using a vanilla SimpleRNN model. Key hyperparameters are annotated with numbers matching the cards above.

#!/usr/bin/env python3 """Vanilla RNN sequence forecasting – all hyperparameters labeled.""" import numpy as np from sklearn.preprocessing import MinMaxScaler from sklearn.model_selection import train_test_split from tensorflow.keras.models import Sequential from tensorflow.keras.layers import SimpleRNN, Dense from tensorflow.keras.optimizers import Adam from tensorflow.keras.callbacks import EarlyStopping # ── Generate synthetic time-series data ── np.random.seed(42) t = np.arange(1500) series = np.sin(0.04 * t) + 0.3 * np.sin(0.12 * t) + np.random.normal(0, 0.15, t.shape) # ── ⑦ Sequence length / time steps ── TIME_STEPS = 30 def create_sequences(data, time_steps=TIME_STEPS): X, y = [], [] for i in range(len(data) - time_steps): X.append(data[i:i+time_steps]) y.append(data[i+time_steps]) return np.array(X)[..., np.newaxis], np.array(y) X, y = create_sequences(series) X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, shuffle=False) # ── Build RNN model ── model = Sequential() model.add(SimpleRNN( units=128, # ① Hidden units activation='tanh', # ⑧ Activation function dropout=0.2, # ⑥ Input dropout recurrent_dropout=0.2, # ⑥ Recurrent dropout input_shape=(TIME_STEPS, 1) # ⑦ Sequence length )) model.add(Dense(1)) # output prediction # ── Optimizer, learning rate, loss ── optimizer = Adam(learning_rate=0.001, clipnorm=1.0) # ③ LR and gradient clipping model.compile(optimizer=optimizer, loss='mse') # ── Callbacks ── early_stop = EarlyStopping(monitor='val_loss', patience=10, restore_best_weights=True) # ── Train ── history = model.fit( X_train, y_train, batch_size=32, # ④ Batch size epochs=80, # ⑤ Epochs validation_split=0.15, callbacks=[early_stop], verbose=1 ) # ── Evaluate ── test_loss = model.evaluate(X_test, y_test, verbose=0) print(f"📊 Test MSE: {test_loss:.6f}")
